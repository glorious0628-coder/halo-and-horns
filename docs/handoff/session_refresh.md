# 세션 새로 열기 (사용자 2026-10-11)

사용자가 공유한 팁: 긴 세션은 자동 압축이 몇 번 돌면 느려진다(새 세션 4분 반 vs 늙은 세션 18분). 자주 커밋하고 새로 연다.

## 언제
- 대화 창 50% 이상(검수가 get_usage로 봄), 또는 자동 압축이 2번 이상 돈 세션.
- 큰 묶음이 끝났을 때만 바꾼다. 하던 일 한가운데서 끊지 않는다.

## 어떻게
1. **세션:** 하던 묶음을 마치고 커밋·push한다(공유 트리는 `py tools/push_paths.py`, worktree는 pathspec 커밋).
2. **세션:** `docs/handoff/state/<역할>.md`를 덮어쓴다. 60줄 이하로, 아래만 적는다.
   - 지금 하던 일과 다음 큐(순서대로)
   - 브랜치, worktree, 커밋 안 된 것
   - 막힌 곳, 검수·사용자 결정을 기다리는 것
   - 꼭 알아야 할 숫자·경로(이미 문서에 있으면 경로만)
3. **세션:** 검수에 "인계 끝" 한 줄을 보낸다.
4. **검수:** 새 세션을 연다. 시작 글은 `role_prompts/<번호>_<역할>.md` + `state/<역할>.md` + "이어서 해"다. 모델·노력은 role_prompts/README 표대로 한다.
5. **검수:** 새 세션이 첫 보고를 하면 옛 세션을 지운다(사용자 승인 카드).

## 규칙 파일은 짧게
- 역할 파일과 state 파일은 짧게 쓴다. 긴 내용은 경로만 적는다.
- 매번 꼭 해야 하는 검사(예: Firefly 프롬프트 1000자 미만)는 훅으로 옮기는 것을 검토한다(검수 큐).

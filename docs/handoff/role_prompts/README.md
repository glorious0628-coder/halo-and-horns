# 역할 프롬프트 폴더 (검수가 관리)

새 세션을 만들 때 이 폴더의 파일을 하나 열어요. 맨 위의 이름·모델·노력대로 세션을 만들고, 코드 칸의 글을 그대로 붙여 넣어요.

- 이 폴더는 **'모든 것 검수' 세션이 관리해요.** 역할, 큐, 규칙이 바뀌면 검수가 해당 파일을 고치고 push해요.
- 세션 id는 적지 않아요. 보고할 곳은 늘 "'모든 것 검수' 세션(id는 list_sessions로 찾기)"이에요.
- 세션 순서: **검수 먼저** → 메인 반영 1 → 게임성 개발 1·2·3 → 이미지 개발 → 이미지 생성 1·2 → 소리 만들기(배경 음악, A23-100) → (쉬는 차례: 촬영 편집 — 사용자 10/10: ③ 교차로가 디자인·게임성 모두 끝난 뒤에 세션을 만들어 찍음, A23-102).

**세션 줄이기(사용자 10/11 "12월 1일 베타니까 세션 좀 줄여도 될 것 같지?" → 검수 결정):** 늘 일하는 세션은 8개예요. 검수, 메인 반영 1, 게임성 개발 1·2, 이미지 개발, 이미지 생성 1·2·3.
- **게임성 개발 3 → 쉬기.** 지금 하던 검증(dev2-hint·skillq)만 끝내고, 남은 서버 큐는 게임성 개발 2가 이어받아요. 게임성 개발 2의 브랜치 검증은 검수가 시험·워크플로로 하고 합쳐요.
- **소리 만들기 → 부를 때만.** 스킬 소리 42개 올리기, 몬스터 죽는 소리처럼 묶음이 생기면 검수가 깨워요.
- **촬영 편집 → 계속 쉼.** 교차로가 끝나면 다시 만들어요.
- 쉬는 세션은 지우거나 보관하지 않아요. 깨우면 그대로 이어서 해요.

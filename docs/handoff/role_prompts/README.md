# 역할 프롬프트 폴더 (검수가 관리)

새 세션을 만들 때 이 폴더의 파일을 하나 열어요. 맨 위의 이름·모델·노력대로 세션을 만들고, 코드 칸의 글을 그대로 붙여 넣어요.

- 이 폴더는 **'모든 것 검수' 세션이 관리해요.** 역할, 큐, 규칙이 바뀌면 검수가 해당 파일을 고치고 push해요.
- 세션 id는 적지 않아요. 보고할 곳은 늘 "'모든 것 검수' 세션(id는 list_sessions로 찾기)"이에요.
- 세션 순서: **검수 먼저** → 메인 반영 1 → 게임성 개발 1·2·3 → 이미지 개발 → 이미지 생성 1·2 → (쉬는 차례: 촬영 편집, 소리 만들기).

## 4. 시험을 돌리는 법·알려진 것
- 한 번에 `ls tools/test_*.py`를 **동시 3~4개까지만**(PC 메모리). 변이 있는 시험은 오래 걸린다(`test_a23_14` 약 20~40분, `test_swing_hint` 약 10분). 오래 걸리는 것은 **복사본 폴더에서** 돌려라(시험이 돌 동안 원본 파일이 바뀌면 '바뀜' 검사로 실패 처리됨).
- 시험이 `docs/art/verification_*/…json`을 다시 쓰니, 주제가 아닌 것은 `git checkout -- <파일>`로 되돌린 뒤 커밋(CRLF 때문에 'M'으로 계속 보이는 것은 내용 차이가 없다).
- `test_a23_14`의 변이 `goose rest: a mark of 0 rests`가 개발 2의 동시 실행에서 한 번 못 잡혔다(95/96). 내 혼자 돌린 실행은 96/96(286 체크). 동시 실행 때 시간·순서 문제로 보이지만 **원인은 못 찾았다**: 다시 안 잡히면 그 변이의 앵커 `kind == "Daily" and num(data.GooseDay) > 0`과 fixture의 goose 그룹을 보라.
- 파이썬 Edit 때 Bash 안 `\n`·`\t`는 줄바꿈·탭이 되어 버린다 → 파일에 Write/Edit 도구로 쓰고 `py -m py_compile`.

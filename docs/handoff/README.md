# 인계 폴더 — 읽는 순서 (검수 2026-10-11, 10/13 고침)

규칙 우선순위는 `AGENTS.md`의 "Which rule wins"를 따른다. 인계 파일은 현재 파일·브랜치·최신 사용자 결정과 대조한 뒤 쓴다.

1. `AGENTS.md` → 이 파일 → `role_prompts/README.md` → 자기 역할 프롬프트.
2. `state/<역할>.md`가 있으면 읽는다. 검수는 `state/review.md`.
3. `state/review.md`의 맨 아래 절(10/13)이 지금 상태다. `review_handoff_2026-10-11e.md`(세션 0개 때)는 기록으로만 본다.

- `role_prompts/`는 검수가 관리하는 시작 안내다. 모델 표·도구 이름·옛 작업 큐를 현재 실행 상태로 추정하지 않는다.
- `state/`와 최신 검수 인계의 완료 표시는 근거 커밋·검증 결과·실제 Studio 상태를 구분해 읽는다. 파일 수정·푸시·Studio 반영·Play 검증은 각각 다른 상태다.
- 그 밖의 날짜별 인계·설계·검토 문서는 기록이다(예외: AGENTS "Which rule wins" 6번의 지금 쓰는 방법 파일, `docs/design/3d_pipeline_2026-10-13.md` 포함). `after_reset_*` 등의 옛 큐·허락·사용량·종료 지시는 오늘 작업을 허락하지 않는다. `agents_detail.md`·`api_agent_howto.md`는 필요한 절만 참고한다.
- Claude 앱: `list_sessions`로 이 저장소(또는 worktree)의 세션을 찾고 `send_message`(local_… id)로 보낸다. 덩어리마다 최종 검수(그림은 디자인 검수)에 한 번 보고. 세션 id는 문서에 저장하지 않는다. (Codex 도구 이름은 10/11 인계 때 것.)

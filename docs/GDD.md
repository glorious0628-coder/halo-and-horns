## 0. 절대 안 바꾸는 핵심 조건 (2026-10-04 사용자 확정)

**"모든 행동이 천사 아니면 악마 쪽으로 기운다."**

새 시스템과 콘텐츠는 이 조건에 맞는지 먼저 확인하고, 안 맞으면 넣지 않는다.
- **선택이 곧 편:** 다른 플레이어를 도울지 털지, 그 선택이 헤일로(천사)나 뿔(악마) 쪽으로 쌓인다.
- **결과가 따라온다:** 악마 짓이 쌓이면 현상수배 별이 붙고, 천사 쪽 플레이어가 잡으러 온다. 이 흐름은 깡패·정의, 현상수배, 복수, 덩치 저울 시스템으로 이어진다.
- **겉모습으로 보인다:** 어떻게 놀았는지가 날개·뿔·헤일로·표정으로 드러나서 남도 한눈에 알아본다. (2026-10-05: 치비 3D 코스튬을 뺐으므로 플레이어는 본인 Roblox 아바타 위에 헤일로·뿔이 보인다. 플레이어 표정은 현재 없음.)
- **조작은 쉽게, 전투는 직접 + 원하면 자동:** 기본은 수동 전투다. 선택 퀘스트 "내 싸움을 배우는 왕관 조각"을 끝내면 자동 전투를 켜고 끌 수 있다(자동은 몬스터만). 누구를 돕고 어느 편에 설지 고르는 재미는 유지한다. 상세 기준은 §0-2와 `SPEC_ADDENDUM.md` A23을 따른다.

### 0-1. 성장·보상 원칙 (2026-10-04 최신 사용자 확정, 일부 구현·검증 중)

위의 선악 핵심은 그대로 유지한다. **피로감은 덜하게 만들지만 재미가 먼저다.** 버튼 하나를 바로 누르면 다음 무기가 되는 흐름보다, 사냥의 기대감·전리품·마을에서의 선택·다음 도전이 이어져야 한다.

- **현재 무기 강화:** 몬스터가 떨어뜨리는 강화 주문서를 얻고 모아 강화한다. 골드로 다음 티어를 사는 것과 구분한다.
  - 주문서는 모두 **성공률 10% / 30% / 70%** 세 종류다. 확률이 낮을수록 더 많이 오른다.
  - **파괴는 절대 없다.** 실패하면 그대로이거나 최대 한 단계만 내려간다.
  - **강화 옮기기 주문서**(역시 10/30/70%)로 새 무기에 강화를 옮길 수 있다. 실패해도 원래 무기의 강화는 남는다.
  - 실패하면 50%는 그대로, 50%는 한 단계 하락(최소 +0)이에요. 최대 +10이고, +1마다 공격 +10%예요. 강화는 무기마다 따로 저장되고 환생해도 남아요.
  - 첫 왕 슬라임을 잡으면 70% 주문서 1장을 꼭 줘요.
  - 상세 규칙은 `SPEC_ADDENDUM.md` A23-11·A23-12(2026-10-05 사용자 확정).
- **대박 드랍:** 레벨1 몬스터(슬라임)에서 아주 낮은 확률로 전설 무기가 나와요(상점 최고 무기의 약 2배 세기). 고렙도 아이템 때문에 슬라임을 잡으러 와요. 자동 전투로 잡아도 나와요.
- **기본 물품은 마을의 NPC 상점:** 잡화점·무기점·스킬·물약 상점은 NPC와 상호작용한다. 장비 상인의 여러 기본 무기 중 원하는 것을 골라 골드로 구매한다. 레벨·골드 조건을 만족하면 중간 무기를 건너뛸 수 있으며, 다음 나무 무기 구매를 강요하지 않는다. 구매한 무기는 보유하고 무료로 재장착한다.
- **보유 무기 판매:** 상인에게 구매가의 1/10(`floor(구매가 × 0.1)`)로 판다. 판매한 무기는 보유 목록에서 제거하고, 장착 중이었다면 무료 시작 무기로 바꾼다. 시작 무기는 판매 불가이며 중복 판매로 골드를 다시 지급하지 않는다.
- **진짜 희귀한 것은 도전의 보상:** 희귀 장비·보상은 몬스터 드롭이나 매우 어려운 퀘스트 완료로 얻는다. 모든 등급을 골드 버튼만으로 끝까지 사는 구조로 만들지 않는다.
  - 사용자 재확인 (2026-10-06): **기본 무기는 상점(대장간)에서 산다. 진짜 좋은 레어템은 퀘스트 보상, 제작자(장인)에게 사기, 몬스터 드롭으로 얻는다.** "기본 무기를 사라"는 퀘스트는 두지 않는다(이야기 퀘스트 S5 삭제).
- **최상급은 보스 도전과 재료 제작:** 매우 까다로운 보스를 공략해 얻은 재료로 특별한 장비를 만드는 경로를 둔다. 정확한 보스·재료·레시피는 아직 정하지 않았다.
- **첫 플레이도 목적이 이어져야 한다:** 진영 선택 → 그 진영에서 내가 성장할 이유 → 안내자의 감사 인사와 첫 임무 제안·수락 → 첫 사냥 → 전리품 → 마을 상인 선택 → 다음 지역·더 어려운 도전. 안내자 대화·수락은 코드 반영 후 Studio 통합 검증 대기이며 월드3D 안내자는 없다. 주문서 강화는 남은 작업으로 구분하고 현재 없는 아이템·보상을 이미 얻었다고 안내하지 않는다.
- **NPC는 상황에 맞게 반응한다:** 둘러보기·구매·재장착·판매에 맞는 짧은 반응을 둔다. 현재 구현은 미리 작성한 문구의 상황 분기다. 실제 AI 대화 연결과 유료 API 사용은 아직 승인되지 않았으며, 비용이 드는 연결은 총액을 먼저 알리고 별도 승인받는다.
- **노가다는 없애는 게 아니라 덜 지루하게(2026-10-05 사용자):** "노가다가 아예 없을 수는 없어. 덜 있는 건 있어도." 반복 사냥은 RPG의 기본이라 남긴다. 대신 아래처럼 붙여서 덜 지루하게 만든다.
  - 짧은 목표와 보이는 진행
  - 사냥 중 작은 놀람(드랍·대박·황금 몬스터)
  - 동사 바꾸기(처치·채집·이벤트·선택)
  - 같이 하면 더 빠르게
  - 자동 전투(퀘스트로 해금)

  성장에 시간이 걸리는 것 자체는 정상이다. 같은 숫자만 커지는 벽("여우 50마리")과 할 일 없는 대기는 피한다.
- **간단함을 무료 자동 완료와 혼동하지 않는다:** 불필요한 왕복과 반복 확인은 줄이되, 무엇을 얻고 어느 도전에 준비할지 고르는 재미는 유지한다. 확률 실패·장비 파괴·거래소·새 과금은 이번 요구에 포함되어 있지 않다.

**현재 구현:** 기본 나무·철 무기(티어2·3, 150·800골드)의 직접 선택 구매, 보유 목록·무료 재장착, 판매(15·80골드), 상황별 작성된 상인 반응이 코드에 반영됐고 오프라인 검사를 통과했다. 시작 무기(티어1)는 무료 재장착만 한다. 구매는 필수가 아니다. 현재 서버 상호작용 대상은 교차로의 기존 대장간 모루다. Studio 통합 검증은 아직 하지 않았다(2026-10-06 작업 재개). **2026-10-05 검토 결과:** 지금 코드는 대장간 방문 뒤 다음 목표 줄이 사라지므로, A23-3대로 다음 목표 1줄을 고정 표시해야 한다. 환생 때는 보유 무기도 초기화한다(§9, A23-4).

**남은 범위:** 모든 상점을 실제 NPC로 연결하는 작업, NPC 스폰, 안내자 대화·첫 임무 수락의 최신 Studio 통합 검증이 남아 있다. 장비 상인 C “피곤하지만 통달한 장인” 원화는 승인됐고 초보 무기9장은 미승인·미업로드다. 물약 상인은 아직 비활성이다. 주문서 강화, 희귀 장비 드롭·고난도 퀘스트 보상·보스 재료 제작과 실제 AI 대화도 완료가 아니다. Config에 상위 티어 가격이 남아 있어도 상점 판매 상한은 티어3이며, 상위 획득 경로가 구현됐다는 뜻이 아니다.

**기존 설명보다 우선:** 아래 절에 남은 `업그레이드 버튼 한 번 → 다음 무기 자동 장착`과 강제 순차 구매 설명은 이 최신 선택 구매·NPC 상점 원칙으로 대체한다. 선악 핵심 조건과 기존 승인 디자인은 유지한다.

**일정은 미확정:** `RELEASE_PLAN.md`의 베타·정식 날짜는 바꾸지 않는다. 이 새 성장 계약 중 무엇을 베타/정식에 포함할지와 완료 날짜는 별도 확정이 필요하다. 기존 정식 이후 경제 항목을 근거로 이번 보스 재료 제작 요구를 없던 것으로 하거나, 반대로 전부 베타에 끝낸다고 약속하지 않는다. 기록: [사용자 결정](art/weapon_progression_user_decisions_2026-10-04.md), [첫 플레이 진단](art/onboarding_story_review_2026-10-04.md).

### 0-2. 전투 방향 — 수동 전투 + 선택 퀘스트로 얻는 자동 전투 (2026-10-04 수동 확정, 2026-10-05 자동 켜기/끄기 추가)

**사용자가 기존 자동 전투 방향에서 마음을 바꿔 수동 전투를 선택했고(10-04), 다음 날 자동 전투 켜기/끄기를 선택 퀘스트 보상으로 추가했다(10-05).** 과거의 “자동은 장전, 손은 발사”(충전·PERFECT) 설계는 계속 폐기다. “모든 행동이 천사 아니면 악마 쪽으로 기운다”는 핵심은 그대로다.

- **기본 공격:** 공격 버튼·키 또는 짧은 클릭을 입력할 때만1회 공격한다. 길게 누르기 반복 공격은 없다.
- **자동 전투 (2026-10-05):** 처음엔 꺼져 있다. 진영·직업을 고르면 바로 받을 수 있는 **선택 퀘스트 "내 싸움을 배우는 왕관 조각"**을 끝내면 영구 해금되고, 그 뒤로 버튼으로 켜고 끈다(상태 저장). 자동일 때는 기본 공격과 스킬을 모두 알아서 쓰며 **몬스터만** 때린다. 사람은 직접 입력으로만 때린다. 레벨 조건 없음.
- **왕관 조각 퀘스트 (선택):** 큰 슬라임이 삼킨 왕관 조각을 되찾으면, 조각이 내 싸움을 지켜본다 — ① 기본 공격만으로 슬라임 3마리 ② 스킬 한 번에 2마리 이상 맞히기 ③ 체력 절반 이상 지키며 큰 슬라임 잡기. 마지막에 조각을 **정화**(천사 쪽, 명예 조금)할지 **삼킬지**(악마 쪽, 악명 조금) 고른다. 어느 쪽이든 자동 전투가 풀린다. 첫 10분 안에 선악 선택을 직접 느끼게 하는 장치다. 5~7분 목표.
- **스킬:** 전투 충전 게이지 자체를 없앤다. 충전 링·숫자·PERFECT·자동 발사·10스택 조건도 없다. MP와 재사용 시간으로 사용하며 현재 기본 스킬 구현값은 **MP20·재사용3초**다. 수치는 실제 플레이 후 조정할 수 있다.
- **카메라:** 왼쪽 버튼으로 화면을 끌면 회전한다. 짧은 클릭은 공격하고 드래그는 공격하지 않는다.
- **성장:** 요구 레벨을 만족해 스킬을 배우고 빈 칸에 장착하는 방향이며 학습·슬롯은 미완료다. 전직은 후속 업데이트 대상으로 남긴다. “다음 해금” 예고는 제거하며 아직 없는 기능을 완료로 안내하지 않는다.
- **첫 임무:** 같은 진영 안내자의3쪽 대화 → 명시적 수락 → 말랑 초원 → 슬라임5마리 → **150골드**(2026-10-05 사용자 확정, 120에서 올림 — 나무 무기를 바로 살 수 있게, 구매는 선택)로 이어진다. 대화 닫기는 수락이 아니고 메뉴의 “안내자 만나기”로 다시 연다. 마을에 개인 튜토리얼 슬라임을 소환하지 않는다. 대장간 방문 뒤에도 다음 목표 1줄을 계속 보여 준다.
- **스킬 사용 퀘스트:** 몬스터를 1마리 이상 맞힌 스킬만 센다(2026-10-05 사용자 확정).
- **현재 상태 (2026-10-05 14:00 검수):**
  - 코드에 반영됐고 미커밋이다: 수동 전투·안내자·대장간, 150골드(실제 플레이 기록 확인), 스킬 퀘스트 맞힌 것만 집계, 대장간 뒤 다음 목표, 3D 오프닝.
  - 자동 전투는 서버 루프와 버튼까지 만들었지만, 왕관 조각 퀘스트가 아직 없어서 해금할 수 없다.
  - 아직 검증 전: 직접 입력 체감, 재접속 저장, 다인, 전체 첫 10분. 자세한 내용은 `docs/review/checkpoint_2026-10-05_1400.md`.

이 절과 `SPEC_ADDENDUM.md` A23·A22가 다른 문서에 남은 자동 전투·충전 설계보다 우선한다. 승인 카드 그림 속 옛 게이지 문구는 디자인 보류로 남을 수 있으며, 이를 고쳤다고 보고하거나 승인 디자인을 임의 교체하지 않는다. 전쟁 점수와 HP/MP/경험치 표시는 전투 충전 게이지와 구분해 유지한다.

### 1-1. 세계관 (짧게)

**오프닝 (2026-10-05 사용자 결정, 구현 예정):** 처음 들어오면 진영을 다짜고짜 고르지 않고, **15~25초짜리 짧은 3D 연출**을 먼저 봐요. 게임 속 맵에서 카메라가 움직여요: 교차로 하늘의 **부서진 왕관**을 올려다보고 → 분수 위 **조각 빛기둥**으로 내려와 조각이 **빛의 성채**와 **뿔 소굴**로 날아가 후광·뿔이 빛나고 → 교차로에 선 **내 캐릭터 앞에도 조각 하나가 떨어지며** "어느 편에 설래?" → 진영 카드. 아래 세 줄이 자막으로 나와요. **건너뛰기** 가능, 처음 한 번만(메뉴에서 다시 보기), 새 그림 없이 게임 속 맵·카메라·기존 효과로 만들어요(그림 단계에서 Firefly로 더 다듬을 수 있음). 진영·직업을 고른 뒤에는 같은 진영 안내자의 짧은3쪽 대화로 첫 임무를 제안해요.

> 세상을 지키던 균형의 왕관이 부서졌다.
> 조각을 주운 자들 중 누구는 머리 위에 후광이, 누구는 뿔이 돋았다.
> 조각을 더 많이 모으는 쪽이 세상을 다시 만든다.

모든 시스템이 이 한 가지 이야기에 붙어 있어요 (문구는 전부 `Config.Story` / `Config.Text`):

| 시스템 | 세계관 속 의미 |
|---|---|
| 후광 / 뿔 | 왕관 조각의 힘. 계급이 오를수록 커져요 |
| 10분 진영 전쟁 | 이번 판에 **왕관을 누가 차지하나** ("이번 판 왕관은 빛의 기사단이 차지했다!"). 하늘 색 = 왕관의 색 |
| 황금 거위 | 왕관 조각을 품은 신성한 짐승 (기사단은 구조, 뿔 군단은 밀렵) |
| 괴수화 | 조각의 어둠에 삼켜진 악당 (경보 문구) |
| 전향 환생 | 타락(빛 → 뿔) / 구원(뿔 → 빛) 이야기 |
| 지역·몬스터·퀘스트 이름 | "조각먹은 슬라임", "조각 도둑 고블린", "몬스터 쓰러뜨려 조각 모으기" 같은 말투 |

안내자에게 감사 인사와 보급로 이야기를 듣고 마지막 쪽에서 임무를 수락해요. 닫거나 “나중에”를 누르면 미수락 상태를 유지하고 메뉴에서 다시 만날 수 있어요.

## 2. 왜 계속 하게 되는가 (재미를 설명해 줄게요)

"왜 재밌는지 설명은 못 하겠는데 계속 하게 되는 게임"에는 이유가 있어요. 사람 뇌가 좋아하는 작은 장치들을 여러 개 겹쳐 놓은 거예요.

| 게임 속 장치 | 플레이어가 느끼는 기분 | 심리학 이름 |
|---|---|---|
| 때릴 때마다 숫자가 튀고 골드가 `+16` | "뭔가 계속 얻고 있다" | 즉각 보상 (손맛) |
| 직접 공격하고 MP·재사용 시간을 보며 스킬 사용 | "지금 스킬을 쓰자!" | 전투 선택과 손맛 |
| 화면에 남은 경험치와 현재 임무 진행 표시 | "조금만 더 하면 되는데…" | 목표 기울기 효과 |
| 몬스터 4%가 **황금 몬스터**, 황금 거위 보상 5%+가 **희귀** | "이번엔 희귀일지도?" | 가변 보상 (돈은 안 씀) |
| **일일 퀘스트** 3개 + 끝나면 계속 이어지는 추가 퀘스트 | "하던 건 마저 끝내야지" | 자이가르닉 효과 |
| 5분마다 **전쟁 결과** 또는 **황금 거위** | "이번 것만 보고 끌게" | 약속 시간 효과 |
| 등의 **골드 자루**, 악당의 **원한 돈자루** 45초 | "털리기 전에 저금!", "45초만 버티자!" | 손실 회피 (작은 긴장감) |
| 후광/뿔이 계급마다 커지고, 칭호·표식이 붙음 | "다들 내가 센 걸 보겠지" | 보여지는 지위 |
| 나를 쓰러뜨린 상대에게 **복수** (90초, 화살표) | "저 녀석 꼭 잡는다" | 라이벌 이야기 |
| 우리 편이 왕관을 차지하면 하늘이 금빛/핏빛 | "우리 편을 위해 싸운다" | 소속감 |
| 환생마다 영구 보너스 +25% (적은 편으로 가면 +40%) | "다음 판은 더 빨리 큰다" | 복리 성장 |

**착하게 만들기 약속 (로블록스 유저는 어린 친구가 많아요):**
- **지금(베타·정식 출시)** 로벅스로 파는 건 **변경권**(진행도를 지키는 선택권)뿐이고, 무료로도 언제든 바꿀 수 있어요. **뽑기 등 캐시 아이템은 나중에 차차 업데이트할 예정**이에요(2026-10-05 사용자 결정, 아직 설계·구현 안 함 — §10-1).
- 잃는 건 항상 **조금만** (주머니 골드 일부). 그마저도 기사단이 **120%로 되찾아 줄 수 있어요.** 금고, 무기, 레벨은 절대 안 뺏겨요.
- 쉬었다 와도 벌칙이 없어요. 오히려 **휴가 보너스**로 못 한 날의 70%를 챙겨 줘요.

## 3. 독창성: MMORPG 유저 불만을 뒤집은 시스템

실제 MMORPG 유저들이 자주 하는 불평을 모아서, 하나씩 "뒤집은" 시스템이에요. **7개 모두 첫 버전(MVP)에 들어가요.**

| 유저 불만 | 우리 게임 시스템 | 어떻게 뒤집었나 |
|---|---|---|
| "사람 많은 쪽이 무조건 이겨요" · "고렙이 저렙만 골라 잡아요" | **덩치 저울** (+ 깡패 규칙) | 약한 편은 몸·체력·공격력이 최대 1.6배로 커져요. 약자를 괴롭히면 보상 0, 내 몸이 줄어들고 현상금 2배 |
| "털리면 그냥 끝, 억울해요" | **원한 돈자루** | 뺏긴 골드는 45초 동안 도둑 등의 자루에 묶여 있어요. 기사단이 잡으면 피해자에게 120%로 돌아가요 |
| "자동사냥이면 사람이 할 게 없어요" | **직접 공격이 기본, 자동은 선택해서 얻는 편의** | 기본은 공격 입력과 MP·재사용 시간으로 싸워요. 왕관 조각 선택 퀘스트로 얻는 자동 전투는 처음엔 꺼져 있고, 몬스터만 때리고, 사람은 못 때리며, 팔지 않아요 |
| "PK·수배범이 무적처럼 굴어요" | **수배범 괴수화** | 별 5개 악당은 거대 괴수가 되어 120초 동안 서버 전체의 레이드 목표가 돼요 |
| "이벤트는 늦게 오면 끝, 지면 아무것도 없어요" | **황금 거위 줄다리기 + 단골 운** | 10분마다(전쟁과 엇갈려 5분마다 무언가) 열리고, 져도 40% + 응원별. 오래 있을수록 희귀 확률 ↑ |
| "편을 바꾸면 다 날아가고, 환생은 지루해요" | **전향 환생** | 환생할 때 편을 다시 골라요. 인원이 적은 편으로 가면 +40%, 타락/구원 표식이 영구로 남아요 |
| "일일 숙제를 강요해요, 빠지면 손해예요" | **일일 퀘스트 + 휴가 보너스** | 안 해도 되지만 하면 좋아요. 못 온 날은 70%를 챙겨 주고, 직접 하면 100% |

## 4. 코어 루프

### 30초 루프 — "직접 공격하고, 스킬 쓰고, 보상 받기!"
1. 몬스터가 알아서 나한테 걸어와요 (30칸 안에 들어오면).
2. **공격** 버튼·키·짧은 클릭으로1회씩 공격해요. 전투 충전은 없어요. 왕관 조각 선택 퀘스트를 끝냈다면 자동 전투를 켜서 공격·스킬을 맡길 수도 있어요(몬스터만).
3. MP가 충분하고 재사용 시간이 끝났으면 **스킬**을 눌러요. 현재 기본값은20MP·3초예요.
4. 몬스터가 펑 터지면서 `+골드 +경험치`, 골드는 **주머니**로.

### 5분 루프 — "무기 바꾸고, 이벤트 하나"
1. 마을 대장간에서 여러 기본 무기(검·지팡이·활) 중 골라 구매하거나 보유 무기를 무료로 재장착해요. 특정 다음 무기 구매를 강요하지 않아요.
2. 일일 퀘스트 하나 완료 → **받기** 펑!
3. 5분마다 둘 중 하나: **왕관 쟁탈전 결과** 또는 **황금 거위 줄다리기**.
4. PvP 지역 선택지: 악당이라면 "털고 45초 버티기", 기사라면 "보라색 화살표 = 원한 자루 도둑 잡으러 가자!", 별 5개 악당이 나오면 다 같이 **괴수 레이드**.

### 한 판 (20~60분) — "왕관 2~6번, 거위 2~6번"
- 10분짜리 **왕관 쟁탈전** 2~6판. 이기면 다음 10분 동안 우리 편 골드/경험치 +25%.
- 황금 거위 2~6번, **단골 운**이 올라 희귀 확률 상승 (최대 12.5%).
- 끝낼 때쯤 화면엔 항상 "황금 거위까지 3:12" 같은 카운트다운이 떠 있어요.

### 장기 (며칠~몇 주) — "환생, 계급, 표식"
- **전향 환생:** Lv 50(2번째부터 +5씩)에 환생하면서 편을 다시 골라요 (9장).
- **진영 계급:** 기사단은 명예, 뿔 군단은 악명을 쌓아 칭호가 올라가요. 후광/뿔도 함께 커져요.
- **일일 퀘스트**와 **휴가 보너스**로 매일 조금씩.

| 계급 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 필요 점수 | 0 | 10 | 50 | 200 | 1000 |
| 빛의 기사단 (명예) | 견습 기사 | 기사 | 성기사 | 성자 | 대천사 |
| 뿔 군단 (악명) | 불량배 | 약탈자 | 군벌 | 공포의 군주 | 마왕 |

## 5. 선역 vs 악역

### 5-1. 한눈에 비교

| | **빛의 기사단 (선역)** | **뿔 군단 (악역)** |
|---|---|---|
| 판타지 | 조각을 지키고 되찾아 주는 빛나는 기사 | 조각을 빼앗아 부자 되는 만화 악당 |
| 생김새 | 머리 위 노란 후광, 금색 이름 | 머리에 빨간 뿔, 빨간 이름 |
| 성장 | **경험치 +30%** | **골드 +25%** |
| 전투 | 최대 체력 +20%, 초당 체력 2% 회복 | **공격력 +15%**, 준 피해의 10% 흡혈 |
| 스킬 지원 | 스킬 범위 안 동료 **치유** | 별도 충전 보너스 없이 기존 공격력·흡혈 특성 유지 |
| 함께하기 | 근처 기사 1명당 공격력 +5% (최대 +15%) | 혼자서도 강함 |
| 골드 보관 | 90초마다 주머니 골드 **절반 자동 저금** | 자동 저금 없음 → 마을까지 들고 가야 저금 |
| 다른 편 쓰러뜨리면 | 현상금(새로 생기는 골드) + 명예, 원한 자루를 되찾아 주면 **복수 대행 +100** | 기사 주머니 골드 20%를 **원한 돈자루**에 담기 + 현상수배 별 +1 |
| 특별 규칙 | 현상수배가 안 됨. 괴수는 **어디서든** 때릴 수 있음 | 별 1개마다 공격력 +5%, 사냥 골드 +10%. **별 5개 = 괴수화** |
| 추천 | 편하게 키우기, 친구랑 같이, 추적의 재미 | 짜릿한 한탕, 45초 버티는 재미 |

세 번째 길인 **장인 길드(중립)** 는 5-8에서 따로 설명해요.

### 5-2. 두 편이 만나는 규칙 (PvP)
- **PvP는 고블린 숲, 해골 유적에서만.** 마을 3곳과 말랑 초원은 안전 (단, 괴수는 예외 — 어디서든 기사단에게 맞아요).
- **장인 길드는 PvP에 아예 끼지 않아요.** 어디서든 때릴 수도 맞을 수도 없어요 (5-8).
- **같은 편끼리는 못 때려요.** 빛 vs 뿔만 싸워요.
- **사람은 직접 누른 공격·스킬로만 때려요.** 자동 전투(왕관 조각 퀘스트로 해금)는 몬스터만 때려요 — 잠깐 자리를 비워도 싸움이 나지 않아요. 서버의 진영·지역·보호 규칙은 그대로 적용해요.
- 손 공격 한 대 = 상대 기본 체력의 약 5%, 발사 한 방 = 최대 35%. 높은 레벨이 한 방에 끝내는 일은 없어요.
- 옛날의 "레벨 차이 10 이상이면 무피해" 규칙은 없어지고, **깡패 규칙**(5-7)으로 바뀌었어요.

### 5-3. 원한 돈자루 · 현상수배 · 괴수화
**원한 돈자루**
- 악당이 기사를 쓰러뜨리면 뺏은 골드(주머니 골드의 20%, 상한 있음)가 바로 악당 것이 되지 않고 **등의 보라색 자루**에 들어가요. 자루 위에는 피해자의 **반투명 원한 유령**이 떠 있어요.
- 자루는 **PvP 지역에 있을 때만** 45초가 줄어들어요. 자루를 든 동안은 순간이동·이동 발판 금지. 여러 번 털면 자루 하나에 합쳐지고 시간은 다시 45초.
- 모든 기사단 화면에 **자루 든 악당을 가리키는 화살표**가 떠요.
- 45초 안에 기사단 누구든 도둑을 잡으면 → 피해자 금고로 **120%** 반환 + 잡은 기사는 현상금 + **복수 대행 보너스 100골드**.
- 45초를 버티면 → 골드와 악명이 악당 것. 도둑이 몬스터에게 죽거나 나가 버리면 → 피해자에게 100% 반환.
- 짜고 치기 방지: 같은 도둑이 같은 사람을 3분 안에 또 털면 0골드. 20% 추가 보너스는 **피해자 한 명당 10분에 한 번**, 복수 대행 보너스는 **기사 한 명당 5분에 한 번**이에요 (도둑이 누구든 — 부계정 도둑을 여러 개 만들어도 더 받을 수 없어요). 이 기록은 저장돼서 서버를 옮겨도 그대로예요.
- 자루가 풀리기 전에 피해자가 환생하면, 그 피해자 몫은 돌려주지 않아요 (환생 초기화를 피해 가는 걸 막아요).

**현상수배 별 & 현상금**
- 악당이 기사를 쓰러뜨릴 때마다 별 +1 (최대 5, 깡패 KO는 0). 2분 동안 아무도 안 쓰러뜨리면 1개씩 사라져요.
- **별 3개 이상:** 몸이 빨갛게 빛나 벽 너머로도 보이고, 순간이동 금지.
- **현상금** = 15 × 레벨 × 별 개수 (깡패면 2배). 교차로 마을 **현상수배 게시판**에 TOP 3.
- **도망쳐도 소용없어요:** 별이 있는 악당이 전투 중에 나가 버리면, 마지막으로 때린 기사가 현상금을 받아요. 나갔다 다시 들어와도 별은 그동안 줄어든 만큼만 빠지고 남아 있어요. 마을에서 스스로 리셋하거나 떨어져 죽어도 별은 그대로예요.
- 같은 두 사람 사이의 KO 보상(현상금·명예·악명·별)은 5분에 한 번만 나와요. 짜고 치기로 별을 쌓거나 골드를 만들지 못하게 하는 규칙이고, 기록이 저장돼서 둘이 서버를 옮겨도 그대로예요.

**수배범 괴수화**
- 별 5개가 된 악당은 (서버에 괴수가 없으면) **10초 경보** 뒤 **괴수**로 변신해요. 괴수는 서버에 한 명만, 나머지는 줄 서서 기다려요.
- 괴수: 몸 **3배**, 체력 **20배** (+근처 기사 1명당 15% 더), 4초마다 **발 구르기**로 근처 기사에게 체력 6% 피해 (새싹·부활 보호·마을 안은 안전). 안전 지역에서 밟힌 건 PvP 공격으로 치지 않아요. 조작은 그대로.
- 기사 한 명의 발사 한 방은 괴수 체력의 8%까지만 들어가요 (사람 상대는 35%). 괴수의 흡혈도 원래 체력 기준이라, 레이드를 혼자 회복으로 버티지 못해요.
- 괴수는 **안전 지대에서도** 기사단에게 맞고, 순간이동을 못 해요. 새싹 기사도 괴수는 때릴 수 있어요.
- **괴수 토벌:** 보상 = 현상금 × 3 + 괴수의 주머니 골드 → 절반은 넣은 피해 비율로, 절반은 참여자(때린 사람 + 그 사람을 발사로 치유한 사람) 모두에게 똑같이. 막타 보너스 없음 (피해는 실제로 깎은 체력만 세요).
  - 짜고 치기 방지: 보상에 들어가는 괴수 주머니는 레벨 × 100골드까지, 같은 괴수로 받는 새로 생기는 골드 몫은 30분에 한 번.
  - 괴수가 나가 버려도 기사단이 피해를 넣었다면 토벌로 끝나 보상이 나와요.
- **120초 생존:** 주머니 골드 × 1.5가 금고로 + 이번 접속 동안 칭호 **"전설의 악당"**.
- 어느 쪽이든 별 0개, 원래 크기, 10초 보호막.

### 5-4. 왕관 쟁탈전 (진영 전쟁 게이지)
- 화면 맨 위에 빛 vs 뿔 게이지 + 10분 카운트다운. 끝나면 "이번 판 왕관은 ○○이 차지했다!"
- 점수: 몬스터 1, 황금 몬스터 5, 상대 편 쓰러뜨리기 20 (+별 1개당 5, 깡패 KO는 0), 황금 거위 승리 +60, 괴수 토벌/생존 +150. 여럿이 같이 잡은 몬스터도 진영 점수는 한 마리분만 들어가요 (내 개인 점수는 그대로).
- **이번 판 평균 인원수로 나눈 점수**로 승부 → 3명인 편도 8명인 편을 이길 수 있어요. 끝나기 직전에 우르르 나가도 결과가 뒤집히지 않아요.
- 장인 길드는 점수를 내지 않고 축복도 받지 않아요.
- 이긴 편: 다음 10분간 **골드/경험치 +25%** + 하늘이 왕관 색으로 (빛 = 금빛 새벽, 뿔 = 핏빛 월식).
- 이번 판에 30점 이상 낸 사람은 상자 (이긴 편 레벨×100, 진 편 레벨×30 골드).
- 한 편만 서버에 있으면 **몬스터 포위전**: 1인당 150점을 넘기면 승리.

### 5-5. 편 바꾸기 (운명의 제단)
- 교차로 마을의 **운명의 제단**에서 바꿔요. 빛의 기사단·뿔 군단·장인 길드 중 지금 편이 아닌 곳을 골라요. 두 가지 길이 있어요 (10장 변경권 참고):
  - **무료:** 떠나는 진영의 개인 점수가 0이 돼요 ("배신의 대가"). 기사단을 떠나면 명예 0, 뿔 군단을 떠나면 악명 0. 들어가는 진영 점수는 예전 그대로.
  - **진영 변경권 1장:** 명예·악명 둘 다 그대로.
  - 잃을 점수가 없으면(점수 0, 또는 장인 길드를 떠날 때) 언제나 무료이고 변경권을 쓰지 않아요.
- 조건: 현상수배 별 0개, 원한 자루 없음, 괴수 아님, 전투 중 아님. 깡패 단계가 남아 있으면 장인 길드로는 갈 수 없어요 (깡패 벌을 피해 숨지 못하게). **누구나 10분에 한 번** (전쟁 판마다 편 갈아타기 방지). 처음 약한 편을 골라 +300골드를 받은 직후에도 10분이 지나야 바꿀 수 있어요.
- 레벨, 골드, 무기, 직업은 그대로. 제단에서 바꾸면 표식(타락/구원)은 안 생겨요.

### 5-6. 덩치 저울 (예전 "약자 보너스 %"를 대신해요)
- 30초마다(그리고 누가 들어오거나 나가거나 편을 바꿀 때) 두 편의 **진영 힘 합계**를 비교해요. 진영 힘 = 레벨·무기·환생으로 계산한 기본 힘(코드 `JusticeService.GetPower`). (2026-10-05: 예전 이름 "전투력"을 "진영 힘"으로 바꿨어요. 이제부터 "전투력"은 5-7 깡패 규칙에 적은 `Config.CombatPower`만 뜻해요. beta_basics BB4.)
- 새싹, 2분 넘게 아무것도 안 한(잠수) 사람, 마을에 1분 넘게 서 있는 사람은 합계에서 빠져요 (고렙 부계정을 마을에 세워 두는 꼼수 방지). 빠진 사람도 덩치 효과는 똑같이 받아요. 장인 길드는 아예 계산에 들어가지 않아요.
- 약한 편은 **S = √(상대 합 ÷ 우리 합)** 만큼 커져요 (최소 1.0, 최대 **1.6배**). 강한 편은 1.0.
- S는 **몸 크기**(3초 동안 스르륵), **최대 체력**(체력 % 유지), **모든 공격력**에 곱해져요. 그래서 인원이 적어도 한 명 한 명이 "거인"처럼 싸워요.
- 두 편 모두 1명 이상 있을 때만 작동. 처음 진영을 고를 때 약한 편을 고르면 **시작 골드 +300** (처음 한 번만).

### 5-7. 초보 보호 & 깡패 규칙 & 복수
- **새싹 보호:** 첫 환생 전, Lv 15 미만이거나 플레이 60분 미만이면 PvP에서 때릴 수도 맞을 수도 없어요 ("새싹 보호").
- **부활 보호 10초:** 부활하면 보호막. 내가 사람을 때리면 바로 풀려요.
- **깡패 규칙 (두 진영 모두):** 아래 중 하나면 "깡패 KO"예요.
  1. 상대 전투력이 내 **절반 미만** (여기서 전투력은 `Config.CombatPower`, 곧 레벨·무기(강화 +N 포함)로만 계산해요. 환생 보너스는 골드·경험치 전용이라 빼요). 단, 상대가 10초 안에 먼저 나를 **내 기본 체력의 20% 이상** 때렸거나(실수로 한 대 스친 건 안 쳐요), 상대가 현상수배·깡패 상태면 예외
  2. 상대가 **부활한 지 15초 안**
  3. 10분 안에 같은 사람을 **3번째 이상** 쓰러뜨림
  - **방어 KO:** 상대가 먼저 덤벼서(10초 안에 20% 이상) 2·3번에 걸린 경우는 깡패가 아니에요. 대신 보상(약탈·별·명예/악명·현상금)도 없어요.
  - 괴수는 깡패가 되지 않아요.
  - 깡패 KO = 약탈 0, 별 0, 명예/악명 0. 대신 내가 **깡패 1단계** (최대 3): 단계마다 **몸 -15%, 공격력 -15%**, 이름표에 빨간 **"깡패"**, 나를 잡으면 **현상금 2배**. 5분 동안 깡패 짓을 안 하면 1단계씩 풀려요. 나갔다 다시 들어와도 그동안 풀린 만큼만 줄어 있어요.
- **복수:** 누군가에게 쓰러지면 90초 동안 그 사람에게 **공격력 +25%**, 화면에 **주황 화살표**.
- **잃는 건 주머니 골드뿐:** 레벨×10 골드는 절대 안 뺏기고, 한 번에 최대 레벨×100까지만. 몬스터에게 죽으면 아무것도 안 잃어요 (별 있는 악당만 예외 — 단, 마을 안에서 죽거나 스스로 리셋한 건 손실도 없고 별도 그대로예요).

### 5-8. 장인 길드 (중립 · 세 번째 길)
싸움보다 사냥과 (나중에) 제작이 좋은 사람을 위한 편이에요. 진영 고르기 화면의 세 번째 카드: "싸움 버프 없음 · PvP 없음 · 제작 특화(곧 추가)". 세계관 한 줄: "조각을 줍지 않고, 다듬기로 한 자들."
- **PvP 완전 면역:** 어느 지역에서든 사람을 때릴 수도, 사람에게 맞을 수도 없어요 (손 공격·발사·발 구르기 전부). 약탈, 원한 자루, 현상수배 별, 현상금, 깡패, 복수, 괴수화와 상관없어요. 새싹 보호도 필요 없어요. PvP 지역에 들어가면 "PvP 지역이지만 장인 길드는 공격받지 않아요." 안내가 나와요.
- **싸움 버프 없음:** 경험치·골드·체력·공격력 보너스, 체력 회복·흡혈, 기사단의 90초 자동 저금이 없어요 (마을에 들어가면 저금되는 건 똑같아요). 기본 스킬은 MP·재사용 시간으로 쓰며 빛의 동료 치유는 없어요.
- **전쟁·저울에서 빠짐:** 왕관 쟁탈전 점수를 내지 않고 축복도 받지 않아요. 덩치 저울 합계와 인원 비율(약한 편 시작 보너스, 환생 +40%)에서도 빠지고, 내 덩치는 항상 1배예요.
- **황금 거위·퀘스트:** 줄다리기에 끼지 않아요 (때려도 0점, 보상 없음). 일일 퀘스트에 PvP·약탈·현상금·거위·괴수 퀘스트가 나오지 않아요.
- **집 = 교차로 마을:** 교차로 마을에서 부활해요. 빛의 성채와 뿔 소굴에는 들어갈 수 없어요 (들어가면 교차로로 돌려보내요).
- **직업 이름:** 전사 = **대장장이**, 마법사 = **연금술사**, 궁수 = **사냥꾼** (능력치와 공격 모양은 같아요).
- **생김새:** 청록색 이름표와 **'장'** 문장, 머리 위 청록 톱니바퀴 표식. 후광·뿔은 없어요.
- **편 바꾸기·환생:** 장인 길드는 떠날 때 비용이 없어요 (언제나 무료). 다만 이번 주 '장인 명성' 기록은 사라져요 (A23-24). 깡패 단계가 남아 있으면 제단으로도 환생으로도 장인 길드에 들어올 수 없어요. 장인 길드로 오가는 환생은 표식이 안 생기고, 환생 보너스는 항상 +25%예요.
- **장인 명성 (베타, A23-24):** 직접 사냥해 얻은 강화 주문서로 강화에 성공하면 오른 칸만큼 주간 "장인 명성"이 올라요. 1~3위는 명예·악명 1~3위와 같은 보상을 받아요.
- **제작 특화는 2단계(페이즈 2):** 제작 능력은 나중에 추가되고, 제작 점수도 같은 "장인 명성"에 더해져요.

## 6. 직업

버튼은 모두 똑같아요 (뇌 빼고!). 직업은 **공격 모양, 능력치, 무기 모양, 발사 모양**만 바꿔요. 직업과 진영은 따로라서, 어느 진영에서든 어떤 직업이든 할 수 있어요.

| 직업 | 빛의 기사단 이름 | 뿔 군단 이름 | 장인 길드 이름 | 공격 모양 | 체력 / 공격 / 공격 간격 | 발사 모양 | 무기 |
|---|---|---|---|---|---|---|---|
| 전사 | 성기사 | 광전사 | 대장장이 | 내 주변 10칸 **전부** | ×1.3 / ×1.0 / 1초 | 내 자리 충격파 | 검 |
| 마법사 | 빛의 마법사 | 흑마법사 | 연금술사 | 35칸 안 가장 가까운 적 + **7칸 폭발** | ×0.8 / ×1.3 / 1.25초 | 가장 가까운 적에게 메테오 | 빛나는 지팡이 |
| 궁수 | 레인저 | 그림자 사냥꾼 | 사냥꾼 | 30칸 안 가장 가까운 **2명** | ×1.0 / ×0.55 / 0.5초, 이동 +10% | 가장 가까운 적에게 화살비 | 활 |

- 원거리(마법사·궁수)는 **사람 상대 공격력 ×0.85** (공정함).
- 궁수도 입력할 때만 공격하며 직업별 공격 간격을 따라요. 직업별 충전량은 사용하지 않아요.
- 무기 7단계(가격·공격력)는 모든 직업이 같고, 이름과 모양만 달라요. 예: 나뭇가지 → 나무 검 / 마른 지팡이 → 참나무 지팡이 / 새총 활 → 나무 활 … 7단계는 "여명의 검"(기사단) / "파멸의 활"(뿔 군단) 같은 진영 무기.
- **고르기:** 처음 진영을 고른 뒤 직업 카드 3장이 나와요 (진영에 맞는 이름 + 한 줄 설명). 예전 저장 데이터가 있는 사람도 한 번 무료로 고를 수 있어요 (레벨 유지).
- **바꾸기:** 메뉴 > 직업 변경 (안전 지대에서, 쿨타임 없음). **무료 = 레벨 1부터 다시**, **직업 변경권 = 레벨 그대로** (10장).

## 7. 황금 거위 줄다리기 & 단골 운

- **10분마다** 교차로 마을 광장(안전 지대)에 **황금 거위**가 60초 동안 내려와요. 전쟁 결과와 5분씩 엇갈려서 **5분마다 뭔가 일어나요.** 화면에 항상 "황금 거위까지 4:59".
  (랜덤으로 나오는 4% 황금 몬스터와는 다른 이벤트예요.)
- 거위는 안 죽어요. 때릴 때마다 우리 편 쪽으로 끌려와요: 기사단 = **구조**, 뿔 군단 = **밀렵**. 손 공격 2점, 자동 1점, 1초에 최대 3번, 덩치 저울 S만큼 곱하기. 화면에 줄다리기 바가 보여요.
- 60초 뒤 점수가 많은 편 승리:
  - 이긴 기사단 = **경험치 위주**, 이긴 뿔 군단 = **골드 위주** 보상 (내 레벨에서 사냥 10분어치).
  - 진 편 = 40% + **응원별 1개**. 무승부면 둘 다 진 편 보상. 서버에 상대 편이 한 명도 없으면 겨룰 상대가 없으니 무조건 무승부예요.
  - 응원별 5개를 모으면 다음 황금 보상은 **무조건 희귀** (응원별 소모).
  - **희귀** = 보상 ×5 + 큰 축하 알림.
  - 이긴 편은 왕관 쟁탈전 점수 +60.

## 8. 퀘스트: 일일 퀘스트 & 휴가 보너스

**"굳이 안 해도 되는데, 하면 좋은 것"** 이 목표예요.

- 화면 왼쪽에 퀘스트 3칸. 매일 **한국 시간 자정**에 3칸이 모두 금색 **"일일"** 퀘스트로 바뀌어요.
- 종류: 몬스터 처치, 수동 스킬 사용, 황금 거위 참여, 골드 벌기, 황금 몬스터, 현상수배범 잡기(기사단) / 기사단 털기(뿔 군단). 스킬 퀘스트는 충전량 조건 없이 서버가 인정한 사용 횟수로 진행해요. PvP 퀘스트는 새싹이 아닐 때만, 한 번에 하나만.
- 진행은 자동, 다 되면 **받기**만 누르면 돼요 (일일 하나 ≈ 내 레벨에서 사냥 5분어치).
- 몬스터 처치 퀘스트는 "고블린 30마리 쓰러뜨리기"처럼 내 레벨 지역의 몬스터 이름이 붙어요. 더 약한 몬스터를 잡으면 경험치 비율만큼만(예: 0.4마리) 올라가서, 화면에 0.4/1처럼 소수로 보여요.
- 3개를 다 받으면 **보너스 상자** (사냥 10분어치 + 10% 확률로 **직업 변경권**). 다 해 두고 못 받은 일일은 자정에 자동으로 받아지고, 그걸로 3개가 채워지면 상자도 같이 받아요.
- 받은 칸은 끝없이 이어지는 회색 **"추가"** 퀘스트가 돼요 (보상은 작고 자동 지급).
- 받지 않고 둔 보상은 **받는 순간의 레벨** 기준을 넘지 않아요 (직업 무료 변경이나 환생으로 레벨이 내려간 뒤 받으면 그만큼 줄어요).
- **휴가 보너스:** 하루 이상 못 왔다면, 못 온 날 하루마다(최대 3일) **하루치 전체 보상(일일 3개 + 상자)의 70%** 를 지금 레벨 기준으로 계산해서, 접속하면 팝업으로 **받기**. 일일을 일부만 한 날도 못 한 만큼은 휴가로 쳐 줘요 (예: 1개만 한 날은 남은 몫이 휴가로 쌓여요). 직접 하면 100%, 쉬면 70% → 하는 게 항상 조금 더 좋아요.

## 9. 전향 환생

- **조건:** Lv 50 (2번째부터 +5씩, 최대 100). 현상수배 별·원한 자루·괴수·전투 중이면 안 돼요. 깡패 단계가 남아 있으면 장인 길드로는 환생할 수 없어요.
- **초기화:** 레벨만(2026-10-05 사용자 변경, A23-14). **유지:** 골드, 무기(전설 포함)와 무기별 강화, 아이템·재료, 직업, 명예·악명(둘 다), 환생 보너스, 표식, 변경권. 무기는 정식 때 경매장에서 다른 유저에게 팔 수 있게 할 예정이에요.
- 환생 화면에 큰 버튼 세 개 **[빛의 기사단] [뿔 군단] [장인 길드]** 와 지금 서버 인원 비율이 보여요. 다음 생의 편을 골라요 (항상 무료, 변경권 필요 없음).
- 영구 보너스(골드·경험치)는 환생마다 **+25%**, 나를 뺀 서버 인원 중 **45% 미만인 편**을 고르면 **+40%**. 이 인원에는 새싹과 2분 넘게 잠수 중인 사람을 세지 않아요 (Lv1 부계정으로 +40%를 만들지 못하게). 장인 길드로 가면 항상 +25%. 보너스는 계속 더해져요.
- **편을 바꿔서 환생하면 영구 표식** (각 최대 5개):
  - 빛 → 뿔 = **타락**: 골드 +5%씩, 찢어진 검은 망토.
  - 뿔 → 빛 = **구원**: 경험치 +5%씩, 금 간 후광.
  - 둘 다 3개 이상 = 칭호 **"회색 전설"** + 회색 오라.
- 제단에서 편을 바꾸는 건 표식을 주지 않아요. 장인 길드로 가거나 장인 길드에서 오는 환생도 표식이 없어요.
- 환생 1/3/5/10회에 오라 색깔이 바뀌어요.

## 10. 변경권 (로벅스)

**규칙: 모든 "바꾸기"에는 두 가지 길이 있어요. 진행도를 내놓는 무료 길, 또는 진행도를 지키는 변경권(로벅스).** 능력치도 확률도 없어서 돈으로 강해지는 게 아니에요.

| 바꾸는 것 | 무료 | 변경권 1장 (로벅스, 소모형) |
|---|---|---|
| **직업** (메뉴, 안전 지대에서) | 레벨 1·경험치 0부터 다시 (골드·금고·무기·환생 보너스·표식·퀘스트는 그대로) | **직업 변경권** (약 49 R$): 레벨 그대로 |
| **진영** (운명의 제단) | 떠나는 진영의 개인 점수 0 (명예 또는 악명, "배신의 대가") | **진영 변경권** (약 79 R$): 명예·악명 둘 다 그대로 |
| 환생 때 편 고르기 | 항상 무료, 점수 유지 | 필요 없음 |

- 패널에는 두 길이 나란히 보이고, 잃는 것 / 지키는 것, 확인 창, 보유 변경권 수, **[로벅스로 구매]** 버튼이 있어요. 구매하면 "직업 변경권 1장을 받았어요!" 알림.
- 직업 변경권은 일일 보너스 상자에서 10% 확률로도 나와요.
- 한 번 결제된 건 서버가 기록해 두고 저장까지 끝낸 뒤에야 "지급 완료"를 알려요. 같은 결제가 두 번 들어와도 두 번 주지 않아요.

> **출시 후 꼭 할 일 (만든 사람):** 게임을 공개(Publish)한 뒤 create.roblox.com → 내 게임 → 수익 창출(Monetization) → **Developer Products**에서 상품 **2개**(직업 변경권, 진영 변경권)를 만들고, 나온 숫자 ID를 `Config.Products`의 `ClassTicket.Id`, `FactionTicket.Id`에 붙여 넣으세요. ID가 0인 동안은 버튼에 **"상품 준비 중"** 이 뜨고, 스튜디오 출력창에도 안내가 나와요.

## 11. 수동 전투를 돕는 편의 요소

- 몬스터가 **알아서 다가옴** → 찾으러 다닐 필요 없음
- 직업이 달라도 **버튼은 똑같음**. 2026-10-05 사용자 요청으로 **캐릭터가 바라보는 방향으로 공격**해요(전사·마법사·궁수 모두, 따로 조준 버튼 없음). 자동 전투일 때는 알아서 대상 쪽으로 돌아요(A23-12).
- **공격 입력1회에 공격1회**, 스킬은 MP·재사용 시간을 확인하고 직접 사용
- 왼쪽 짧은 클릭은 공격, 드래그는 카메라 회전으로 구분
- 골드/경험치와 **드랍 아이템(재료·주문서·물약·희귀 무기)**은 몬스터가 죽는 순간 **바로 들어옴** → 줍기 없음, 가방 없음. 받은 아이템은 메뉴의 간단한 "아이템" 목록에서 봐요. 바닥에는 반짝 연출만 있어요(A23-12). — **A23-19로 대체(2026-10-05): 가방 창이 생겨요. 땅에서 줍기는 여전히 없어요.**
- **마을 장비 선택**: 원하는 기본 무기 구매·보유 무기 무료 재장착·구매가1/10 판매
- 마을에 들어가면 주머니 골드 **자동 저금**
- 퀘스트는 자동 진행, **받기**만 누르기. 휴가 보너스도 팝업에서 받기 한 번
- **화살표**가 알려 줌: 보라 = 원한 자루 도둑, 빨강 = 괴수, 주황 = 복수 대상
- 누가 적인지 색으로 바로 앎: 노란 후광 = 기사, 빨간 뿔 = 악당, 빨갛게 빛남 = 현상수배범, 빨간 "깡패" 이름표, 청록 '장' 이름표 = 장인 길드(서로 공격 못 함)
- 화면의 공격·스킬·메뉴·물약 조작은 기존 승인 UI를 사용해요. 충전 링은 없어요. 자동 전투 켜기/끄기 버튼은 왕관 조각 퀘스트로 해금한 뒤에만 보여요(구현 예정). 새 스킬 장착 화면은 아직 미구현이에요.

## 13. MVP 범위 vs 나중에 추가할 것

### 첫 플레이 가능 버전 (MVP) — 3단계로 만들기 (아래 전부 MVP에 포함)
**마일스톤 A — 혼자 해도 재밌는 사냥**
- 자동 생성 맵 (6개 지역), 몬스터 6종 + 황금 몬스터
- **직업 3개** (전사·마법사·궁수, 진영별 이름), 직업별 무기 7단계와 모양
- **수동 공격 / MP·재사용 시간 기반 스킬** / 큰 데미지 숫자 / 화면 흔들림
- 레벨·경험치, 저장 (DataStore, 예전 데이터 자동 변환)
- 모바일 우선 공격·스킬·물약 조작, 메뉴 안의 이동·환생·직업 변경
- **체크포인트:** 친구 2~3명에게 시켜 보기. 발사가 시원하지 않으면 효과부터 고치고 넘어가기!

**마일스톤 B — 선과 악**
- 진영 선택 화면 (세계관 3줄), 진영별 특성과 발사 특기, 후광/뿔
- 주머니 골드 vs 금고, **덩치 저울**, **깡패 규칙**, 복수, 새싹·부활 보호
- **원한 돈자루** (유령, 화살표, 120% 되찾기), 현상수배 별, 현상금, 게시판
- **수배범 괴수화** (경보, 3배 괴수, 발 구르기, 보상 나누기)
- 왕관 쟁탈전 게이지 + 축복 + 하늘 변화, 운명의 제단 (무료 / 변경권)

**마일스톤 C — 다시 오게 만들기**
- **황금 거위 줄다리기**, 응원별, **단골 운**
- **일일 퀘스트 + 휴가 보너스**, 추가 퀘스트
- **전향 환생** (+25% / +40%, 타락·구원 표식, 회색 전설), 오라, 칭호
- **변경권 (로벅스)** — 상품 ID는 출시 후 입력
- 콤보 카운터, 효과음, 레벨업 빛기둥, 진영 안내자 대화와 첫 임무 수락

### 나중에 추가할 것 (로드맵)
| 단계 | 추가할 것 |
|---|---|
| v1.1 | 월드 보스 "해골왕" (15분마다, 피해 1% 이상 넣은 사람 모두 보상) · 오프라인 수입 (최대 8시간) |
| v1.2 | **펫과 알**: 번 골드로만 구매, 확률 표시, 기사 전용 "새벽 알" / 악당 전용 "저주받은 알", 도감(회색 실루엣) |
| v1.3 | **금고 털이**: 20초 털기 → 기사들에게 경보 → 45초 도주 · 새 지역 "용의 봉우리" (Lv 60) |
| v1.4 | 서버끼리 합산하는 주간 왕관 쟁탈전 · ~~전체 랭킹~~(**A23-19로 베타로 앞당김**, 베타 기본 기능 BB10; 서버끼리 합산하는 왕관 쟁탈전은 그대로 v1.4) · 진영 마을 꾸미기 |
| 이후 | 길드/파티, 4인 던전, 무법 지대, 한국어/영어 번역, 꾸미기 전용 상점 (오라·이름 색·무기 꼬리 효과), **뽑기 등 캐시 아이템 차차 업데이트**(§10-1, 구성은 그때 사용자 결정) |

## 14. 위험 요소와 해결책

| 위험 | 해결책 |
|---|---|
| 다들 악당만 고름 (애들은 악당을 좋아함) | 덩치 저울(적은 편이 거인), 약한 편 시작 골드 300, 인원수로 나눈 전쟁 점수, 전향 환생 +40%. 숫자는 Config에서 바로 조절 |
| 초보가 털려서 바로 나감 | 새싹 보호, 깡패 규칙, 부활 보호, 원한 돈자루(되찾기 120%), 주머니 골드만 일부 손실 |
| 기사 쪽이 지루함 | 보라 화살표로 도둑 추적, 복수 대행 보너스, 괴수 레이드, 거위 구조, 동료를 살리는 발사 |
| 전투가 반복 클릭만 남음 | 수동 공격·스킬 사용과 사냥 보상·장비 선택·다음 도전의 연결을 실제 플레이로 확인. 억지 반복으로 시간을 채우지 않음 |
| "로벅스 = 돈 내면 이기는 게임" 비판 | 출시 때 파는 건 변경권뿐 (능력치 없음), 무료 길이 항상 있음. 나중 캐시 아이템·뽑기는 §10-1 규칙(확률 공개·나라별 제한·무료 길)으로 |
| 괴수가 너무 세거나 약함 | 체력 배수, 발 구르기, 보상은 모두 Config 숫자. 첫 플레이 테스트에서 바로 조절 |
| 저장이 날아감 / 복사 버그 | 재시도 + 세션 잠금 + 60초 자동 저장 + 서버 종료 시 저장. 결제는 기록 + 저장 후에만 지급 완료 |
| 해킹 (골드 조작, 순간이동 공격) | 모든 계산은 서버가 함. 클라이언트는 "휘둘렀어요/발사했어요"만 보냄. 거리·쿨타임 검사 |
| 혼자 만들기엔 너무 큼 | A → B → C 순서 엄수, 숫자·문구는 Config 한 곳, 펫·보스는 MVP 이후 |
| 악당 테마가 괴롭힘처럼 느껴짐 | 만화 같은 연출, 깡패 규칙, 공개 방송은 좋은 소식 위주, 정해진 문구 위주 |
| 휴대폰에서 버벅임 | 몬스터 수 제한 (총 42마리), 데미지 숫자 최대 25개, 단순한 파트 모델, 몸 크기는 천천히 변함 |
| 그냥 흔한 복제 게임처럼 보임 | 거대 괴수 + 원한 유령 자루 + 황금 거위 줄다리기 + 왕관 색 하늘을 썸네일에 사용 |

## 15. 참고한 로블록스 게임들

| 게임 | 가져온 것 |
|---|---|
| **Blox Fruits** (해적 vs 해군) | 진영별 다른 장점, 현상금/명예 따로 저장, 초보 PvP 잠금, 안전 지대, 현상수배 포스터 |
| **Jailbreak** (경찰 vs 죄수) | 범죄할수록 현상금 증가, 잡으면 현상금 획득, "여러 번 밸런스 패치가 필요하다"는 교훈 |
| **Mad City** (영웅 vs 악당) | 영웅/악당 판타지. "업데이트를 꾸준히 해야 살아남는다"는 교훈 |
| **Pet Simulator 99** | 한 번 탭하면 돈이 오르는 루프, 지역 문, 환생 영구 보너스 (자동 사냥을 유료로 파는 건 따라 하지 않음) |
| **Grow a Garden** | 서버 전체가 바뀌는 이벤트 (하늘 변화), 정해진 시간 이벤트 |
| **Steal a Brainrot** | 훔친 걸 들고 도망치는 재미 → 원한 돈자루. 대신 아이들이 우는 일이 없게 **되찾을 수 있도록** |
| **WoW 워 모드 / 여러 MMORPG** (로블록스 밖) | 인원이 적은 편 보너스, 유저 불만(쏠림·학살·자동사냥·숙제)을 뒤집는 아이디어 |

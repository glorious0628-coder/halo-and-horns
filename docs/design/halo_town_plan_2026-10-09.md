## 시안에서 읽은 것
- 땅은 **바다 위 흰 석회 절벽 섬 여러 개**를 계단식 단으로 쌓은 것. 가운데 큰길(흰 타일 + 금 띠 + 금 메달리온)이 문 → 영웅상 길 → 큰 계단 → 광장 → 대성당으로 올라감. 양옆은 낮은 단·절벽 섬, 섬 사이는 **아치 돌다리**, 다리 밑·절벽 모서리로 **폭포**가 바다로 떨어짐. 멀리 작은 섬 + 등대 탑.
- 건물은 전부 **흰 대리석 + 금 돔·금 띠 + 하늘색 천 깃발**. 후광 링은 탑 꼭대기·문 위에만. 구름은 **흰 솜 덤불**로만(건물 받침 구름 없음). 나무는 둥근 나무 + 뾰족 원뿔 나무(토피어리). 꽃은 하늘색·흰색 화단.

## 새 분수 = FountainFx 이름·자리 (이미지 생성 1, 2026-10-09 밤, 모델 `Halo_Fountain_HD_plain.glb` 측정)
- **이름 계약(검수 10/10 정정):** `FountainFx.luau`는 태그가 아니라 **Model 이름**(`SPECS[inst.Name]`)으로 붙는다. 새 3단 분수의 가져오기 메시 이름 = 키트 Model 이름 = **`Town_Halo_Fountain3`**(FountainFx에 이미 이 키가 있음). **`Town_Halo_Fountain`은 교차로 광장의 구름 분수 이름이라 절대 쓰지 않고 --replace도 하지 않는다**(A23-96). 피벗 = 밑면 가운데, 크기 16×16×12.85(폭×폭×높이). 배치 도구 `halo_props.luau`가 이 이름으로 Map.Decor.HaloProps 안에 둔다.
- **SPECS 숫자는 새 모양에 맞게 고쳐야 한다(개발 1, `Town_Halo_Fountain3` 항목 — 3단, 후광 고리 없음):** 새 분수는 3단 수반 + 후광 고리 없음(`Halo` 줄 지움). 높이 비율 Y, 반지름 비율 R(폭 16 기준, 중심에서):
  - 바닥 물웅덩이: `Pool = { Y = 0.165, R = 0.45 }` (물 표면 y≈2.1, 돌 테두리 안쪽 반지름 0.455, 모서리 금공 기둥 윗면 y≈0.35)
  - 가운데 큰 수반: 물 표면 y≈0.53, 테두리 반지름 ≈0.25(테두리 위 y≈0.55)
  - 위 작은 수반: 물 표면 y≈0.75, 테두리 반지름 ≈0.15(테두리 위 y≈0.77)
  - 맨 위 금 구슬 y≈0.80~0.90, 끝 뾰족 y 1.0 → `Jet = { Y = 0.80, Up = 8 }`
  - 물줄기(시안: 위 수반에서 4개 → 가운데 수반, 가운데 수반 가장자리 4개 → 웅덩이): `Curtains = { {FromY=0.76,FromR=0.145,ToY=0.54,ToR=0.19,Count=8,Width=1.6}, {FromY=0.55,FromR=0.25,ToY=0.17,ToR=0.31,Count=12,Width=2.2,Ripples=true} }` (첫 추정, 모델이 들어간 뒤 사진으로 다듬기)

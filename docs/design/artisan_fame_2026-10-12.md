# ⑦ 장인 명성·계급 (게임성 개발 3, 2026-10-12, 설계안 — 게임성 검수 판단 전)

근거: GDD 장인 명성(A23-24: 주간 "장인 명성" = 직접 사냥한 주문서 강화 성공 칸, 1~3위 보상 = 명예·악명 1~3위와 같음; "제작 점수도 같은 장인 명성에 더해져요"), A23-135(랭킹은 종류별 — 장인 명성 판 따로), `save_v4_tables`(Craft.Rep = 평생 장인 점수, 계급 5단계; 주간 판은 이미 `Rank.Artisan`), A23-139(제작 XP는 그 역할 장인만), 현금 규칙(능력치 안 팜).

## 1. 명성 얻기 (CraftService.complete, 제작 XP와 같은 조건 = 지금 그 역할 장인)
- 한 번 만들 때 명성 = 레시피 제작 Lv 띠: Lv 1~9 → 1, 10~19 → 2, 20~29 → 3, 30 → 4, **+2(망치질 완벽)면 +1**. (W1 = 1, 간식 T1 = 1~2, G3·R3 = 3~4, W9 = 4~5)
- 두 곳에 더함: `Craft.Rep`(평생, 상한 MaxCount) + `RankingService.Credit(player, "Artisan", fame, "Craft")`(주간 판, 기존 주간 상한 60·중립만·개인 서버 안 셈 그대로).
- 2배 XP 패스는 명성에 안 들음(XP만, A23-139). CraftResult에 `Fame` 더함(화면이 '+N 명성' 보여 줌, 따로 알림 없음).

## 2. 계급 5단계 (평생 Rep)
| 계급 | Rep | 이름 |
|---|---|---|
| 1 | 0 | Apprentice |
| 2 | 30 | Journeyman |
| 3 | 150 | Artisan |
| 4 | 500 | Master |
| 5 | 1500 | Grandmaster |
- 속성 `ArtisanRank`(1..5, 장인 아니면 0) — 모두에게 보임(이름표·랭킹 창 배지는 클라 몫). 들어올 때·바뀔 때.
- 오르면 알림 키 1번(`Config.Craft.Text.RankUp`, args: 계급 이름 키) + 신호 `RankUp(player, rank)`.
- **계급 혜택 = 보이는 것만**(이름·배지). 능력치·할인 없음(베타). 나중에 칭호·꾸미기는 검수 판단.
- CraftInfo에 `Rep`, `Rank`, `NextRep`(다음 계급까지, 끝이면 0).
- 편 바꾸기·직업 바꾸기: Rep·계급은 남음(평생), 주간 판은 A23-24대로 RankingService가 정리.

## 3. 시험
test_craft에 묶음 추가: 띠별 명성·+2 보너스·장인만(편 바꾼 뒤 남은 제작은 명성 없음)·패스 무관·Rep 상한·주간 Credit 호출(대역)·계급 경계(29/30, 149/150 …)·속성·알림·CraftInfo. 변이 하나씩.

## 4. 판단 부탁(게임성 검수)
① 명성 띠(1/2/3/4 + 완벽 +1) ② 계급 문턱 30/150/500/1500 ③ 혜택 없음(보이는 것만) ④ 주간 판 상한 60을 그대로 둘지(제작이 더해지면 금방 참 — 예: 100으로).

# 스킬·무기·펫 설계 (2026-10-05, 검토 세션)

- **근거:** 웹 조사(World // Zero, Blox Fruits, Swordburst, Pet Simulator 99, Adopt Me, MapleStory 등)와 레포 코드를 읽고 시스템마다 설계했다. 각 설계는 반박 검토로 고쳤다.
- **원문:** `docs/design/skills_weapons_pets_2026-10-05.json`(조사 결과·설계·검토 지적 전부).
- **사용자 결정:** SPEC A23-13~A23-15. 베타에 넷 다 넣는다(무기 등급, 아기 슬라임 펫, 직업 Z 스킬, 핼러윈 몬스터). 새 스킬 PvP는 3초 35% 공동 한도, 펫 속도는 언제나 켜짐, 알 둥지는 골드 랜덤 알(확률 표시), 좋은 아이템·펫은 전체 채팅으로 알린다.
- 창작 세부(이름·모양·능력)는 세션들이 정했다. 그림은 Firefly 시안 승인이 필요하고, Tripo는 총액을 먼저 묻는다.

## 0. 공통 — 먼저 만들 것
1. **속도 한 곳(computeWalkSpeed):**
   - `PlayerService.applyStats`가 기본 20 × 직업(궁수 1.1) × (1 + 펫) × 스킬 버프를 한 번에 계산한다. 전체 상한은 ×1.35이고 서버만 정한다.
   - 다시 계산할 때: 장착·해제, 펫 레벨, 지역, 괴수 상태, InCombatUntil 만료(타이머), SackGold 변경.
   - 펫 속도는 언제나 켜진다(A23-15). 다만 괴수 변신 중에는 기존 괴수 속도 규칙을 따른다.
   - 이동 감시(ZoneService.checkMove, MoveMult 1.6 + Slack 8)가 최대 속도에서도 오탐하지 않는지 오프라인 테스트로 확인한다.
2. **스킬 피해 한도(슬라이딩 창) 모듈:**
   - 공격자→피해자 쌍마다 `{시각, 양}` 목록을 둔다. 허용량 = 35% × 피해자 MaxHP − 최근 3초 합계(활성 괴수는 8%).
   - 빛 치유는 동료 1명당 30%/3초, 뿔 흡수는 3%/3초로 같은 모듈을 쓴다.
   - 지금 Q의 시전당 상한을 이 창으로 바꾼다.
3. **좋은 것 전체 채팅 알림:**
   - 서버가 모두에게 `{Key, Args, Grade}`를 보내고, 클라이언트가 `TextChatService` 시스템 메시지로 RBXGeneral에 표시한다. 등급 색을 입히고, 이름은 게임 닉네임을 쓴다.
   - 대상: 희귀 이상 무기, 전설·대박, 펫 획득, 처음 +10(사람당 1번).
   - 같은 사람은 10초 안의 알림을 묶는다. 토스트를 함께 띄울 때는 오프닝·선택 화면·첫 임무 전에는 미룬다(UIKit 큐).
4. **NPC·상점 일반화:** `ensurePotionMerchant`를 `ensureShopNpc(def)`로, `BUILDERS.PotionShop`을 목록형 상점 빌더로 일반화한다. 스킬 선생님·펫 둥지·물약 상인이 데이터만으로 생긴다(Panels 200 local 한도에도 안전).

## 1. 무기 — 베타 (약 1.5일)
- **B0 저장 안전(먼저):**
  - DataService: 장착 티어가 범위 밖이거나 정수가 아니면 1로 바꾼다(지금은 8로 잘려 전설이 된다). 보유 비트는 리셋 대신 `band`로 처리한다.
  - LootService.sanitize: 범위 밖 강화 칸을 보존한다.
  - 상점 판매 목록을 `Config.WeaponShop.Tiers = {2,3}`으로 명시한다.
  - `WeaponTier >= 3` 같은 순서 비교는 헬퍼(`WeaponIsShop`, `WeaponAtLeast`, 피해 비교)로 바꾼다. 대상: QuestService 411, StoryQuestService 133, Fx 1788, CharacterVisuals 466/549/558.
  - `Config.Weapons`에 "인덱스 = 저장 키, 뒤에 붙이기만" 주석을 단다. 아직 없는 무기 줄(stub)은 넣지 않는다.
- **B1 등급·별:**
  - 일반(흰)·고급(초록)·희귀(파랑)·영웅(보라)·전설(주황). 색은 ART_DIRECTION:56 기존 색을 쓴다.
  - 별 1~5는 "희귀도"이고 세기가 아니다. 목록에는 "가장 센 무기" 표시와 "고블린 5방 → 2방"을 보여 준다.
- **B2 표시 위치:** 아이템 목록, 대장간 줄, 드랍 팝업, 전체 채팅 알림.
- **B3 이름:**
  - T4 숲도둑 황금 검/지팡이/활, T5 옛 왕국 수정 …, T6 수호령 …(몬스터 이름에서 온 이야기).
  - T8 젤리 왕관(피해 76, A23-12 수정). T7 진영 무기(여명·파멸·왕관 조각)는 정식 제작.
  - 영어 이름 표도 둔다.
- **B4 얻는 곳 한 줄:** 각 무기에 "어디서 나와요"를 글자로 넣는다. 예: "고블린·고블린 우두머리가 드물게".
- **정식:** 진영 무기 제작(해골왕 재료 + 장인; 계급 조건은 제작할 때만 확인), 운 나쁠 때 보장(기운 %), 말랑 방울·잠든 왕 같은 새 계열, Firefly 아이콘·3D 36개(총액 먼저), 강화 단계 빛(시안 승인).
- **경매장(정식, A23-13/14):** 무기를 다른 유저에게 판다. 보스 재료나 퀘스트 보상처럼 묶어 둘 것만 `Bound`로 표시한다.

## 2. 아기 슬라임 펫 — 베타 (약 2~3일)
- **얻기:** 이야기 서브 P1 "길 잃은 아기 슬라임".
  - **M1_1 뒤(약 5분)**에 연다. 첫 10분 안에 귀여운 순간이 오도록, 서브 줄에서 S0처럼 순위 2를 준다.
  - 단계: 초원 슬라임 8마리 → 선택 [보살펴요](명예 +1) / [내 졸개로 삼아요](악명 +1). 장인 길드는 기록만 한다.
  - 둘 다 같은 펫을 받는다. 이름표에 선택이 보인다("아기 슬라임 · 착한 친구" / "아기 슬라임 · 장난꾸러기 졸개").
- **능력:** 이동 속도 +7%(펫 Lv1) → +10%(펫 Lv10). 펫 경험치는 처치로 오르고(자동 킬 포함), 다음 레벨까지 15 × 레벨 킬이다.
- **저장(정식 경매·입양 대비):**
  - `Pets.List[uid] = {Sp, Lv, XP, Name, Lean, Bound}`, `Pets.Equipped = {uid}`. 퀘스트 펫은 `Bound`.
  - 펫 목록은 본인 전용 원격으로 보낸다. 다른 클라이언트에는 `EquippedPet`·`PetLv`·`PetForm`만 속성으로 보낸다.
  - DataLoaded 때 "P1 완료인데 펫이 없으면 지급"을 넣는다. S0 → 자동 전투도 같은 방식으로 따라잡는다.
- **따라다니기(클라이언트):**
  - 지금 슬라임 3D를 0.35배로 쓴다. 두께 보정과 깡충·눌림 움직임은 작은 공용 모듈로 만든다(Fx·HUD local 한도 때문).
  - 15Hz로 땅에 내려 붙인다. 다른 사람의 펫도 보인다.
- **화면:** 메뉴 → 아이템 맨 위에 펫 줄(장착·숨기기)을 둔다.
- **정식:**
  - 몬스터 드랍 알, 진영 알(새벽 알·저주받은 알, 계급 2), 12종과 도감, 별, Lv10 진화 모습(천사·악마·균형; 힘은 같음)
  - **골드 랜덤 알 둥지**(A23-15): 확률표 합 100%, 중복은 별, 둥지에서 산 알만 중복 골드 30%
  - 펫 훈련사(장인 길드 궁수 대체, 기존 사냥꾼 무료 변경), 입양·경매(A23-13)
- **펫 능력 종류(정식):** 속도·몬스터 피해·골드·경험치·MP 회복. PvP 피해와 덩치 저울에는 절대 들어가지 않는다. 행운·드랍 펫은 없다(대박·주문서 확률 보호).

## 3. 직업 Z 스킬 — 베타 (약 5~6일, 기능 플래그로 숨겨 두고 10/20에 켤지 결정)
- **배우기:**
  - 교차로 "스킬 선생님"(임시 기본 NPC)에게 **Lv5, 100골드**로 배운다.
  - 이야기 서브로 안내한다: 선생님 만나기 → 배우기 → "Z로 한 번에 슬라임 2마리".
  - 배운 스킬만 버튼이 생긴다(잠금 예고 없음). 환생·직업 변경 후에도 배운 스킬은 남는다.
- **직업별 Z(대표 스킬):** 검토 반영으로 Lv5~10 구간에서 쓰는 맛이 나게 했다.
  - **전사 "대지 가르기":** 앞으로 22×10 띠, x7.5, MP25, CD6. 맞은 몬스터를 내 쪽으로 살짝 끌어온다(몬스터만).
  - **마법사 "마력 사슬":** 가장 가까운 겨냥 대상 → 10stud 안에서 3~4번 튀는 번개, 각 x5, MP25, CD5. 대상이 없으면 MP를 쓰기 전에 거절한다.
  - **궁수 "꿰뚫는 화살":** 일직선 관통, MP25, CD5.
  - 진영별 이름과 색: 예) 빛의 가르기 / 분노의 가르기 / 망치 가르기. 빛 치유·뿔 흡수가 그대로 붙고, 한도는 §0-2를 따른다.
- **조준:** 서버가 겨냥 원뿔(직업 AimCone)과 사거리 안에서 가장 가까운 대상을 골라 방향을 정한다. 대상이 없으면 LookVector를 쓴다. 클라이언트 회전 복제에 의존하지 않는다.
- **실행:**
  - `CombatService.Release`를 `castSkill(player, def, isAuto)`로 일반화하고, 슬롯마다 쿨다운을 둔다.
  - 스킬 사이 공동 0.5초 간격 안에 누르면 한 번 줄 세운다. 버려지는 입력은 폰에서 고장처럼 느껴지기 때문이다.
  - `Release` 원격은 Q 별칭으로 같은 검사를 거친다. `UseSkill(slot)`·`LearnSkill(id)`는 호출 간격 제한과 검증을 둔다.
  - UseSkill도 lastManualAt을 갱신한다. 그래야 자동이 수동을 덮지 않는다.
- **자동 전투:** 배운 슬롯 Q→Z 순서로, 모양 안에 몬스터가 있을 때만 쓴다. 효과는 조용하게(흔들림 없음, 입자 ≤15, 보내는 반경 작게). 스킬 퀘스트·거위·괴수 공헌에는 세지 않는다.
- **PvP:** A23-15 슬라이딩 창(3초 35%)을 적용한다. 느리게·끌어오기는 몬스터만 한다.
- **화면:**
  - Z 버튼은 승인된 BtnSpecial + 글자, MP·쿨다운을 표시한다. PC Z키, 게임패드 L1.
  - `HUD.Layout.SkillSlots` 기준점을 하나 만들어, HUD 재디자인 때 한꺼번에 옮긴다.
- **정식:** X 스킬(전사 수호 함성·마법사 느림 마법진·궁수 바람 걸음), 스킬 교체 화면, 희귀 스킬북 드랍, 실패 없는 스킬 레벨업, Firefly 아이콘. 전직(약 Lv30)과 필살기(MP + 긴 쿨다운, 충전 게이지 아님)는 나중이다.

## 4. 핼러윈 몬스터 — 베타 (Tripo 유료: 총액 먼저)
- 세션 제안(사용자는 그림·총액만 승인):
  - **호박 슬라임:** 말랑 초원, 핼러윈 기간 슬라임 대신 일부 등장
  - **꼬마 유령:** 고블린 숲 밤 분위기, 귀엽게, 무섭지 않게
  - **박쥐 고블린:** 숲, 날개 달린 고블린
  - 모두 아이 안전 디자인이다(피·해골 공포 없음).
- 기존 방식으로 만든다: Tripo 3D → 리깅 + 동작 5개 → 데이터 재생. 드랍은 기존 무기 계열 줄과 사탕 재료(판매용)를 쓰고, 새 무기 줄은 만들지 않는다.
- 시즌이 끝나면 꺼지는 설정 플래그를 둔다. 매년 돌아오고, 한정 압박 문구는 쓰지 않는다.
- 순서: Firefly 시안 3장 승인 → Tripo 총액 안내·승인 → 제작.

# 세계 스타일 규칙 — "우리 게임만의 모양" (이미지 생성 1, 2026-10-06)

> 검수 메모(10/11): '공통 표시'·종족별 모양 규칙은 그대로 맞음. 만드는 **순서**는 낡음 — 지금은 Tripo HD H3.1 멀티뷰 앞·뒤·좌·우 4장 → Blender 손보기(필수) → Roblox 재질 손보기(A23-122·A23-125); 건물 몸통·벽·바닥·계단은 Studio 파트 골격(A23-120), Tripo는 장식·식물·조각·몬스터·NPC만. 빛 마을은 처음부터 다시(A23-121).

사용자 피드백: "지금은 어디서 많이 본 것 같고 통일감만 있어." → 흔한 무료 소품처럼 보이지 않게, 모든 건물·광장에 **우리 표시**를 하나 이상 넣는다. 순서(A23-47이 대체): **장면 2D 시안 → 검수 100% → 사용자 → 시안 속 물건 하나씩 2D → 누끼 → Tripo(중요 건물 multiview) → Blender 정면 렌더로 시안 비교 → WorldKit → 메인**. 무료 에셋은 바닥 덮개만. 앞서 만든 무료 3D 20종(`art/models/worldkit/manifest.json` towns 임시)은 배치 연습·크기 잡기용으로만 둔다.

## 공통 표시 (모든 건물)
1. **왕관 조각 크리스털** — 게임 이야기의 중심(부서진 균형의 왕관). 지붕·간판·문 위에 박혀 빛난다. 빛 = 금빛, 뿔 = 호박색(앰버), 중립 = 청록 빛.
2. **장난감 비율** — 문·창·지붕을 과장되게 크고 둥글게, 벽은 살짝 기울어진 만화 집. 반듯한 직선의 현실 집은 쓰지 않는다.
3. **글자 없음** — 간판은 입체 그림(빵·물약병·모루·주스컵). 이름은 가까이서만 작은 이름표(A23-36, TextLabel).

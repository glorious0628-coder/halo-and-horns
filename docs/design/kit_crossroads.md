# 교차로 키트 목록 (A23-47, 이미지 생성 1 초안 2026-10-06)

순서(A23-47): 장면 2D 시안(~~`art/prompts/Scene_Crossroads.txt` 한 장~~ → 시안 묶음 = 전체 1 + 부분 5, 모두 고급, A23-93; 검수 → 사용자) → 시안 속 물건을 **한 장에 하나씩** 2D(3/4 앞모습, 전체가 그림 안, 단색 회색 배경, 글자 없음, 시안과 같은 색·모양) → 누끼 → Tripo(~~중요 건물 multiview~~ → 큰 건물·랜드마크는 앞·옆·뒤 2D 멀티뷰 먼저, A23-80) → Blender 정면 렌더로 시안과 비교 → WorldKit 크기·색 → ~~게임성 개발 1이~~ 메인 반영 1이 메인(10/08부터). 무료 에셋은 바닥 덮개(풀·자갈)만. 교차로는 ③번째 구역이라 빛·뿔 마을이 끝난 뒤 배치한다(A23-97).
지금 WorldKit 교차로에 놓인 무료 생성 21종(`art/models/worldkit/manifest.json` crossroads)은 **자리 표시**다 — Tripo판이 오면 같은 자리·크기로 바꾼다. (→ 10/08 메인에서 Tripo판으로 바꿈: `crossroads_3d_swap_2026-10-07.md`, 48da94fc. 이제는 교차로 차례(③)에 시안 묶음대로 다시 배치하고, 색만 바꾼·빌린 것은 새로 만든다: `remake_list_2026-10-09.md` ③)

담당: **큰 것 = 이미지 생성 1**(건물·성벽·문·스폰 단상·랜드마크·큰 나무), **작은 것 = 이미지 생성 2**(통·상자·등불·간판·노점·벤치·화분·수레 등). 크기는 스터드(높이 기준), 개수는 교차로 전체.
면 수 한도(A23-47): 건물 ≤ 1만, 소품 ≤ 3천, 바닥 덮개 ≤ 5백. 작은 장식은 CanCollide·CanQuery·CanTouch false, 작은 것 CastShadow false.
※ 시안이 정해지면 '시안 속 모양' 칸을 시안에 맞춰 고친다(지금은 세계 스타일 규칙 `world_style_rules_2026-10-06.md` 기준 초안).

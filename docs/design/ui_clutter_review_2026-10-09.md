# UI·퀘스트 난잡함 점검 — "너무 친절하지도, 너무 불친절하지도" (검수, 2026-10-09)

사용자: "우리 UI나 퀘스트 진행할 때 난잡한 점은 없는지, 나는 너무 친절하지도 않고 너무 불친절하지도 않은 게임성이면 좋겠거든?"
근거 사진: 메인 Studio Play 2026-10-09 09:00(`docs/art/verification_2026-10-09/main_checklist_0900/{pc,phone}/` 05_hud·05a_guide_window·07_reward_popup·09a_story_pop·10_*). 세상은 하얗게 찍혔지만 HUD는 그대로 보임.

## 기준 (이 게임의 '적당히 친절')
1. **목표 하나, 가리키는 것 하나:** 지금 할 일은 퀘스트 줄 1줄 + 3D 길 표시 1개로만 알려 준다.
2. **필요해질 때 보여 준다:** 아직 쓸 일이 없는 칸은 처음부터 띄우지 않는다.
3. **막혔을 때 돕는다:** 힌트는 처음부터 띄우지 않고, 진행이 없을 때(약 45초) 한 번 띄운다. 한 번 해내면 다시 안 띄운다.
4. **아이가 아는 말:** 줄임말·숫자만 있는 칸은 그림 + 쉬운 말로 바꾼다.
5. **알림은 한 번에 하나, 3초.**

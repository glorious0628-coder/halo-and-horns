# 빛 마을 처음부터 다시 (SPEC A23-121, 사용자 2026-10-11)

사용자: "빛 마을 대충하지 말구, 처음부터 다시 한다고 생각하면 돼. 처음부터 다시 구역잡고, 건물들 스튜디오용에서 하고, 그 다음에 그 위에 입히는 거야. 오키?"

## 원칙
- **메인의 빛 마을은 새 마을이 다 될 때까지 그대로 둔다**(화면이 비지 않게). 중간 조각 적용(4차 적용: 대성당 v2·성문 v3·탑·구름 덤불 빼기 등)은 **멈춘다**. 새 마을은 마지막에 한 번에 바꾼다.
- 단계마다 검수가 먼저 본다. ★ 표시는 사용자에게도 보여 주고 OK를 받는 단계다.
- 그대로 지키는 규칙:
  - A23-112: 빛 마을은 비대칭이다.
  - A23-117: 모든 것은 그 자리에 있는 이유가 있고, 구획(상점가·사는 동네 …)을 나눈다.
  - A23-106·A23-120: 모든 건물은 진짜 문(땅 높이, 사람보다 큼)과 빈 속을 갖는다. 실내는 추후 업데이트.
  - A23-120: Studio 골격 → 타일·금 입히기 → Tripo 장식 순서로 만든다. 성은 돔 없이, 다른 돔은 예쁜 곳만.
  - 빛살 무늬는 쓰지 않는다.
  - `acnh_halo_layout_rules_2026-10-10.md`의 12규칙을 따른다(포장 ≤35%, 거울 쌍 0, 층층 지형, 갈래길, 구역별 꽃, 작은 장면, 사진 자리 …).
- **이미 있는 것은 재료로만 쓴다.**
  - 승인된 2D(집 12·가게 4 앞면, 대성당, 성문, 소품)는 건물 디자인 참고로 쓸 수 있다. 자리와 크기는 새 구역 계획이 정한다.
  - Tripo 조각(문짝, 지붕, 차양, 등불, 식물)은 5단계 입히기에서 다시 쓴다.
  - 옛 plan json(`halo_layout_plan_2026-10-10.json`)은 참고만 하고, 새 계획은 새 파일로 만든다.

## 단계
1. **이야기와 구역 — 이미지 생성 1, 검수 함께**
   - 마을 이야기: 누가 살고, 어디로 들어와 무엇을 하는가. 새 플레이어 첫 10분 동선이 기준이다: 도착 → 길잡이 → 물약 가게 → 훈련장 → 교차로로 나가는 길.
   - 구역과 이유를 정한다.
     - 구역: 들어오는 곳·광장, 상점가, 사는 동네(2~3곳), 대성당 구역, 기사단 성 + 훈련장, 정원·쉼터, 전망대 등.
     - 구역마다 높이(층층 섬)와 꽃 종류·색을 정한다.
   - 길을 정한다: 큰 길 하나 + 갈래길, 다리, 높이 차(계단·경사), 경치가 열리는 곳, 사진 자리.
   - **게임 고정점**(스폰, NPC 자리, 퀘스트 목표, 교차로 출구, 구역 경계, 미니맵)은 검수가 코드에서 뽑은 목록(이 문서 맨 아래)대로 둔다. 옮겨야 하면 "옮길 것 + Config 고칠 곳" 목록을 만든다.
   - 결과물 ★: 위에서 본 구역 지도(깔끔한 그림), 구역별 한 줄 이유, 건물 목록(종류·바닥 크기·층·문 방향). 새 파일은 `docs/design/halo_plan_v2_2026-10-11.json`.
2. **새 마을 그림 — 이미지 생성 2**
   - 1단계 지도대로 마을 전체 조감 시안 1~2장(Medium 후보 → 고른 것 High) ★.
   - 새 종류의 건물이 생기면 그 2D 앞면을 그린다(성은 성당 조사 방향).
3. **회색 상자(블록아웃) — 이미지 생성 1**
   - WorldKit에 섬·지형·길·다리를 만든다.
   - 모든 건물은 회색 골격 덩어리로 놓는다(문 구멍 포함, 실제 크기).
   - 사진 ★: 들어오는 곳 눈높이, 광장, 각 구역, 위에서. 아바타 크기 대비로 걸어 보고 길 폭, 계단, 막힌 곳을 확인한다.
4. **건물 골격 — 이미지 생성 3**
   - 건물마다 2D 앞면의 비율대로 Studio 파트 골격을 짓는다: 벽, 층, 창(아치), 문, 띠, 기둥, 받침, 계단.
   - 대리석·금 MaterialVariant는 이미지 개발이 만든다.
   - **집 07 골격 시험 통과가 기준이다:** 15칸에서 2D와 같은 집으로 읽히고, 5칸에서 옛 Tripo판보다 선명해야 한다.
5. **입히기 — 이미지 생성 3·1**
   - Tripo 조각(지붕, 문짝, 차양, 등불, 조각, 메달)을 붙인다.
   - 이유 있는 소품, 꽃 덤불·생울타리·나무, 등불(LampLight), 폭포(halo_waterfx)를 놓는다.
   - 사진 ★: 3단계와 같은 자리에서 찍어 비교한다.
6. **메인에 한 번에 — 메인 반영 1**
   - 옛 빛 마을을 보관 폴더로 옮기고 새 마을을 넣는다.
   - Play 사진(PC)을 찍는다. 고정점(스폰·NPC·퀘스트 표시)이 다 맞는지 시험한다.
   - 검수가 본 뒤 사용자가 플레이한다.

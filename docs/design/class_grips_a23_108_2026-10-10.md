# A23-108 직업·진영별 무기 쥐는 법·몸짓 설계 (게임성 개발 1, 2026-10-10)

근거: SPEC A23-108(사용자 10/10 "직업별로 무기 쥐는 법 이런 것도 다 해야 된다"). 9개(3직업 × 3진영)를 **같은 품질**로. 몸짓은 업로드 없는 **코드 몸짓**(Motor6D Transform, 지금 Fx.luau `MOTION.CLIPS`와 같은 방식)부터. 무기 모델은 재제작 P3(Tripo, A23-107)과 함께 — 이 문서는 모델이 바뀌어도 그대로 쓰는 **손 자리·자세·몸짓 규칙**이다.

## 1. 지금 (코드 기준)
- **쥐는 곳:** 서버 `CharacterVisuals.buildWeapon` — 활만 왼손(LeftGripAttachment), 나머지는 오른손. 무기는 코드 도형(검: 손잡이·가드·날 / 지팡이: 자루·고리·빛 구슬 / 활: 호 5조각 + 빔 시위 / 조련사: 지휘봉). **진영 차이 = 색만**(`Config.WeaponColor`). 중립 대장장이는 검, 연금술사는 지팡이를 그대로 든다(스킬은 망치·물약인데 손엔 없음).
- **서기·걷기:** Roblox 기본 걷기·서기 애니메이션 그대로 — 무기를 든 자세가 따로 없다(검이 팔 따라 덜렁).
- **기본 공격:** `MOTION.CLASS_CLIPS` 3종(WarriorSwing / MageSwing / ArcherSwing, Release = Q 같은 3종) + 활은 팔 두 마디 계산(`Feel.solveArm`)으로 시위 당김. **진영마다 같은 몸짓.**
- **스킬(Z·X):** 공격 몸짓을 그대로 다시 씀(슬롯마다 몸짓 없음). Z·X는 10/20까지 꺼져 있음(A23-86).
- **자동 전투:** 같은 Fx 꾸러미라 같은 몸짓(좋음 — 그대로 둠).

## 2. 원칙
1. **뼈대 3개, 성격 9개:** 무기 종류(검·지팡이·활)가 손 자리와 큰 동작을 정하고, 진영이 **성격**을 정한다 — 빛 = 바르고 단정(방패 팔, 곧은 선, 위에서 아래로), 뿔 = 크고 거침(두 손, 낮은 자세, 옆으로 휘두름), 중립 = 장인의 도구(망치·플라스크·지휘봉 — 무기 자체가 다르다).
2. **중립 3직업은 손에 든 것부터 바꾼다:** 대장장이 = 망치, 연금술사 = 플라스크(왼손) + 짧은 막대(오른손), 조련사 = 지휘봉(지금처럼). 스킬 이름(Hammer Quake·Potion Bomb)과 손에 든 게 맞아야 한다.
3. **한 몸짓 길이 ≤ 그 직업 SwingInterval × 0.9**(지금 규칙 `SWING_FIT`), 키 사이 180° 미만(slerp), 손이 무기 축을 벗어나지 않게(지금 활 계산처럼 손 자리를 실제 팔 길이로 확인).
4. **아이 친화·빛살 금지:** 피·찌르기 강조 없음, 효과는 둥근 빛·반짝이·연기(AGENTS).
5. **폰:** 몸짓은 가까운 12명만(지금 `PROC_MAX_CHARS`), 서기 자세 레이어는 계산이 가벼운 고정 오프셋(트윈 없음).

## 4. 구현 (개발 1, 순서대로 — 각 단계 시험 + 메인 Play 사진)
1. **Config 표 하나** `Config.ClassGrips[직업키]`(직업키 = `Warrior_Halo` … `Archer_Neutral`): `Weapon`(Sword / GreatSword / Hammer / Staff / CrookStaff / Flask / Bow / ShortBow / Baton), `Hand`(R / L / Both), `Grip`(손 기준 위치·각도), `Hold`(서기 자세 관절 각도), `Walk`(걷기 때 보정), `Swing`·`Release`·`Skill.Z`·`Skill.X`(클립 이름). 진영이 없거나 None이면 지금 3종으로 떨어짐(옛 저장·시험 안전).
2. **쥐는 곳(서버 제안 → 개발 3 검증):** `CharacterVisuals.buildWeapon`이 `ClassGrips`의 `Weapon`·`Grip`을 읽게(망치·플라스크·대검·짧은 활 도형은 지금 코드 도형으로 임시 — P3 모델이 오면 교체). 두 손 무기는 오른손에 붙이고 왼손은 클라 몸짓이 자루로 가져감(활 계산과 같은 두 마디 계산).
3. **서기·걷기 자세 레이어(클라, Fx):** 무기를 들었고 공격 몸짓이 없을 때 `Hold` 관절 각도를 Animator 위에 더함(지금 클립과 같은 PreSimulation 자리). 걷는 속도에 따라 `Walk` 보정을 섞음. 공격이 시작되면 0.05초에 넘김, 끝나면 0.12초에 돌아옴(지금 FADE 값).
4. **기본 공격 9개:** 지금 3종을 바탕으로 진영별 클립 추가(Paladin/Berserker/Blacksmith…). 타격 시점(`RELEASE_CONTACT` 등)은 클립마다 표로 — 소리(Audio ContactDelay)와 맞춤.
5. **스킬 몸짓:** Q(Release)부터 9개, Z·X는 켜지기 전(10/20)까지 클립만 준비. Fx "Skill" 꾸러미의 Slot으로 고름.
6. **자동 전투:** 바꾸지 않음(같은 꾸러미 → 같은 몸짓). 단, 자동일 때 서기 자세 레이어가 공격 사이에 튀지 않게 0.3초 유지.

## 5. 시험·사진
- 오프라인: 9개 모두 표에 있음, 클립 길이 ≤ SwingInterval × 0.9, 키 사이 < 180°, 진영 없는 저장은 옛 3종, 두 손 무기의 왼손 목표가 팔 길이 안. 변이 시험.
- 메인 반영 1 사진: 9개 × (서기 / 걷기 / 기본 공격 한 순간 / Q 한 순간), PC 먼저(A23-98), 같은 각도. 빛 팔라딘만 좋고 나머지 대충이면 통과 아님.

## 6. 남은 결정 (검수)
- 위 표의 무기 모양(대검·망치·굽은 지팡이·플라스크·짧은 활)을 무기 2D(이미지 생성 2) 의뢰에 그대로 넘길지.
- 서버 쥐는 곳(2번)은 서버 파일이라 개발 3 검증 뒤 검수 병합 — 개발 1이 브랜치로 제안해도 되는지.

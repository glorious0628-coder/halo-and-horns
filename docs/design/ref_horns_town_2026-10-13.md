# 뿔 마을 실제 참고 (최종 검수 2026-10-13 밤, 사용자 "현실에 실제 있는 것에서 아이디어")

사용자: "창의성을 발휘해줘. 그런데 현실에 실제 있는 것에서 아이디어를 얻어서. 빛 성은 성당을 검색해보고 하라고 했거든." → 뿔 마을·뿔 성채 시안은 아래 6곳에서 가져온다. 출처는 맨 아래.

| 실제 장소 | 무엇을 가져오나 | 뿔 마을 어디에 |
|---|---|---|
| **바이킹 원형 요새 Trelleborg·Fyrkat(덴마크, 980년쯤)** — 둥근 흙 성벽 + 목책, 동서남북 문 4개, 가운데서 만나는 십자 길, 네 구역에 긴 집 4채씩 | **마을 평면 = 둥근 성벽 + 십자 길 + 가운데 모닥불 광장**, 문 4개 중 남문이 정문, 구역 4개(시장·집·전쟁 천막·훈련장) | 전체 배치(구역 지도 ①) |
| **마오리 파(pā) 언덕 요새(뉴질랜드)** — 언덕을 계단식 단으로, 목책 여러 겹, 정문 양옆 큰 조각 기둥, 문 위 감시 무대, 꺾인 진입로 | **계단식 단 + 목책 2~3겹**, 정문 양옆 **뿔 조각 기둥**(얼굴 금지 → 뿔·황소 문장만), 문 위 감시 무대, 꺾인 진입로 | 정문·울타리·단 |
| **다케다 성(일본 야마지로, 산 위 성)** — 능선 3갈래를 계단식 단으로, 단마다 자연석 돌담, '하늘 위 성' | **성채 = 고원 맨 위 능선을 따라 돌담 단이 층층이**, 안개·용암 빛 위에 떠 보임 | 성채 자리(북쪽 높은 단) |
| **카르카손 성채(프랑스)** — 이중 성벽 + 둥근 탑 52개, 탑 위 뾰족 고깔 지붕, 성벽 사이 빈 띠, 도개교 정문 | **이중 벽 + 둥근 탑 + 고깔 지붕(붉은 천)**, 벽 사이 띠는 용암 홈, 정문은 들보 다리 | 성채 벽·탑 |
| **딤무보르기르·스바르티포스(아이슬란드)** — '어두운 성' 용암 기둥 지대, 육각 현무암 기둥, 자연 용암 아치 | **현무암 육각 기둥 무리**(시안에 이미) + **자연 용암 바위 아치**를 북문·뒷길로 | 바위·북문 |
| **메사 베르데 절벽 궁전(미국)** — 절벽 처마 아래 돌집 100여 칸, 둥근 의식 방 | **절벽 처마 아래 집 몇 채**(동쪽 벼랑), 둥근 움푹 방 = 모닥불 광장 돌 고리의 뿌리 | 절벽 집·광장 |

## 뿔 성채 시안 4안 (Codex, `art/out/s2/horns_castle/HornsCastle_{A,B,C,D}.png`)
- A 다케다: 능선 따라 돌담 단 3층, 맨 위 큰 홀(붉은 천 지붕) — '하늘 성'.
- B 카르카손: 이중 벽 + 둥근 탑 4~5 + 고깔 붉은 지붕, 정문 들보 다리.
- C 마오리 파: 계단식 언덕 + 목책 3겹 + 뿔 조각 기둥 정문 + 문 위 감시 무대.
- D 딤무보르기르+메사 베르데: 자연 용암 아치 정문, 절벽 처마 아래 박힌 성.
## 뿔 마을 전체 조감 2안 (`art/out/s2/horns_zone/HornsZone_{a,b}.png`)
- 둘 다 바이킹 원형 요새 평면(둥근 성벽·십자 길·가운데 모닥불·문 4). a = 성채 북쪽 가운데, b = 성채 북동 높은 바위 + 서쪽 절벽 집. 크기 = 빛 마을과 같음(A23-164).

# A23-90 서버 계약 — 유적 바깥 PvP 끔 + 개인 서버 보상 절반 (게임성 개발 2, 2026-10-09)

근거: SPEC A23-90(사용자 2026-10-09), `docs/design/system_review_round1_2026-10-09.md`. 가지 `dev2-a2390`(dev2-mlevel 위).

## 1. 유적: 바깥 사냥 고리(안전) + 안쪽 왕관 구덩이(PvP)

- `Config.Zones.SkeletonRuins.PvP = false`, 새 칸 `PvPArea = { Name = "Crown Pit", Center = (1660, 0, 0), Size = 200 × 240, LootMult = 1.25 }`.
  - 구덩이는 왕관 제단 폐허(1700, 0) 둘레예요(x 1560~1760, z −120~120). 서쪽 입구(1260~)부터 x 1560까지와 남북 가장자리는 PvP 없는 사냥 고리예요.
  - 해골 궁수(A23-87)를 포함해 모든 유적 몬스터는 바깥·안쪽 둘 다 나와요(구역 번호는 그대로 하나).
- `Config.PvPAt(pos)` = 구역 PvP이거나 PvP 구역 사각형 안. `Config.PvPAreaAt(pos)`, `Config.ZoneHasPvP(zone)`(지도·관문용: 유적은 "안에 PvP 있음").
- ZoneService: `ZonePvP` 속성과 `IsPvPZone(player)`이 **서 있는 위치**를 따라요. 유적 안에서 구덩이 경계를 넘을 때도 "EnteredPvP"/"EnteredSafe" 알림이 떠요(ZoneChanged는 구역이 바뀔 때만).
  - 그래서 수배 별·털기 자루·원한 훔치기·PvP 피해·직업 변경 막기·괴수 공격은 모두 구덩이 안에서만 돼요(모두 `IsPvPZone`/`ZonePvP`를 봄).
  - 이동 채널(Travel)이 맞아서 끊기는 규칙도 PvP가 켜진 곳에서만(바깥 고리는 초원처럼).
- 구덩이 안에서 잡은 몬스터는 드롭 줄 확률 ×1.25예요(`info.AreaMult`, 잭팟 제외).
- Captain Clatter: 사당 표시(`ClatterSpawn`)가 없으면 구덩이 (1670, 0)에 나와요.
- 지도 관문 색(MapBuilder)은 `ZoneHasPvP`로 그대로 위험 색이에요.

## 2. 개인 서버 보상 절반

- `Config.PrivateServer = { RewardMult = 0.5, HalfSources = { Event, War, Bounty }, Text = "Rewards are halved in private servers" }`.
- `game.PrivateServerId ~= ""`이면 `ProgressionService.AddBankGold`가 출처 Event(황금 거위)·War(왕관전 상자, 포위 상자 포함)·Bounty(현상금·원한 복수 보너스)를 **2배 패스보다 먼저** 절반으로 해요(내림). 거위 경험치도 절반(GooseService, `ProgressionService.PrivateMult()`).
- 사냥·퀘스트·드롭·선택 카드·출석은 그대로예요. 랭킹은 이미 개인 서버에서 안 셈(RankingService).

## 3. 개발 1 몫 / 메인 반영

1. 구덩이 경계 표시(잘 보이게, 빛살 무늬 금지)와 미니맵·큰 지도에서 유적 바깥은 안전 색, 구덩이만 PvP 색. 구역 목록의 `z.PvP` 대신 `Config.ZoneHasPvP(z)`·`PvPArea` 사각형을 쓰면 돼요(MiniMap/WorldMap/Panels 여행 안내).
2. 첫 입장 카드: 구덩이에 처음 들어갈 때 PvP 카드 재사용(`ZonePvP`가 true가 되는 순간).
3. 상점 개인 서버 칸에 `Config.PrivateServer.Text`를 미리 적기.
4. 메인 반영: 구덩이 경계 사진.

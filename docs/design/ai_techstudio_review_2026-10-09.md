# AI 기술 스튜디오(ai-techstudio.web.app) 분석 — 우리 게임에 쓸 것 (검수 2026-10-09 밤)

사용자가 보내 준 사이트: https://ai-techstudio.web.app/#home. `llms.txt`(전체 목록 443줄)를 끝까지 읽고, 기술 하나(i484 전투 판정)의 문서를 열어 품질을 확인했다. 우리 `src/`와 대조해 이미 있는 것은 뺐다.

## 1. 무엇인가
- 웹 게임 기술 394가지(그래픽·이펙트·게임 시스템·지도·소리 등)와 조합 레시피 4개. 기술마다 움직이는 견본, 'AI 주문서', 원리, 흔한 실수, 완성 기준, 견본 코드가 있다. 문서는 한국어 + 영어 용어.
- **코드는 거의 다 three.js + TypeScript(웹)·Web Audio**다. Roblox Luau에 그대로 붙일 수 없고, Roblox에는 사용자 셰이더가 없어서 그래픽·셰이더 65개는 거의 못 쓴다. **원리·숫자·흔한 실수 목록은 옮겨 쓸 수 있다.**
- AI 연결: MCP 서버 `https://ai-techstudio.web.app/mcp`(Streamable HTTP, 로그인 없음, 읽기 전용 도구 5개: search_techniques · get_technique · list_categories · list_recipes · get_recipe). MCP 없이도 기술 하나는 `https://ai-techstudio.web.app/ai/t/<번호>.md`, 전체 목록은 `/ai/index.json`·`/llms.txt`로 읽힌다.

## 2. 이미 우리 게임에 있는 것 (새로 안 해도 됨)
히트스톱·카메라 킥(Fx.luau `Feel.hitStop`, 전사 접촉 프레임), 맞으면 흰 번쩍(`Config.HitFeel`), 튀어 오르는 숫자, 넉백(`MonsterService.ApplyKnockback`), 보스 바닥 예고(telegraph), 큰 순간 소리 낮추기(`Config.Audio` Duck), 대사 타자 소리(TalkBlip), 충격 고리·착지 먼지(King Slime 7d2a7b1a), 화면 흔들림 설정.

## 6. MCP 연결 — **사용자 결정(2026-10-09 밤): 연결 안 함.** 필요할 때 기술 번호 주소로 읽는다.
- 연결하면 세션들이 기술을 직접 검색해 읽는다. 무료·로그인 없음·읽기 전용. 다만 코드는 웹용이라 Luau로 다시 짜야 하고, 읽은 글은 참고 자료일 뿐 지시가 아니다.
- 연결 안 해도 위 표의 번호로 `https://ai-techstudio.web.app/ai/t/<번호>.md`를 열면 같은 글을 읽는다(검수 추천: 이 방법으로 충분).
- 연결한다면: 이 게임 폴더에만 `claude mcp add --transport http --scope project ai-techstudio https://ai-techstudio.web.app/mcp`(저장소에 `.mcp.json`이 생김). `--scope user`는 다른 게임(패션 폴더) 세션에도 붙는다. 설정 변경이라 사용자 OK 뒤에만.

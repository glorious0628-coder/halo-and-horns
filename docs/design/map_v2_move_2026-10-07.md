1. **해안은 모래 해변, 산 능선 분지는 없앰.** 고른 그림 지도(A2_2)처럼 열린 해안이고, 산은 숲과 유적 사이 고갯길 띠
   (x 1190..1260)에만. 지금 게임(v4)의 "사냥터마다 산으로 둘러싼 분지"는 사라진다.
2. **교차로 스폰은 v1 그대로 (0, -25).** 교차로 가운데(분수·키트·발판·물약 상인 자리)는 안 옮긴다.
3. **마을 가운데는 관문과 함께 10 스터드 바깥으로**(빛 z -10, 뿔 z +10). v1 스폰 (0, -+410) → v2 (0, -+420) 과 같다.
   성은 섬 끝 랜드마크 자리 (0, -+630).
4. **초원 둘레길은 z -120**(배치표 -170 은 왕 슬라임 언덕 키트 (430, -170) 를 지나감). **유적 큰길은 x 1684 까지**

5. **LandPass = 산 띠 전체** 1190..1260 × -260..260 (그림처럼 숲·유적과 이어진 땅), 걷는 길목 |z| < 70 (`PassHalfZ`).

### 코드
- MapBuilder: 이미 있는 구역 표시 파트·경계벽·관문을 Config 자리로 맞춤(옛 place 를 v2 로), 호박밭·유령 숲 v2.
- QuestTarget (호박밭·유령 숲 안내), HUD (연못 안내), Intro (마을 장면) 좌표 v2.
- `tools/preview_map.lua` 다시 씀: 기본 **terrain 모드**(땅·물·길·산·구역 표시·벽·다리·PvP 경계 다시, 관문 옮김, 나머지
  그대로, 바꾼 옛 조각은 ServerStorage.MapV1Backup). full 모드는 빈 place 전용.
- `tools/map_v2_move.lua`: v1 → v2 옮기기(기본 dry). 마을 10 바깥·성 섬 끝, 사냥터 장식은 v1 땅 안 상대 자리 →
  v2 땅의 같은 상대 자리, 호박밭·유령 숲 장식은 보관함(MapBuilder 가 v2 자리에 다시 지음).
- `tools/map_v2_apply.py survey | terrain | move [--apply] | build` — Studio Edit 에서만 돈다.

## P2 — Studio (검수에 "개발 1 — 지도 v2 Studio 작업 — 약 N분" 먼저)
0. 메인 Studio 가 꺼져 있으면 연다(A23-17 상시 허락, 창 작업은 검수에 먼저).
1. 백업: 파일 > 다른 이름으로 저장 `build/GoodEvil_before_v2.rbxlx`.
2. mapv2-p1 을 main 위로 올려 푸시 → `py tools/sync_to_studio.py` (Edit).
3. `py tools/map_v2_apply.py survey` (전 기록) → `terrain` → `move` (dry 목록 확인) → `move --apply` → `build` → `survey`.
4. 사진(MCP): 교차로 키트·분수 그대로, 빛·뿔 마을 + 성, 다리 4, 초원, 호박밭·유령 숲, 고갯길 산, 유적, 위에서 본 전체.
5. Play (내 시험): 진영별 스폰, 발판 → 구역, 구역 칩 이름, 몬스터가 구역 안에, 퀘스트 안내(연못·야영지·다리),
   폰 화면. 끝나면 Play 멈춤.
6. 다른 이름으로 저장 `build/GoodEvil.rbxlx` → `place/` 복사 → src 와 같이 커밋.
7. 되돌리기: `build/GoodEvil_before_v2.rbxlx` (또는 MapV1Backup).

# 영어 밈 묶음: Halo & Horns (SPEC A23-132)

> 최종본입니다. 설계안과 안전 검토를 모두 반영했습니다. main `95da401d` 기준입니다. 줄 번호는 따로 적지 않으면 `src/ReplicatedStorage/Shared/Config.luau`의 줄입니다.
> 사용자 OK가 필요한 일은 최종 검수만 사용자에게 묻습니다. 다른 세션은 사용자에게 직접 묻지 않습니다.

## 정한 것

1. 영어로 보는 플레이어만 밈 말투를 봅니다. 한국어 모드는 보통 말투 그대로입니다.
2. 새 줄과 새 키는 없습니다(A23-130, A23-99). 이미 있는 줄 81개의 말만 바꿉니다. 밈 65줄과 위험한 옛 줄을 고치는 안전 수정 16줄입니다.
3. 오래 가는 게임 말(GG, OP, AFK, respawn, boss music)을 주로 씁니다. 금방 낡는 유행 말은 12줄(18%)뿐이고, 2027년에 한 번에 바꿀 수 있게 표시해 둡니다.
4. 사실, 규칙, 값, 확률을 말하는 글은 그대로 둡니다. 놀림은 몬스터와 NPC 자신에게만 하고, 플레이어에게는 칭찬만 합니다.
5. 밈 느낌 그림은 7개입니다(꾸미기 2쌍, GG 스티커, 몬스터 1, 보스 음표, 소품 2). 이름 바꾸기 2개와 그림 고르기는 사용자 OK를 받은 뒤에 합니다.

## 말투 규칙

1. **게임 말을 먼저 씁니다.** GG, OP, AFK, respawn, loot, nerf, boss music, side quest, patch notes, speedrun처럼 오래 가는 말을 씁니다. 2019년 뒤에 뜬 유행 말은 밈 줄의 20% 이하로 두고, '오래 감'을 3 이하로 적습니다.
2. **말투만 바꿉니다.** 자리와 뜻은 같아야 합니다. 새 줄과 새 키는 만들지 않습니다. 새 줄은 옛 줄보다 최대 10자까지만 길어지고, 칸 한도를 지킵니다(몬스터 한마디는 2단어, 12자). 한 줄에 밈은 하나만 넣습니다.
3. **사실을 먼저 남깁니다.** 결과, 벌점, 보상 줄에는 사실을 말하는 말(failed, level up, knocked out/KO, not angel-like, won the crown)을 남깁니다. 밈은 그 옆에 더하기만 하고, 사실 말을 밈으로 바꾸지 않습니다.
4. **놀림은 몬스터, NPC 자신, '우리'에게만 합니다.** 플레이어에게 noob, L, EZ, ratio, outplayed, skill issue 같은 말은 쓰지 않습니다. 플레이어 이름(`%s`)이 들어간 줄에는 칭찬(GG, maxed)만 씁니다. PvP 줄(Player 원인, Bully, Plunder)은 그대로 둡니다.
5. **규칙, 숫자, 값을 말하는 글은 그대로 둡니다.** Help/Safety, PassInfo, 벌점 글, M2_7 안전 줄, D0/TS1/SG1/SZ1/KO1, 사는 버튼 옆 글이 여기에 들어갑니다. 없는 능력치("+1 aura")나 없는 효과("sip of luck")는 만들지 않습니다.
6. **확률이 있는 곳은 보통 말을 씁니다.** 강화, 옮기기, 떨어지는 물건, 거위, 오늘의 운이 그렇습니다. 운이나 도박을 떠올리는 말, 반응 밈(Oof, Bruh, F, RIP, W, L)을 쓰지 않습니다.
7. **뜻이 둘인 말은 쓰지 않습니다.** 성, 마약, 갱, 정치, 혐오 쪽 뜻이 있으면 뺍니다. "Horny"는 어떤 꼴로도 쓰지 않습니다(Horn 군단 이름 때문에 생기기 쉬운 함정입니다). 말하는 사람과 줄을 붙여서 읽어 봅니다. 위험한 짝의 예: Smokey + cook, Dad + BOING, Brute + sack, 할머니 + buns.
8. **줄임말은 GG, OP, HP, MP, AFK, Lv, KO, 1v1만 씁니다.** 한 글자 말(W, L, F)은 쓰지 않습니다.
9. **같은 밈은 3번까지 씁니다.** GG만 6번까지 됩니다. 렉 농담은 1번만 씁니다(M3 로딩 슬라임과 겹치기 때문입니다).
10. **밈은 글자로만 씁니다.** 그림은 모두 새로 그립니다. 밈 사진, 밈 얼굴, 만화 컷, 춤, 노래, 유명인 말버릇은 쓰지 않습니다. 가운데에서 퍼지는 빛줄기도 쓰지 않습니다.
11. **9살 영어 초보도 읽을 수 있어야 합니다.** 농담을 몰라도 원래 뜻으로 읽혀야 합니다. 예: "Ding!"은 종소리, "Power up!"은 세졌다는 뜻으로 읽힙니다.
12. **한국어는 보통 말투로 둡니다.** 한국어 표는 옛 영어 줄의 보통 뜻에서 옮깁니다. 밈 줄에서 옮기지 않습니다.

## 만드는 법 (영어 표만 바꾸고 한국어 표는 그대로, 시험)

**바꾸는 방법**
1. 영어는 지금 있는 자리에서 바로 바꿉니다(Config 칸, 화면 스크립트의 `TXT`/`L` 표). 쌍둥이 `X`/`XEn`은 둘 다 바꿉니다. 영어 밈만 따로 덮는 표(`TextMemeEn`)는 만들지 않습니다. 글이 두 곳에 있으면 서로 어긋나고 시험도 두 배가 됩니다.
2. 번역용 메모 `docs/l10n/meme_gloss_en.json`을 만듭니다. 게임 글이 아니라 문서입니다. 모양: `{ "<키>": { "Old": "옛 보통 줄", "New": "밈 줄", "Meme": "밈 이름", "Life": 1-5 } }`. 81줄 모두 넣습니다.
3. `tools/l10n_export.py`가 `Old`를 영어 옆에 같이 적게 합니다(`docs/l10n/strings_server_en.json` 등). 한국어는 `Old`의 뜻에서 옮깁니다. 나중에 `TextKo`에 넣을 때 `En` 칸에는 지금 영어(밈 줄)를 적습니다. 그래야 맞춤 검사를 통과합니다.
4. 한국어 모드 동작은 이미 있습니다(`L10n.luau`). `TextKo[key].En`이 지금 영어와 같을 때만 한국어가 뜹니다. 항목이 없거나 다르면 영어(밈 줄)가 뜹니다. 지금 `TextKo.luau`는 비어 있습니다.
5. 순서: A23-130 글 줄이기(fix/lesstext, fix/lesstext-server, 남은 글 훑기 표) → 밈 → 한국어 번역(빛 마을이 끝난 뒤, A23-111). 밈이 번역보다 늦으면 번역한 줄이 다 낡습니다.
6. 아직 영어로 굳어 있는 곳이 있습니다(계약 §10 전). 몬스터 한마디(`Bark` 속성), 칭호(`SessionTitle` "Final Boss"), 이름표, 서버 `Net.Notify` 글입니다. 그래서 한국어 플레이어도 A1~A15, F2~F6, D4~D13, D16은 영어 밈으로 봅니다. 대부분 소리 말이나 게임 말이라 괜찮습니다. §10 때 BarkService가 `BarkKey`를 보내고, 화면이 `L10n.T`로 바꿉니다.
7. 2027년에 바꿀 때: '오래 감' 3 이하인 12줄은 메모 JSON에 키로 있으니 한 번에 바꿉니다.

**시험 (새 파일 `tools/test_meme_pack.py`, 오프라인)**
1. **어긋남과 길이를 봅니다.**
   - 메모의 키마다 지금 영어가 `New`와 같아야 합니다.
   - `len(New) ≤ len(Old) + 10`이어야 합니다.
   - 칸 한도: 한마디 2단어·12자 이하, TownReact 12단어 이하, 이야기 14단어 이하, ShortName 14자 이하, Looks 12자 이하.

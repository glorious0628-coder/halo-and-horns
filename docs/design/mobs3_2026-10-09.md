# 새 몬스터 3종 — 서버 계약 (게임성 개발 2, 2026-10-09)

근거: SPEC A23-87(사용자 "넣자!"), 검수 계획 OK 2026-10-09(+ 튀어나옴은 작은 반짝이·0.4초, FlowerPatch 카드). 가지 `dev2-mobs3`.

## 1. 몬스터

| 종류 | 구역 | 모델(그림 오기 전) | 숫자 | 특징 |
|---|---|---|---|---|
| Flower Slime `FlowerSlime` | 초원 | 슬라임 모델 + 분홍 (`ModelFrom = "Slime"`) | 2마리, HP 14, 공격 2, XP 7, Gold 4 | 꽃 무리(땅 재질 Salt) 위에 숨어 있다가, 쫓을 수 있는 플레이어가 8스터드 안에 오거나 맞으면 튀어나옴. 퀘스트는 Slime으로 셈 |
| Slingshot Goblin `SlingshotGoblin` | 고블린 숲 | 고블린 모델·동작 + 색 | 3마리(고블린 10 → 7), HP 70, 공격 4(고블린 6보다 낮음) | 첫 원거리. 사거리 22, 17스터드 거리 유지 |
| Skeleton Archer `SkeletonArcher` | 해골 유적 | 해골 모델·동작 + 색 | 3마리(해골 8 → 5), HP 380, 공격 10(해골 14보다 낮음) | 원거리, 짝 없는 해골 기사 옆 4~8스터드에 나옴(`PartnerOf`). 사거리 26, 20 유지 |

- 구역 총수: 숲·유적은 그대로(기본 종 자리를 나눠 씀). 초원은 초록 슬라임 12마리를 그대로 두고 꽃 슬라임 2마리를 더해서, `Config.MonsterDensity.GlobalCap`을 72 → **76**으로 올렸어요(꽃 슬라임이 사람 수로 늘어도 최대 4).
- 드롭: 꽃 = Petal 50%(새 판매 재료 "Flower Petal", 3골드) + 초원 주문서 줄, 새총 = 고블린 줄, 궁수 = 해골 줄.
- 말풍선(2단어·12자): 꽃 "Peekaboo!"·"Surprise!"…, 새총 "Ready… aim!"·"Pew pew!"…, 궁수 "Target!"·"Draw!"…

## 2. 원거리 판정 (아이용, 서버)

- `Ranged = { Range, Stand, Windup, Speed, Radius, Cooldown }` — 새총 {22, 17, 0.9초, 18 studs/s, 3, 3초}, 궁수 {26, 20, 1.0초, 20, 3, 3.2초}.
- 사거리 안: 멈춰서 바라보고 `WindupAt`(근접 휘두르기와 같은 속성)으로 예고 → Windup 뒤 발사.
- 발사 = **그때 대상이 서 있던 자리**로 날아감(따라오지 않음). s→c `Fx "MonsterShot" { Id, Kind, From, To, Speed, Radius, Travel }`(모두에게), `AttackSeq` +1.
- Travel초 뒤 **대상만**, 착탄 지점 Radius(3) 안·높이 6 안이면 맞음. 옆으로 걸으면 피해요. 다른 사람은 안 맞음. 마을·구역 밖·물은 근접과 같은 규칙(`targetable`).
- 발사 순간 대상이 사거리 밖이면 쏘지 않아요. 이미 날아간 탄은 몬스터가 죽어도 떨어져요.
- 사거리 밖: 대상에게서 Stand만큼 떨어진 자기 쪽 자리로 걸어가요. 근접 링(SEP)에는 들어가지 않아요.

## 3. 꽃 숨기

- 숨음: 모델 속성 `Hidden = true`(이동·공격 없음). 튀어나옴: `Hidden = false`, `PopAt = 서버 시각`, Spot 말풍선.
- 개발 1: `Hidden`이면 이름표·체력바 숨기기, `PopAt`에 **작은 반짝이 + 0.4초 '뿅'**. 큰 소리·화면 흔들림 금지.

## 4. FlowerPatch 카드 (공용 선택 카드)

- `Config.ChoiceCard.Kinds.FlowerPatch`: "A flower got squished!" — [Replant it](Good, `Reward.XP = 6`) / [Pick the petals](Evil, Petal ×2). 저장 카드(시간 제한 없음), 점수는 Deeds.
- `KillCardService`(새): 꽃 슬라임 처치(기여자마다) 때 25%, **플레이어당 10분에 최대 1번**(카드가 실제로 열렸을 때만 시간 시작). `Config.KillCards.FlowerPatch`.
- ChoiceCard 보상에 `Reward.XP`를 더했어요(검수 ② 2026-10-09, 개발 3 파일에 한 줄 + 시험): `AddXP(player, xp, xp)` — cap이 패스 뒤에 걸려서 **2배 XP 패스를 타지 않아요.** `Fx "Card"`의 옵션에 `XP`, `CardEnd`에 `XP`, 알림 줄 "+6 XP"(`Config.ChoiceCard.Text.XP`).

## 5. 개발 1 몫

1. `MonsterShot` 그리기: 폰에서도 보이는 크기(Radius 3에 맞는 굵기), 느린 탄, 착탄 자리 동그라미 표시(빛살 무늬 금지).
2. `AnimFrom` 별칭(J와 같은 한 줄).
3. 꽃: `Hidden` 이름표 숨김, `PopAt` 작은 반짝이.
4. 그림(이미지 생성 2 → 이미지 개발): 세 몬스터 아이콘·말풍선(없는 동안 가족 것), Petal 아이콘 `IconPetal`.
5. 공용 카드 화면: 옵션의 `XP`가 있으면 "+6 XP" 표시(아이템·골드 칸처럼).

## 만드는 방법 (순서)
1. **설계 먼저.** 소리마다 '아이가 기대하는 소리(의성어)·길이·높낮이 쓸림·톤/잡음·피할 것'을 정한 뒤에 만든다. 사용자는 "맞아요 할 게 아니라 그 전에 알아야지"라고 했다.
2. **Firefly 효과음 생성**(Firefly 웹, 사용자 크롬, 이미지 세션과 같은 계정). 고르기용 후보부터 만든다.
   - 첫 생성 전에 한 번에 몇 크레딧이 드는지 화면에서 확인해서 검수에 알린다. 묶음마다 '몇 개 × 몇 크레딧'을 먼저 보내고, 검수의 '예'를 받은 뒤 만든다.
   - 프롬프트는 영어로 짧게 쓴다(1000자 아래). 유명 게임·브랜드 이름은 넣지 않는다.
   - 프롬프트는 `art/prompts/SFX_<키>.txt`, 결과는 `art/sfx/cand/<키>_<글자>.wav`로 저장한다.
3. **우리 기준으로 거르기.** 길이·시작(어택)·최대 dBFS(잘림 없음)·크기(같은 종류 평균 ±2 dB)·띠 쓸림(위/아래)·톤 줄(활은 팅 줄이 없어야 함)·폰 스피커(150 Hz 아래만 있는 소리는 안 됨)를 본다. 개발 2의 모양 시트(`C:\Users\glori\Documents\Roblox\Game-dev2\art\review\sfx_shapes_2026-10-07.png`)와 같은 칸(파형 + 첫 40 ms + 스펙트로그램 + 목표 점선 + 검사 줄)으로 그린다.
4. 종류마다 2~3개를 **시트 + 듣기판**으로 검수에 보낸다. 검수가 먼저 보고 2개씩 사용자에게 가져간다. 사용자에게 직접 묻지 않는다.
5. 고르면 다듬기(앞뒤 무음 자르기, 48 kHz 모노, 크기 맞춤) → `art/sfx/<키>.ogg` → wav로 업로드 → id를 개발 1에게 보낸다.
6. Firefly가 못 만드는 소리는 Kenney CC0 팩(`C:\Users\glori\Documents\Roblox\Game\build\devlog\sfx\impact|interface\Audio`, git 밖)이나 우리 합성으로 만든다.

## 소리 규칙
- 아이(8~12세)용이다. 무섭거나 아프게 들리는 소리, 피·비명 같은 소리는 쓰지 않는다. 빛(Halo)은 밝고 가볍게, 뿔(Horns)은 따뜻하고 장난스럽게 만든다. 종교 느낌(교회 종·성가)은 피한다.
- 자주 나는 전투 소리는 짧게(0.15~0.4 s) 만들어 귀가 지치지 않게 한다. 폰 스피커에서도 들리게 500 Hz~4 kHz에 몸통이 있어야 한다.
- 출처를 장부에 적는다: Firefly 생성(날짜·프롬프트 파일), Kenney CC0, 직접 합성. 출처를 모르는 무료 모음, Roblox 라이브러리 오디오, 유명 게임 소리는 쓰지 않는다.
- 커밋은 경로를 지정해서(`git commit -m "…" -- <paths>`) 한다. `git add -A`는 쓰지 않는다. 이 세션이 자기 git worktree에서 시작했다면 `git fetch origin && git rebase origin/main` 뒤 `git push origin HEAD:main`으로 올린다. 공유 트리(`C:\Users\glori\Documents\Roblox\Game`)에서 일한다면 푸시가 거절될 때 임시 worktree에서 cherry-pick 한다.
- 사용자에게는 직접 말하지 않는다. 승인이 필요한 것(크레딧, 업로드 라이선스 칸, 고르기)은 모두 **검수**에게 보낸다. 검수에게 쓰는 글은 한국어로 짧게 쓴다.
- 화면 제어(데스크톱 마우스·키보드)는 쓰지 않는다. 크롬은 Claude in Chrome 도구로만 쓴다. 꼭 필요하면 검수에게 "소리 만들기 — 무엇 — 몇 초"를 보내고 "전달함, 시작"을 기다린다.

## 첫 할 일
1. Firefly 웹에서 효과음 생성 화면을 찾고, 한 번 생성에 드는 크레딧·길이 제한·내려받기 형식을 확인해 검수에 보낸다(아직 생성하지 않는다).
2. 활 쏘기(슉), 마법 쏘기, 퍽, 치명타 4종의 Firefly 프롬프트 초안을 2개씩 쓰고 검수에 보낸다. 사용자가 듣기판에서 이미 고른 것이 있으면 그 종류는 뺀다.
3. 검수의 '예'를 받은 뒤 생성 → 모양 시트 → 듣기판 순서로 진행한다.
4. 그다음 설계서(sound_spec) 순서대로 나머지 소리를 다시 만든다. 확정된 셋은 그대로 둔다.

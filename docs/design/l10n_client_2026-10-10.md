# 한국어 모드 — 클라 언어 장치 설계 (게임성 개발 1, 2026-10-10, SPEC A23-111)

순서: **빛 마을 끝난 뒤 구현**(사용자 같은 날). 지금은 이 설계만. 글꼴은 A23-111 보강대로 **우리 비트맵 한글 글꼴**(글자 그림 묶음), 나눔고딕은 플레이어 이름·채팅·그림에 없는 글자만.

## 1. 지금 있는 것 (그대로 살림)
- `Config.Settings.Defs.Lang = { "Auto", "ko", "en" }` 저장 칸이 이미 있음(A23-48 때 설정 줄만 숨김).
- `UIKit.Lang()`(지금 늘 `"en"`)과 `UIKit.Tx(t, key, ...)`(표에서 `key.."En"` 또는 `key`) — 표마다 영어 쌍둥이 칸(`PlayerEn` 등)이 남아 있음.
- 글은 대부분 중앙 표에 있음: `Config.*.Text`, 모듈 `TXT`/`T.Text`.

## 2. 언어 고르기 (L10n)
- `UIKit.Lang()` = 저장된 `Settings.Lang`이 `ko`/`en`이면 그것, `Auto`면 `LocalizationService.RobloxLocaleId`가 `ko`로 시작하면 `ko`, 아니면 `en`.
- 바뀌면 `UIKit.LangChanged`(Signal) → 열린 창은 다시 그리고(Panels 재빌드), HUD는 refresh 함수들을 한 번씩 부름.
- 설정 창에 **'Language / 언어'** 줄 다시 보임(Auto / 한국어 / English, 즉시 바뀜, 서버 저장 — 지금 Settings 경로 그대로).

## 3. 글 찾기
- **원칙: 코드는 그대로 두고 한국어는 따로 한 파일.** `src/ReplicatedStorage/Shared/TextKo.luau` = `{ ["<표 경로>.<키>"] = "한국어", ... }` (예: `["Config.Death.Text.Player"] = "%s에게 쓰러졌어요"`).
- `UIKit.Tx(t, key, ...)`가 한국어일 때 `TextKo[경로]`를 먼저 봄 → 없으면 영어. 표 경로는 표를 등록할 때 한 번 정함: `UIKit.RegisterText(t, "Config.Death.Text")`(표 → 경로 표, 약한 키 아님).
- 아직 `UIKit.Tx`를 안 거치는 글(직접 `TXT.X` 대입)은 구현 때 화면별로 `UIKit.Tx`로 바꿈 — HUD·Panels·퀘스트 창·설정·상점부터(첫 10분 화면 순).
- `%s`·`%d` 자리 순서가 한국어에서 바뀌는 글은 `{1}`·`{2}` 이름 자리로 바꿔 씀(`UIKit.Tx`가 둘 다 받음).

## 4. 번역 목록 형식 (검수 API 초안용)
- `py tools/l10n_extract.py` → `docs/l10n/strings_en.json`: `[{ "key": "Config.Death.Text.Player", "en": "Knocked out by %s", "where": "KO screen", "max": 28 }]` (`max` = 그 칸에 들어가는 글자 수 어림).
- 검수가 `strings_ko.json`(같은 key + `ko`)을 만들면 `py tools/l10n_apply.py`가 `TextKo.luau`를 씀 + 시험(모든 key가 영어에 있음, `%`·`{n}` 자리 수가 같음, 글자 수 `max` 안).
- 용어집 `docs/design/glossary_ko_2026-10-10.md`(쉬운 한국어, 아이용) — 검수 확인.

## 5. 글꼴 — 비트맵 한글 (이미지 개발과 같이)
- 모든 글 쓰기를 **한 입구**로: `UIKit.SetText(label, text)`(또는 `StyledLabel`/`Typewriter` 안에서). 영어면 지금처럼 `label.Text`. 한국어면 이미지 개발의 그리기 장치가 글자 그림을 이어 붙임(EditableImage 합성 또는 글자당 ImageLabel — 폰 성능은 그쪽 검사).
- 내 몫: 입구 함수와 줄바꿈 정보 넘기기(한국어는 **낱말(띄어쓰기) 단위**, 넘치면 글자 단위), 글 길이 측정 API(`UIKit.MeasureText(text, size)` — 그림 글꼴 폭 표 기반)를 HUD 배치 코드(`L.Fit*`)가 쓰게 바꿈.
- 그림에 없는 글자(플레이어 이름·채팅 등) → 나눔고딕 TextLabel로 떨어짐.
- 고정 큰 글(게임 이름·진영 이름·창 제목·버튼) = GPT 글자 그림(이미지 생성 2): `Config.UIArt` 부품마다 `IdKo`를 더 두고 `UIKit.ArtId`가 한국어일 때 `IdKo`를 먼저 씀. 월드 간판(SurfaceGui)도 클라가 `IdKo`로 바꿔 끼움.

## 6. 서버 글 (개발 3 + 개발 2 계약)
- 플레이어 속성 **`Lang`** = `"en"`/`"ko"`: SettingsService가 저장값(+ Auto면 접속 때 클라가 한 번 알려 주는 LocaleId)으로 정함.
- 서버가 보내는 알림·퀘스트 줄·이야기 글은 **받는 사람의 `Lang`으로 만든 글**(서버도 같은 `TextKo`를 읽음 — Shared에 있으니). 또는 `{ Key, Args }`로 보내고 클라가 `UIKit.Tx`로 만듦 — 새 알림은 이 방식 권장(서버 영어 문자열이 남지 않게).

## 7. 순서 (빛 마을 뒤)
1. L10n 고르기 + 설정 줄 + `TextKo` + 추출/적용 도구 + 시험 (개발 1)
2. 첫 10분 화면부터 `UIKit.Tx`로 바꾸기(HUD → 퀘스트 → 가방 → 상점 → 설정) (개발 1)
3. 서버 글 `Lang` (개발 3·2)
4. 비트맵 글꼴 그리기 장치 + `MeasureText` (이미지 개발 + 개발 1), 글꼴 후보 시트는 먼저(사용자 고름)
5. 고정 큰 글 그림 `IdKo` (이미지 생성 2 → 이미지 개발)
6. 메인 Play 한국어 첫 10분 사진(PC 먼저)

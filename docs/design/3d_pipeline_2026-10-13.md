## 1. 그림 (2D 4면)
- **그림자 없는 3D 렌더**(A23-150 1번): 부피·둥근 모서리·부드러운 형태 음영·재질 광택은 남김. 사방 고른 밝은 빛. 바닥·드리운·닿는 곳 그림자, 어두운 한쪽 면, 어두운 틈 없음. 납작한 2D 색칠도 아님. 기준 그림 `art/review/codex/mailboy_front_original_flat_3d_1012.jpg` 오른쪽.
- **앞면 먼저.** 옆·뒤는 새 앞면을 참고 그림으로 넣어 같은 모습으로(`tools/ns_draw.py`: ref1 = 그 면의 옛 2D(시점), ref2 = 새 앞면(모습); 방향은 글로 쓰지 않음).
- **4면 같은 카메라 높이·같은 물체 높이.** 옆면 = 끝에서 수평으로 본 모습. 둥근 것은 4면 같은 폭. 맞추기는 다시 그리기보다 `tools/ns_fix.py`(높이·발 선·바탕 맞춤, `--mirror left=right`) 먼저.
- **방향 이름:** `_left` = 앞이 화면 오른쪽, `_right` = 앞이 화면 왼쪽. 한쪽을 보는 물건은 4면 모두 이 방향에 맞춤.
- **작은 알갱이 대신 큰 덩어리:** 잎·꽃 알갱이 수백 개는 스마트 메시가 못 따라감 → 큰 덩어리 10~15개로. 아주 작은 조각은 따로 하지 말고 덩어리로 묶어 한 장(돔+꼭지, 문짝+경첩+문고리, 등불+팔).
- **같은 모양 장식은 한 번만**(A23-150 5번): 2D가 같은 것은 한 번 만들어 여러 곳에 놓고 크기만 맞춤. 다른 물건을 키우거나 색만 바꿔 쓰는 것은 금지(A23-96).
- **대칭 짝은 거울:** 좌우 짝(성 날개 L/R 등)은 한쪽만 만들고 다른 쪽은 Blender 좌우 뒤집기. 그림도 한쪽만.
- 늘 지킬 것: 단정한 옷(사람·사람 닮은 것), 빛살 무늬 금지, 글자 없는 그림, 바깥선 없음.
- **도구:** 확정 그림 = 사용자 ChatGPT 요금제 `py tools/codex_image.py --prompt-file art/prompts/<id>_<면>_ns.txt --ref <옛 승인 2D> --out art/out/s2/noshadow/<id>_<면>_ns.png`(보통 `tools/ns_draw.py`가 부름). 종료 코드 3(사용량 끝)이면 그때만 **Firefly 고급(5크레딧)**(A23-151). 시안 후보만 Firefly 중간(0크레딧). Firefly 프롬프트는 1000자 아래.
- **Firefly 결과 받기:** `tools/firefly_autodl_helpers.js`를 생성 **전에** Firefly 탭에 붙임 → 사전서명 S3 주소 모음 → `py tools/ff_fetch.py map.json --out art/out/... --pattern ...`로 `curl`처럼 프로젝트에 바로 받음(`docs/handoff/firefly_autodownload_2026-10-13.md`). 참고 그림 넣기 = Adobe `asset_initialize_file_upload` → curl PUT → `asset_finalize_file_upload` → `presignedAssetUrl`.
- **금지:** 브라우저 다운로드·저장 창·사용자 Downloads 폴더(AGENTS 규칙 6, 10/13).
- 4면 판정 = 디자인 검수(한 장씩 전체 크기 + 옛 그림 옆, 개수·색 같음, 좌우 옆면 서로 맞음). 통과한 것만 Tripo로.

## 2. Tripo 웹 (Blender 손보기 = 앱 안 브라우저, Blender 손보기 2 = 사용자 Chrome·Claude Chrome 확장)
1. **스마트 메시(100점):** 스마트 메시 탭 → 멀티뷰(큐브) 아이콘 → 칸 순서 `0 앞 · 1 왼쪽 칸 ← _right · 2 오른쪽 칸 ← _left · 3 뒤`. 그림은 Adobe 사전서명 주소를 페이지에서 `fetch` → File로 칸에 넣음(base64 붙이지 않음).
2. **디자인 검수가 흰 모델 4개 중 고름:** 사방·위·아래로 봄(Tripo에서 직접, 창이 숨겨지면 `tools/design_review/` README 1~3: FBX 받아 `clay_views.py` 점토 렌더). 사람은 **얼굴에 아무것도 없는 것**. 바닥 뚫림·속 조각·얇은 장식 끊김·뒷면에 앞 장식 찍힘을 비교. 고른 id + 이유를 Blender 손보기에. 4개 다 안 되면 2D를 다시(큰 덩어리) 그려 ①부터.
3. **텍스처(4K, 계정 2 = 20점; A23-157 전엔 8K 30점):** 모델 아래 버튼 말고 **왼쪽 메뉴 '텍스처'** → **열려 있는 기본 탭 그대로**(사용자 10/13 오후 A23-158: '앞면 사진' 탭을 누르지 않음, 앞면 2D를 따로 올리지 않음; 그 전엔 첫 칸에 앞면 2D였음) → **'조명 없이(조명 제거)' 체크** → **4K**(Roblox는 1024로 줄임, 사용자 "4k가 낫겠엉") → 생성.
4. **PBR(5점):** 텍스처가 끝나면 **바로** PBR 한 번. 사이에 확인 관문 없음.
- **점수 버튼은 Blender 손보기·Blender 손보기 2(Chrome, 다른 계정)만** 누른다(각자 자기 계정·자기 큐). 버튼은 요소·경로 id·상태를 확인한 뒤 JS로 누르고 앞뒤 잔액 비교. Tripo 화면 **좌표 클릭·드래그 금지**(엉뚱한 버튼 맞음). 다른 세션은 보기만.
- 점수 승인: 빛 마을 목록 안 = 디자인 검수 OK(두 계정, 135/개, 다시 하기 포함), 목록 밖 = 최종 검수.
- **자기 계정 잔액이 135점 아래면**(다음 물건 하나 못 만듦) 새 생성을 멈추고 **최종 검수에만** 알림(사용자에게 직접 안 함). 밀린 일을 함. **130점 아래**면 최종 검수가 사용자에게 전함(계정 바꿈)(A23-150 4번).
- 로그인은 사용자가 직접(비밀번호 입력 절대 금지). 앱 브라우저 창이 숨겨지면 Tripo 페이지가 멈춤 → 최종 검수에 "창 보이게" 부탁(화면 사용, 7절 아래 규칙).
- 페이지 함수는 `tools/tripo_web_helpers.js`(로그인 뒤 한 번 실행). 많은 결과 목록은 내 탭에서 `api.tripo3d.ai/v2/studio/assets/v2?asset_type=mine…` fetch.

## 3. PBR 뒤 검수 (디자인 검수 → 최종 검수)
- PBR이 끝나면 Blender 손보기가 **원본 FBX만** curl로 받아(4절, 검수 전엔 Blender 손대지 않음) **이름 + 파일 경로**를 디자인 검수에 보냄.
- **디자인 검수:** 2D 4면과 나란히, **앞·옆(두 쪽)·뒤·위 3/4 + 디테일 많은 곳 100% 크롭**. 도구 `blender --background --factory-startup --python tools/design_review/pbr_gate.py -- <out> 700 2048 <file>[:front] …` → `py tools/design_review/pbr_gate_sheet.py …`(1줄 2D, 2줄 렌더, 3줄 크롭). 색 힌트 `color_compare.py`(숫자는 힌트, 눈으로 판정). 시트 `art/review/design/pbr_gate_<날짜>/`.
- **최종 검수:** 통과한 것만 받아 내려받은 파일을 직접 렌더해 한 번 더 봄.
- 둘 다 통과 → Blender 손보기가 크기·피벗·방향(4절) → 이미지 생성 3이 넣음(5절).
- **떨어지면 ②로**(다른 흰 모델 → 텍스처 → PBR). 칠하기·Blender 고치기·다시 올리기는 없음. 작은 얼룩은 그대로 두거나 ⑤ Roblox 재질에서 좋게.

## 5. Roblox (이미지 생성 3, WorldKit)
1. **메시만 GLB:** `py tools/glb_strip_mesh.py build/import3d <a_TU.glb> …`(8K 그림은 빼고 메시만).
2. **Studio '3D 가져오기'** = 화면 조작 → 최종 검수가 묶어서 차례를 줌(사용자에게 "🟠 제어" 먼저 알림). `CreateAssetAsync`는 이 Studio에서 안 됨.
3. **SurfaceAppearance 맵:** `py tools/glb_sa_maps.py <out> <a_TU.glb> …`(1024, C·N·R·M; 금 아닌 곳 금속 0·거칠기 ≥0.6) → `_check.jpg`를 **한 장씩 직접 눈으로 모두 확인**(하드 규칙 1) → 새 업로드 = **최종 검수 승인** 뒤, **10개 이하**씩 `py tools/upload_sa_maps.py <out> --names … --tags CNMR` → `art/ui/asset_ids.json`의 `SA_<이름>_C/N/M/R`.
4. **키트:** 가져온 `Workspace.<이름>_TU`는 원본(지우지 않음) → `tools/worldkit/tripo_kits_build.luau`로 `ServerStorage.HaloTripoKits.<이름>`(MeshPart + SA, 앞 -Z, 피벗 바닥 가운데). **가져온 메시는 이미 -Z를 봄 → 180° 더 돌리지 않음, PrimaryPart 넣지 않음.**
5. **놓기:** 계획 자리(`docs/design/halo_plan_v2_2026-10-11.json`, 집 장식 `tools/worldkit/tripo_deco_place.luau`). 옛 것은 지우지 말고 `ServerStorage.Parked_*`로. 끝나면 `py tools/worldkit/wk_backup.py save`.
6. **재질을 2D에 맞게 더 좋게:** SA 색 곱하기·거칠기(번쩍이면 올림)·DoubleSided(잎·창 화분)·빈 유리 칸은 Studio 파트(Glass/빛 파트). 텍스처 얼룩도 여기서 좋게 하거나 그대로 둠.
7. **사진:** `tools/halo_light_sim.luau` C2c 빛으로 **낮·밤**, `tools/prop_ab_shots.py`·`tools/building_ab_shots.py`, **2D와 나란히** → 디자인 검수 판정 → 최종 검수. WorldKit 창 펼치기도 화면 조작(최종 검수 경유).
- 메인 게임에는 빛 마을 6단계(새 마을 메인 교체) 때 메인 반영 1이 옮김.

# 몬스터 도감 카드 — 영상 분석 + 우리 판 설계 (최종 검수, 2026-10-12)

사용자: "https://www.threads.com/@dnjsrud25/post/DeYiVMbgDtj 이거 분석한 것도 추가해줘. 우리도 이런 식으로 도감 모을 수 있게 하자." → SPEC A23-153. 앞서 나온 안 11a(`docs/design/psychology_retention_2026-10-08.md`: 실루엣 → 10/100/1000 별, 드롭 확률)를 이 영상 방식으로 키운다.

## 1. 영상에서 본 것 (관찰 — 24초 영상, 2·6·10·14·18·22초 장면을 직접 봄)
- 제목 "수호수 카드 · GUARDIAN BEASTS · SERIES 1". 웹 화면 가운데 카드 1장, 아래에 줄 고르기 썸네일 3개 + [뒤집기] + [자동 기울기] 버튼.
- **줄 3개 × 3단계 진화:** 바람 여우(휘린 → 풍익호 → …), 불 고양이(화롱 → 화표 → …), 물 용(물방 → 파랑마 → …). 왼쪽 아래에 1단계·2단계·3단계 표와 이름·한 줄 설명.
- **카드 앞면:** 단계 표시, 이름, 체력(90·100), 속성 동그라미, 기술 2개와 숫자(깃털 돌풍 60·하늘 가르기 80 등), 아래 짧은 설명 글. 그림이 카드 전체를 채우고 글 칸은 반투명 판.
- **반짝이는 카드:** 무지개 테두리, 카드를 기울이면 빛 띠가 움직임(홀로그램 느낌), 마우스를 따라 카드가 기울어짐.
- **진화 순간:** 카드를 기울이면 다음 단계로 바뀜 — 바뀌는 동안 세로 줄무늬가 흐르며 그림이 녹아 바뀌는 효과(10·14초 장면). 댓글: "카드 기울여서 진화하는 거 진짜 신기하네 퀄리티 미쳤다".
- 댓글(추측 근거): "예전에 엄청 유명했던 포켓몬 카드 사이트에서 많이 차용" — 웹의 홀로 카드 효과 모음을 본뜬 것으로 보임.

## 2. 왜 재밌나 (판단)
① 손으로 만지는 느낌(기울이면 빛이 따라옴) ② 드문 카드일수록 더 반짝임 ③ 진화를 '보는' 순간이 보상 ④ 칸을 다 채우고 싶은 마음(모으기) ⑤ 뒤집으면 이야기가 나옴.

## 3. 우리 판: "Monster Codex" 카드 (게임 글은 영어, 쉬운 말)
- **무엇을 모으나(베타):** 베타 구역 몬스터 11종 — 슬라임 초원(Slime·FlowerSlime·BigSlime·보스 Slime King), 고블린 숲(Goblin·SlingshotGoblin·GoblinBrute), 해골 폐허(Skeleton·SkeletonArcher·SkeletonKnight·보스 Captain Clatter). 호박밭·유령 숲·새 구역 몬스터는 그 구역이 열릴 때 '시리즈 2·3'으로.
- **카드 3단계 = 잡은 수로 진화:** 1단계 처음 잡으면 카드 생김(기본 테두리) → 2단계 100마리(은빛 테두리 + 뒷면에 드롭 표·나오는 곳) → 3단계 1000마리(금빛 홀로 + 움직이는 빛). 영상처럼 몬스터가 다른 생물로 바뀌는 게 아니라, **같은 몬스터의 그림이 단계마다 더 멋진 장면**(1 얼굴 → 2 싸우는 자세 → 3 배경 있는 큰 장면).
- **황금 몬스터 카드(우리만의 것):** 이미 있는 황금 몬스터(4%)를 잡으면 '골드 포일' 카드가 따로 생김 — 가장 드문 카드.
- **진화 순간:** 100·1000마리째를 잡으면 화면 가운데 카드가 떠서 기울어지며 다음 단계로 바뀜(세로 빛 흐름 + 반짝이·별·둥근 빛, **빛살 무늬 금지**) → "Card evolved!".
- **보는 화면:** HUD 메뉴 [Codex] → 구역별 칸(아직 못 본 몬스터 = 실루엣) → 카드를 누르면 크게: PC는 마우스 따라 기울기, 폰은 끌기, [Flip](뒷면: 짧은 이야기·나오는 곳·드롭·잡은 수·처음 잡은 날), [Auto tilt].
- **진영 맛(GDD §0):** 뒷면 이야기 한 줄이 내 진영 학자의 말투(빛 = 다정한 관찰기, 뿔 = 장난스러운 놀림, 장인 = 재료 메모) — 같은 카드도 진영마다 다르게 읽힘.
- **보상(능력치 없음 — 공정함):** 단계마다 작은 골드·XP, 구역 페이지 다 채우면 칭호(예: "Slime Scholar"), 11종 모두 3단계 = 카드 테두리 꾸미기·후광/뿔 반짝 꾸미기(돈 아님). 도감 보상은 팔지 않는다.

## 4. Roblox에서 만드는 법 (판단, 개발 세션이 확인)
- **카드 = ViewportFrame 안 얇은 3D 판 하나**(앞·뒤에 SurfaceGui/그림) → 마우스로 판을 실제로 기울임(원근감 있음), [Flip] = 180° 돌리기. 반짝임 = 앞면 위 반투명 무지개 그림 + UIGradient를 기울기 각도에 맞춰 움직임. 진화 = 두 그림 겹쳐 녹이기 + 반짝이.
- 2D UI만으로 하면(UIGradient만) 원근 기울기가 안 됨 → ViewportFrame 방식 추천.
- **데이터(서버):** 플레이어 저장에 `Codex[kind] = { Kills, Golden, Stage, First }`, 서버가 처치 때 셈(이미 있는 처치 기록 재사용), 단계 오를 때 원격으로 알림 + 보상. 저장 버전 올림.
- **그림:** 카드 그림 = UI 그림(게임 빛 안 받음 → 그림자 규칙 밖). 11종 × 3단계 = 33장 + 골드 11장 + 실루엣·테두리 3종(기본·은·금 홀로)·뒷면 판. 시안 Firefly 중간 → 확정 ChatGPT(Codex). 테두리·뒷면은 글자 없는 판, 글은 TextLabel.

## 5. 언제·누가 (제안)
- **베타 v1:** 위 11종 + 단계·골드 카드·기울기·뒤집기·칭호. 기능 마감(11/24) 전. **정식 뒤:** 시리즈 2(할로윈)·3(새 구역)·펫 도감·무기 도감.
- 담당: 설계 = 최종 검수(이 문서), 서버 = 게임성 개발 2, 화면(도감 창·3D 카드·진화 연출) = 게임성 개발 1, 그림 = 이미지 생성 2 → 이미지 개발(올리기·UIArt).
- 먼저 할 것: 카드 1장 시험(Slime, 1단계, 기울기·뒤집기·반짝임)을 UiSandbox에서 → 사용자에게 보여 줌 → 나머지.

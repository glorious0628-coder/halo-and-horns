## 0. 한 줄 요약
- 영어 원문은 지금 있는 글 표 그대로 둔다. 한국어는 `Shared/TextKo.luau` 한 파일이고, 번역한 영어 원문을 함께 저장한다(§7).
- 키 = 그 글이 사는 표의 경로 + 칸 이름이다(끝의 `En`은 뺀다).
- **플레이어가 읽는 서버 값에는 영어 문장이 없다.** 보내는 글(payload)·Fx·속성·저장·프롬프트·Gui 글 모두 id나 키만 담는다(§5). 클라가 자기 언어로 만든다. 예외: 키가 함께 가는 영어 사본(알림 대체 `Text`, 퀘스트 줄 기록용 `Text`, §5-3)과 §5-4.
- 플레이어 언어 = 서버가 정하는 플레이어 속성 `Lang`(`"en"`/`"ko"`)이다.

## 1. 언어 정하기 (B9 반영)
- 저장 칸은 그대로 `Settings.Lang` = `"Auto"` | `"ko"` | `"en"`이다.
- **PlayerService**가 `player:SetAttribute("Lang", …)`를 두 번 한다:
  - `PlayerAdded`에서 바로: `player.LocaleId`가 `ko`로 시작하면 `"ko"`, 아니면 `"en"`.
  - 저장을 불러온 직후, Mirrored 속성 돌리는 곳 옆에서: 저장값이 `ko`/`en`이면 그것, `Auto`면 위와 같은 규칙. **`DataLoaded`/`PlayerReady` 전**에 한다. 그래서 FactionService·QuestService의 첫 알림도 언어가 정해진 뒤에 나간다.
  - 설정 저장(SetSettings)마다 다시 정한다.
- 클라 `UIKit.Lang()` = 속성 `Lang`이다. 속성이 없으면 **`LocalPlayer.LocaleId`**(서버와 같은 근거)로 정한다. 설정 창에서 누르면 클라가 **바로** 그 언어로 바꾸고, 서버 속성이 오면 그것을 따른다.
- 바뀌면 `UIKit.LangChanged`가 울린다. 열린 창은 다시 그리고, HUD 글은 다시 쓴다.
- 줄 서 있는 알림·배너는 `{Key, Args}`를 들고 있다가 **보여 줄 때** 글로 만든다(바꾼 언어가 바로 맞음).

## 2. 글 키 (S10 반영)
- **키 = `"<표 경로>.<칸>"`**이다.
  - Config: `"Config.Text.GooseReward"`, `"Config.Factions.Halo.Perks.1"`(배열은 1부터).
  - 클라 모듈 표: `"HUD.TXT.Bag"`, `"SkillBook.T.Text.Title"`.
- **끝의 `En`은 키에서 뺀다.** 찾을 때는 칸(`Name`)을 먼저 보고, 없으면 `Name .. "En"`(`NameEn`)을 본다. export도 `*En` 칸과 이름 표(무기·직업·스킬 `NameEn` 등)를 글로 친다.
- **표 등록:**
  - `L10n`이 Config의 하위 표를 스스로 등록한다.
  - 클라 모듈은 `L10n.Register("HUD.TXT", TXT)`로 한 번 등록한다. Register는 **안쪽 표까지 따라 들어간다**(`SkillBook.T.Text`).
- 플레이어가 읽는 글은 등록된 표 밖에 두지 않는다. 폰/PC가 다른 글은 키 두 개로 나눈다.

## 3. 공용 모듈 `Shared/L10n.luau` — API는 이것뿐
| 함수 | 뜻 |
|---|---|
| `L10n.Get(key, lang)` | ko이고 `TextKo[key]`가 있고 그 **저장된 영어 = 지금 영어**면 한국어(§7). 아니면 영어 원문, 그것도 없으면 키 글자 |
| `L10n.Format(template, args, lang, named)` | 자리 채우기(§4). 이름은 `Format` 하나(`Fmt` 없음) |
| `L10n.T(key, args, lang, named)` | `Format(Get(key, lang), args, lang, named)` |
| `L10n.Msg(msg, lang)` | 메시지 하나(§5)를 글로 만든다. 안의 메시지·이름·목록도 차례로 만든다 |
| `L10n.Register(path, tbl)` | 클라 모듈 표 등록(안쪽 표까지) |
| `L10n.LangOf(player)` | 속성 `Lang`, 없으면 `player.LocaleId`로 정한다(§5-4 예외와 서버 로그용) |
- 클라 `UIKit.Tx(t, key, ...)`는 남긴다. 등록된 표면 `L10n.T`, 아니면 지금처럼 영어. 그래서 화면을 하나씩 옮겨도 안 깨진다.

## 4. 자리·숫자·조사 규칙 (B3 반영)
- **숫자:** 서버는 지금처럼 보이는 양을 **미리 꾸며서**(`Util.FormatNumber` "12.3K", `Util.FormatInt` "12,345") `%s` 자리에 **문자열**로 보낸다. 날 숫자는 `%d`·`%.1f` 자리에만 보낸다. **클라는 Args를 다시 꾸미지 않는다.**
  - 예: `Config.Text.GooseReward` = `"+%s gold +%s XP"` → Args = `{ "12.3K", "300" }`.
  - 한국어 예: `"골드 +%s · 경험치 +%s"`(`%d` 아님).
- **`Format` 규칙:**
  1. **Args가 없으면 `string.format`을 절대 부르지 않는다** — 글 안의 `%`("XP +30% (level up faster)")는 그대로 둔다. `{n}`·Named·조사 표시가 있으면 그것만 채운다(아래 5도). Args·Named·`{`·조사 표시가 다 없으면 틀을 그대로 돌려준다.
  2. Args가 있으면 `pcall`로 채운다(`%` 자리). 실패하면 영어 틀로 다시 하고, 또 실패하면 키 글자를 쓴다.
  3. 빠진 자리는 `""`로 채운다.
  4. **쓴 틀이 영어 틀이면**(언어가 en이거나, 한국어 번역이 없거나 낡아 영어로 떨어졌을 때) 마지막에 `Config.Plural`(1 items → 1 item)을 한다. 지금 서버가 하던 일이다(LootService 576, QuestService 283, StoryQuestService 897).
  5. 그다음 클라가 `Config.FillKeys`로 `{Auto}` 같은 키 토큰을 채운다. 키 토큰은 어느 언어에서나 날 글자로 둔다.
- **Args를 받는 틀에서 글자 `%`는 `%%`로 쓴다**("Enhance Scroll 10%%"). Args 없는 틀은 그대로 둔다.
- **순서 바꾸기:** 한국어는 `{1}`·`{2}`(args 번호)를 쓸 수 있다. 한 글 안에 `%`와 섞지 않는다.
- **이름 자리:** `{Unit}`·`{Camp}` 같은 이름 토큰은 `named`(§5-1)로 채운다.
- **조사(을/를, 이/가, 은/는, 와/과, (으)로):** 자리 뒤 조사 표시를 `{1:을}`, `{Unit:이}`처럼 쓴다. `Format`이 채운 글의 마지막 한글 받침으로 고른다.
  - 받침 = (코드 − 0xAC00) % 28 ≠ 0. `(으)로`는 ㄹ 받침이면 '로'.
  - 한글이 아니면(숫자·영어 이름) 두 꼴을 함께 쓴다("을(를)").
  - 첫 번역 묶음 전에 용어집 규칙으로도 적는다.

## 5. 서버 → 클라 모양 (B2·S5·S6·S7·S8 반영)
### 5-1. 메시지 하나
`{ Key = "<키>", Args = { ... }?, Named = { Unit = …, ... }? }`
- **`Args`는 배열**이다(자리 순서). 빈 자리는 `""`(nil 구멍 없음).
- **`Named`는 따로 둔다**(Args에 섞으면 원격에서 키가 사라짐).
- Args·Named의 한 칸은 다음 중 하나다:
  - 문자열: 이미 보이는 모양(꾸민 숫자, 플레이어가 만든 글).
  - 숫자: `%d`/`%.1f` 자리만.
  - **안의 메시지** `{Key, Args, Named}`: 진영·몬스터·물건 이름, 감싼 단계 글(SkillLater 등).
  - **사람 이름** `{ Who = displayName, Hon = true? }` 또는 **숨긴 이름** `{ Hidden = factionId | "None", Hon = true? }`: 클라가 "A member of the …"/"Someone"·높임 표시를 자기 언어로 만든다.
    - `AnnounceService.PublicName(p, honorific)`은 **지금처럼 문자열**을 돌려준다(문자열만 받는 래퍼 GooseService 77-79·CombatService 1397-1399가 숨긴 이름을 진짜 이름으로 떨어뜨리지 않게). 메시지에 넣을 때는 새 **`AnnounceService.PublicNameArg(p, honorific)`** → `{Who, Hon}` / `{Hidden, Hon}`을 쓴다. RankingService.hiddenName도 같은 짝(`hiddenNameArg`).
    - **KaijuName**은 속성이라 표를 못 담는다 → 속성 `KaijuName`(문자열, 진짜 이름 또는 "")과 **`KaijuHidden`**(진영 id 또는 "")을 따로 둔다. 클라가 `KaijuHidden`이 있으면 숨긴 이름으로 만든다.
    - Announce는 이름을 바꾸지 않는다: `who()`가 이미 `Faction`과 `Who = ""`를 보내고 `A.Subject`가 `Who == ""`면 숨긴 이름으로 만든다(AnnounceService 55-66). v3의 `HiddenFaction` 이름 바꾸기는 취소.
    - **메시지나 Fx로 가는 이름은 모두 `PublicNameArg`:** KO Fx의 `Name`(CombatService 1394-1406·1421, 괴수 `publicName(k)` 포함 — Fx 줄은 표를 담을 수 있음), 거위 `Config.Text.RareAnnounce`(GooseService 592) 등 문자열만 받던 래퍼 중 메시지·Fx를 만드는 것은 `PublicNameArg`로 바꾼다. 서버 로그·Kick 같은 서버 전용 줄만 `PublicName` 문자열.
  - **목록** `{ Join = { msg, ... } }`: 보상 목록(ChoiceCard, FinisherService, LostFoundService, StoryQuestService 1119). 구분자는 언어별 키 `L10n.Join`(" · ")이다.
- **이름 키 도우미**(Config, 서버·클라 같이 씀): `Config.WeaponNameKey(tier, class, faction)`, `Config.ClassNameKey(class, faction)`, `Config.TitleKey(…)`, `Config.MonsterNameKey(kind)`. 모두 메시지 `{Key, Args}`를 돌려준다. 계산으로 만드는 이름도 키로 보낼 수 있다.

### 5-2. 규칙 — 플레이어가 읽는 서버 값에는 영어 문장이 없다
보내는 글·Fx·속성·저장·ProximityPrompt·서버가 만든 Gui의 `.Text` 모두 **id나 키**만 담는다. 예외: 키가 함께 가는 영어 사본 두 가지 — 알림의 대체 `Text`와 퀘스트 줄의 기록용 `Text`(§5-3, 클라는 키가 있으면 안 씀) — 와 §5-4. 서버는 글자를 쓴 Gui의 `.Text`를 나중에 다시 쓰지 않는다(클라의 한국어를 덮음).

## 6. 번역 표 `Shared/TextKo.luau` (B4 반영)
- 모양: `["<키>"] = { Ko = "한국어", En = "번역한 영어 원문" }`. 키 순서로 정렬한다.
- `L10n.Get`은 **`En` = 지금 영어일 때만** 한국어를 쓴다. 다르면(원문이 바뀜, 배열에 단계가 끼어 번호가 밀림 — 1,916개 중 925개가 배열 번호, StoryQuests만 692) 영어를 보여 준다. 엉뚱한 단계에 옛 한국어가 뜨지 않는다.
- 직접 고치지 않는다: `docs/l10n/strings_ko.json`(줄마다 `key`·`en`·`ko`) → `py tools/l10n_apply.py`가 쓴다.

## 7. 도구·파일 (S10 반영)
- 도구 하나: `tools/l10n_export.py`가 **Config + 등록된 클라 표**를 함께 뽑는다.
- 파일 한 쌍: `docs/l10n/strings_en.json` / `docs/l10n/strings_ko.json`. 지금의 `strings_server_en.json`은 `strings_en.json`으로 합친다. 세 문서에서 이름이 달랐던 것을 이것으로 맞춘다.
- 줄: `{ key, en, where, args(자리 종류 순서), named, max }`.
- 영어로 둘 글 목록은 `docs/l10n/keep_en.json`이다(게임 이름 같은 것).

## 8. 글자 그림 (S11 반영)
- 공용 판 그림(RibbonHeader·TitleRibbon·LogoPlate)은 글 없는 판이다. 모든 창 제목이 TextLabel로 올라가므로 부품마다 `IdKo` 하나로는 안 된다.
- **글 키로 매긴다:** `Config.UIArt.Lettering["HUD.TXT.Bag"] = { IdKo, Size }`. 언어가 ko이고 그 줄이 있으면 그림을 보여 주고 TextLabel 글은 비운다.

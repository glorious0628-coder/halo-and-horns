# 큰 모델 부품별 새로 만들기 — 부품 목록·접합 기준 (A23-107 보강, 이미지 생성 1 ↔ 이미지 생성 2, 2026-10-10)

> 기록용(일부 낡음) 10/11: 빛 마을은 처음부터 다시(A23-121, `halo_restart_2026-10-11.md`). §1 문·§3 대성당·§4 탑 표의 '탑 몸통·아치벽·돔을 Tripo 부품으로 만들어 조립'은 건물 몸통을 Studio 파트 골격으로 짓는 방식(A23-120)으로 바뀌었고, 성/대성당 돔 크기·'큰 금 돔'은 새 성(돔 없음)에 안 맞는다. Tripo는 4면 멀티뷰(A23-122) → Blender 손보기 필수(A23-125) → Roblox 재질. 아직 유효: 재사용 금지(종류마다 따로), 공통 기준(단위·피벗·접합면 평평), 실내 대비(진짜 문·창 따로·지붕/몸통/바닥 분리), §2 균형의 왕관 부품표.

검수 순서: 빛 마을 전체 질감 조각 나누기(1단계, 지금) → 부품별 새로 만들기(2단계): **문 → 왕관 → 대성당 → 탑**, 뿔 마을 성채는 그 구역 차례.
1단계(조각 나누기)는 같은 모델의 4096 원본 질감을 조각마다 1024로 쓰는 것이고, 2단계는 부품마다 2D(이미지 생성 2) → Tripo HD → WorldKit 조립이다.

## 재사용 금지 (검수 결정 10/10, sharpness_redo_list)
집 12채 = 12종, 가게 4 = 4종, 계단 3 = 3종, 작은 반복 소품·작은 다리 = 종류마다 3~5종 섞기, 좌우 짝도 각각 따로. 같은 모델을 복사·거울 뒤집기로 늘리지 않는다.

## 공통 기준 (모든 부품 그림·모델)
- **단위:** 스터드. 사람(아바타) 키 = 5.5스터드. 아래 크기는 조립 뒤 실제 크기(그림에는 사람 실루엣이나 자를 넣지 않음, 내가 맞춤).
- **피벗:** 부품 밑면 가운데. **앞 = Roblox -Z**(그림의 앞면 = 보는 사람 쪽).
- **그림:** 1024², 회색 바탕(BG_GRAY), 정면·뒤·왼쪽·오른쪽 4장(납작한 장식은 앞·뒤 2장), 같은 크기·같은 높이에 놓기(직교에 가깝게, 원근 약하게), 고급(High). 글씨 없음.
- **접합면:** 부품끼리 닿는 면은 **평평하고 단순하게**(장식 없이), 접합 높이·폭은 아래 표 숫자. 이어 붙는 면 쪽은 그림에 "flat plain joint face" 표현.
- **재질(A23-107 재질 보강):** 금·은 = 금속(Tripo PBR → SurfaceAppearance 금속도·거칠기), 보석·후광 고리 = 따로 부품(Glass/Neon), 유리창 = 따로 부품.
- **실내 대비(A23-106):** ① 문 = 문틀 + 문짝 따로, 진짜 뚫린 입구(높이 ≥ 8, 폭 ≥ 5스터드, 땅 높이), DoorFront 표시 ② 창문 = 따로 부품(유리, 밤 불빛) ③ 지붕·몸통·바닥 분리(몸통은 나중에 속 빈 벽 두께 판으로 바꿔 끼움).

## 5. 집·가게 (중간 크기) — 판단
질감 조각 나누기(2×2) + 장식 따로(간판·깃발 판)로 충분한지 같은 거리 크롭으로 보고 결정(이미지 생성 1). 문은 지금도 ×1.9~2.0 키워 사람이 드나드는 크기.

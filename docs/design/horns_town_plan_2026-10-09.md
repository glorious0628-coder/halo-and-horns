## 시안에서 읽은 것
- **보라 현무암 바위 고원 위의 전투 야영지.** 가운데 둥근 광장(자갈 포장 + 돌 테두리 **모닥불** + 통나무 의자), 둘레는 **뾰족 말뚝 울타리(상아 끝 + 붉은 띠)**, 모서리마다 **나무 감시탑(붉은 천 지붕 + 뿔 4 + 사다리 + 횃불)**, 큰 **붉은 전쟁 천막**(뿔 달림) + 붉은 차양 노점 + 통·상자·나무 탁자.
- **용암**: 고원을 두른 용암 강(해자) 2줄 + 보라 바위벽 위에서 떨어지는 **용암 폭포**(가운데·좌우), 바위 사이 틈마다 주황 빛 금. 건너는 곳 = **돌 아치 다리**(난간에 말뚝·등불·붉은 깃발).
- 문 = 네모 돌기둥 2개(상아 뿔 + 붉은 황소 문장 깃발 + 등불) + 가운데 말뚝 박은 통나무 들보. 길 양옆 화로(돌 받침 + 불).
- 나무 = 검은 침엽수에 붉은 띠. 바위 = 큰 보라 **현무암 기둥 덩어리**(육각 느낌, 윗면 둥글게 깎임), 일렬 금지.

## 땅 계획 (코드, `halo_terrain.luau`의 틀 재사용 → `horns_terrain.luau`)
- 존: x -200..200, z 330..700 (Zones.HornsTown 중심 (0,515), 스폰 (0,0,420), 문 (0,0,330), 성 (0,630)). 계약: 문 끝·스폰 (0,0,420)·다리 판은 Y 0.2 그대로, 스폰 도로는 평지.
- **가운데 고원**: 광장 지름 ~110 (중심 (0,-,480)) 높이 0.2 → 성 쪽(z 560~690)으로 한 단 +6(완만 램프). 둘레 용암 해자 폭 16~22(바닥 -4, **CrackedLava 칠**; 지형엔 용암 액체가 없어서 바닥 용암 칠 + 주황 네온 파트/Light로 흐르는 느낌), 바깥은 바위 고리(Basalt 높이 8~16, 윗면 둥글게, 일부는 육각 기둥 파트).
- **용암 폭포 3곳**: 좌·우 바위벽 위에서 해자로(빛 마을 폭포와 같은 파트식, 색 주황 + 스크롤 텍스처 `Tex_LavaFlow` 필요), 가운데 안쪽 벽 1.
- 다리: 문 앞 2 + 좌우 2 = 아치 돌다리 4(저장소 속성 Bridges에 자리·높이 기록, 빛 마을 방식).
- 재질: 광장 윗면 = Cobblestone(GE_Cobblestone 이미 있음), 바위·절벽 = Basalt(GE_Basalt), 해자 바닥·틈 = CrackedLava(GE_CrackedLava), 가장자리 풀 없음(보라 바위 + 검은 침엽수).

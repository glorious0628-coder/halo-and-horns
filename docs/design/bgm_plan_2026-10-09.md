## 규칙
- 아이(8~12세)용: 무섭거나 아픈 소리 없음, 종교 느낌(교회 종·성가) 피함, 가사·목소리 없음(악기만).
- 효과음과 겹치니 음악은 **효과음보다 작고 몸통이 중간 대역**(250 Hz~3 kHz), 목표 크기 -22 LUFS 안팎(효과음 -17).
- **이음새 없는 루프:** 길이를 BPM에 맞춘 정수 마디로 자르고, 끝→처음을 등력 크로스페이드로 이어 붙여 `Sound.Looped=true`에서 틱 소리가 없게 한다. 확인은 끝 2초+처음 2초를 이어 붙인 파형·귀로 한다.
- **보스 층:** Firefly 곡끼리는 박자가 안 맞을 수 있어서, 보스 층은 우리가 합성(북·저음 맥박, numpy)해서 각 곡의 BPM·마디 길이에 정확히 맞춘다. 곡 8개 모두에 같은 층을 BPM만 바꿔 쓴다. 보스 때 게임성 개발 1이 곡과 층을 같은 `TimePosition`에서 같이 재생한다(둘 다 같은 마디 길이라 항상 맞음).
- 출처 장부: `docs/devlog/sfx_licenses.md`에 음악 절 추가(Firefly 생성 날짜·프롬프트 파일·크레딧). 출처 모르는 무료 모음 금지.

## 출처 선택
- **Roblox Creator Store 무료 음악:** 검색해 보니 DistroKid 업로드 같은 개인 곡이 대부분이고 루프 여부·사용 허가가 불분명 → 기본 후보에서 뺀다. 공식 Roblox 제공 음악이 따로 있으면 그때 확인.
- **Firefly 음악 만들기(Generate Soundtrack):** 악기 배경 음악, 5초~5분, WAV, 상업 이용 안전(Adobe 안내). 이게 기본 길. 화면의 크레딧·길이 제한·참고 음악 올리기 여부는 창이 보이면 확인해서 검수에 보낸다.
- 합성(직접): 보스 층, 필요하면 곡 짧은 변형.

## 진행 순서
1. Firefly 음악 화면 확인(크레딧/곡, 길이, 변형 수) → 검수에 "곡 수 × 크레딧" 보내고 '예' 받기.
2. 빛 마을부터 한 곡씩 후보 2~3개 → 루프 자르기 → 파형·귀 확인 → 후보 시트로 검수에 보냄.
3. 검수가 고르면 wav로 업로드(Creator Hub, Darugi_S2) → `art/sfx/asset_ids.json`의 `bgm` 절에 id → 게임성 개발 1에 전달.
4. 보스 층 합성 → 같은 방식.

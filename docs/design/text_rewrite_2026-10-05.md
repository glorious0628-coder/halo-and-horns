## 말투 규칙 (모든 새 문구에도 적용)
- **빛의 안내자:** 따뜻하고 반듯한 기사, 해요체. 감탄은 한 줄에 하나만. "당신", "~랍니다", 교훈으로 끝나는 문장 금지. 부탁은 "도와줄래요?"처럼.
- **뿔 군단 안내자:** 장난스럽고 거친 선배, 반말("신입", "~거든", "~하자"). 놀려도 욕이나 비꼼은 없다. 남을 털라고 부추기는 말은 PvP 퀘스트 안에서만 쓴다.
- **장인 길드 안내자:** 말수 적은 장인, 짧은 반말에 무심한 농담.
- **장비 상인 C:** 지친 베테랑. "흠…"으로 시작하고 느낌표는 쓰지 않는다.
- **왕관 조각:** 호기심 많은 아이 같은 반말. **분수의 조각:** 차분한 반말.
- **시스템 알림:** 말하는 사람 없이 짧게 쓴다. 모든 줄을 "~요!"로 끝내지 않는다. 느낌표는 좋은 순간에만 붙인다. 보상은 "+N골드 · +N 경험치".
- **서버 전체 공지:** 오프닝 자막처럼 다체 헤드라인으로 쓰고, 이름 뒤 조사는 피한다("%s, 전설 무기를 얻었다!").
- **금지:**
  - "모험가님", "여정", "함께해요", 괄호로 규칙 설명하기
  - "을(를)/이(가)/(으)로" 같은 괄호 조사(지금 코드에 32곳 남아 있음)
  - "메뉴 > 이동 >" 같은 경로 안내: 퀘스트 줄을 누르면 길 안내 빔이 대신한다
  - 같은 어미 반복("~할 수 있어요"가 연속으로 나오는 것)
- **용어 고정:**
  - 일일 퀘스트(첫 임무·이야기만 "임무"), 왕 슬라임, 자동 전투("자동 공격" 아님), 변경권, 원한 자루, 현상수배 별, 금고·주머니, 대장간 모루, 교차로 마을
  - 영어: Halo Knights / Horns Legion / Artisan Guild / Crown Shard / Enhance·Transfer Scroll / Bank·Pocket / Grudge Sack / Bounty / Kaiju / Altar of Fate
- **대사는 실제 규칙과 맞춘다.** 검토자가 찾은 어긋난 예: 고블린이 골드를 훔친다는 대사, 길드는 아무도 못 때린다는 대사, 미리보기 문장의 과거형.

## 여러 언어 (조사 결과와 추천)
- **지금 구조로는 Roblox 자동 번역을 켜도 거의 번역되지 않는다.**
  - 자동 번역은 화면에 고정된 글자만 모은다. 스크립트가 숫자를 넣어 만든 문장은 모으지 않는다(공식 문서).
  - 우리 문구는 거의 전부 서버가 숫자를 넣어 완성해서 보낸다. 서버 알림 호출만 155곳이다.
- **한국어는 반드시 직접 쓴다.** 영어를 한국어로 자동 번역하면 글자가 깨지는 버그가 2025-08부터 신고돼 있다.
- **추천:**
  1. **베타: 한국어 + 영어 직접 작성.** RELEASE_PLAN 컷라인(10/24)을 지킨다.
  2. **정식: 스페인어·포르투갈어(브라질)·일본어·인도네시아어**를 초벌 번역한 뒤 사람이 검수한다. 유료 검수는 사용자 승인이 필요하다.
  3. **그 밖의 언어는 Roblox 자동 번역만 쓴다(검수 없음).** 대상: 프랑스어·독일어·이탈리아어·폴란드어·러시아어·튀르키예어·베트남어·중국어 간체/번체. 태국어·힌디어는 줄 높이 검사를 통과한 뒤에 켜고, 아랍어(오른쪽에서 왼쪽)는 나중이다.
- **기술 계획(작업 세션):**
  - 문구를 키로 관리하는 중앙 표를 만든다. 예: `Config.Text` → `L(key, args)` 한 곳에서 `Player.LocaleId`에 맞는 문장을 고른다.
  - 서버는 완성된 한국어 대신 `{Key, Args}`를 보내고, 클라이언트가 그 플레이어의 언어로 만든다. 155곳을 순서대로 옮긴다.
  - 괄호 조사는 언어별 문장 틀로 바꾼다. 자리표시는 이름 있는 형태(`{name}`)로 바꿔 언어마다 순서를 바꿀 수 있게 한다.
  - Studio 로케일 에뮬레이션으로 ko·en 화면을 캡처해 둔다.
  - 글꼴: 한글·일본어·중국어는 Roblox 기본 CJK 대체 글꼴로 나온다. Gotham은 2024-05에 Montserrat로 바뀌었다. Jua는 승인 그림 안에만 있다.
- 순서: 문구 다시 쓰기(이 표)를 먼저 적용하고, 키 구조는 그다음에 만든다. 영어는 키 구조와 함께 넣는다.

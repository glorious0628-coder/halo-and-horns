# 인기 Roblox 게임 6개 뜯어보기 (2026-10-10, 조사 세션)

앞선 분석 `docs/design/rpg_success_analysis_2026-10-08.md`는 45개 게임의 '왜 됐나'였어요. 이 문서는 **지금 차트에 있는 6개**를 숫자와 상품 목록까지 내려가서 봐요. 거기 있는 내용(Blox Fruits 역사, PS99 토요일 업데이트 등)은 되풀이하지 않아요.

## 0. 어떻게 조사했나 (그리고 못 한 것)

**한 것 (모두 공개 자료, 읽기만, 로그인·계정 행동 없음):**
- roblox.com/charts (2026-10-09 한국·PC 차트).
- Roblox 공개 웹 API: 접속자(playing), 방문, 즐겨찾기, 좋아요/싫어요, 마지막 업데이트 시각, **게임 패스 목록과 Robux 값**, **배지 목록과 '받은 사람 수'**, 만든 그룹 설명.
- DevForum 공지 1건(홈 추천 방식).
- 유튜브: 검색 결과, 영상 설명, 영상 화면 몇 장(소리 끔, 멈춤).
- 보조: 팬 가이드 글 검색 요약. 이것은 **2차 자료**라서 '첫 10분'에만 쓰고 표시했어요.

**못 한 것 (솔직하게):**
- 개발자 상품(Developer Product)은 공개 API가 없어 **목록을 못 봤어요.** 아래 상품표는 게임 패스만이에요.
- 게임 안 구매 버튼 위치는 **직접 못 봤어요.** 추측하지 않고 비워 뒀어요.
- 유튜브 자막이 이 브라우저에서 열리지 않았어요. 영상 속 화면은 3장만 봤어요. UI 얘기는 그래서 얇아요.
- 우리가 직접 플레이한 게 아니에요. '첫 10분'은 팬 가이드 + 배지 순서에서 읽은 것이에요.

**쓰지 않은 것:** 익스플로잇, 실행기, 디컴파일, 스크립트 덤프, REA/Ghidra, 남의 place 파일. 앞으로도 안 써요.

## 2. 게임별

### 2-1. 99 Nights in the Forest (생존·협동, 약 23만)

**왜 지금 인기:** 이 6개 중 접속자 1위. 핼러윈 이벤트 시기예요(팬 글: 새 업데이트 10/18 예고, 날짜는 글마다 달라 **불확실**). 영상 소개 예시로 Roblox 공식 글(DevForum)에 이름이 올랐어요.

**첫 10분 (팬 가이드, 2차):** 캠프파이어가 안전 구역. 낮에 나무·고철을 모으고, 밤에는 불 곁에 있어요. 먼저 지도를 만들라고 권해요. 사슴(Deer) 같은 못 이기는 적은 불빛으로 피해요. 직업(Class)은 게임 안 다이아로 사요(40~600). **튜토리얼이 길을 알려 주는지는 못 봤어요.**

**화면(영상 3장 중 확인):** HUD가 거의 없어요. 위 가운데 'Day 2' 글자 하나, 왼쪽 아래 주황 허기 바 하나, 손에 든 도구. 물건에는 **판 없이 떠 있는 글자 라벨**('Red Key')만 있어요. 말풍선·안내 판 없음.

**핵심 루프:** 낮에 자원 → 캠프 불 업그레이드 → 밤을 버팀 → 날짜(Day)가 올라감. 목표는 99일.

**돌아오는 이유 — 배지가 데이터예요(평생 받은 사람 수):**
| 배지 | 받은 수 | day10 대비 |
|---|---|---|
| survive 10 days | 3.96억 | 100% |
| 20일 | 2.72억 | 69% |
| 30일 | 2.02억 | 51% |
| 50일 | 1.36억 | 34% |
| 100일 | 0.86억 | 22% |
| Determined I (250일) | 2,975만 | 7.5% |
| Determined II (500일) | 1,035만 | 2.6% |
- **가장 많이 받은 배지는 'Firemaking I(불을 Lv3으로)' 7.1억 개**예요. day10(3.96억)보다 많아요. 즉 **눈에 보이는 물건을 곧바로 올리는 목표**가 가장 먼저 닿는 목표예요.
- 배지 57개가 **'기능 가르치기 사다리'** 역할이에요. 제목마다 한 가지를 하게 해요: Combat(캠프 지키기), Gardening(씨앗 사기), Taming(동물 길들이기), Crafting(작업대 Lv4), First Aid(쓰러진 동료 살리기).
- **도전 배지**가 돈 없이 다시 하게 만들어요: Swiftness(99일을 90분 안에, 5,720만), Durability(한 번도 안 죽고, 3,594만), 고기 안 먹기, 구조 안 하기, Teamwork(5명, 875만), Dream Team(5명+90분+무사망, 2.6만). '비밀 행동' 배지 Humiliation은 4,282만이에요.
- 일일 퀘스트는 **평생 횟수 배지**(10회 485만, 50회 36만, 100회 8.8만). 연속 일수가 아니에요.

**돈 (게임 패스):**
| 패스 | Robux | 비고 |
|---|---|---|
| Decorator Pass | 199 | 기지 꾸미기 도구 |
| Diamond Hunter Pass | 판매 중지 | 2025-12 생성, 지금은 안 팖 |
| Ranger Class / Medic Class | 판매 중지 | 지금은 다이아(게임 안 돈)로만 얻음 |
- 힘 패스가 거의 없고, 직업도 게임 안 돈으로 사요. 개발자 상품은 못 봤어요.

**나쁜 점:** 좋아요 90.5%로 6개 중 최저. 서버는 최대 25명. 사슴처럼 '못 이기는 적'이 있어 아이에게 무서울 수 있어요(추측).

### 2-2. Blox Fruits (사냥·열매, 약 19.6만)

**왜 지금 인기:** 7년 된 게임인데 이 6개 중 접속자 2위. 설명 첫 줄이 'OUT NOW: 자석 + 바다 1 + MORE' 같은 **업데이트 알림판** 역할을 해요. 레벨 상한(3000)과 FAQ(열매는 1시간마다 나오고 20분 뒤 사라짐, 딜러는 4시간마다 재고)가 설명에 있어요. 서버는 12명.

**첫 10분 (팬 가이드, 2차):** 시작 섬에 열매도 무기도 없이 들어와요. 맨손 + 나무 칼. 퀘스트 NPC가 레벨 구간마다 있어요. 레벨 10까지 집중하면 약 8분이라는 글이 있어요(한 사람의 추정). 스탯은 처음엔 한 곳에 몰아 주라는 조언이 많아요. 열매 딜러는 처음엔 너무 비싸요. **튜토리얼이 없다**는 평이 많아요(앞선 분석과 같음).

**핵심 루프:** 퀘스트 → 사냥 → 레벨 → 다음 섬 → 열매·검 → 바다 이동(1→2→3).

**돌아오는 이유:** 열매가 매시간 맵에 나옴, 딜러 재고 4시간마다. 배지는 달랑 2개(Second Sea 9,740만, Third Sea 6,059만): 3바다까지 간 사람이 2바다 도착자의 약 62%예요.

**돈 (게임 패스 6개):**
| 패스 | Robux |
|---|---|
| Dark Blade (신화 검) | 1,200 |
| 2x Money | 450 |
| 2x Mastery | 450 |
| Fruit Notifier (열매 생기면 알림+거리) | 2,700 |
| Fast Boats | 350 |
| 2x Boss Drops | 350 |
- **돈 쓰기 쪽 힘:** 검 판매, 보스 드롭 2배. **편의:** 알림·배.
- 우리 패스(경험치 199·골드 149)보다 2배 패스 하나가 2~3배 비싸요.

**나쁜 점:** 최고 레벨까지 수십 시간, 돈으로 힘을 사는 패스(검·드롭), 거래 사기, 열매 알림을 2,700에 파는 것('정보를 파는' 느낌).

## 3. 6개를 합쳐서 보이는 것

1. **돈 쓰는 곳은 '운'이 많아요.** 패스로 운·확률을 직접 파는 게임이 PS99(7개)와 Loot Forge(4개)예요. Anime Zero와 Slayers 2는 뽑기(스핀·가문)가 성장 중심이고, 99 Nights와 Blox Fruits는 운 패스가 없어요. 우리는 이걸 **안 해요**(GDD §10-1, A23-75). 그래서 값을 올릴 방향은 '운'이 아니라 **편의·치장·이름표**여야 해요.
2. **'연출 건너뛰기'가 상품이에요.** Loot Forge 29, Anime Zero 149. 사람들이 연출을 기다리기 싫어한다는 증거예요. 우리는 이걸 **공짜 설정**으로 줄 수 있어요(아래 4번).
3. **패스 가격대:** VIP 349~499, 2배 패스 450, 싼 편의 29~175. 우리(VIP 249, 경험치 2배 199, 골드 2배 149, 치장 99)는 **아래쪽**이에요. (아래 5번, 사용자 결정)
4. **99 Nights의 HUD는 비어 있어요.** 일수 + 허기 바 + 월드 라벨이 전부. 우리 A23-99(덜 친절한 화면)와 같은 방향이에요.
5. **배지가 공짜 퍼널 지표이자 목표 목록이에요.** 누구나 볼 수 있는 숫자(받은 수)로 경쟁작의 이탈 곡선이 보여요. 우리 배지의 받은 수도 남이 볼 수 있어요.
6. **DevForum(홈 개선 공지):** 홈 추천에 **'7일 안 적격 플레이 세션 수'**와 **'깊은 플레이 완주율'** 신호가 들어갔고, **게임 페이지 플레이 영상**이 추천 칸에서 바로 재생돼요(공지의 테스트: 추천에서 플레이 시간 최대 +39%, 'Standout Games'에서 품질 플레이 +47%). 영상은 **지금 게임 안 모습만**, 목소리·해설·가사 있는 음악·홍보 글·영화 같은 예고편은 거절될 수 있어요. 우리 '다시 오게 하기'(A23-77·79)가 추천에도 도움이 된다는 뜻이에요.

### 4-1. 이미 맞게 가고 있어서 새로 할 필요 없는 것
- **눈에 보이는 가까운 업그레이드 목표**(99 Nights Firemaking I가 1위 배지): 우리는 첫 무기 대장간(A23-74)과 주문서가 같은 역할을 해요. 확인 질문 하나: **첫 5분 안에 '올릴 물건'이 보이나?** (메인 반영 1의 PC 플레이로 확인).
- **자동 전투를 안 판다:** PS99는 Auto Tap·Auto Farm을 팔아요. 우리는 퀘스트로 줘요(계속 유지).
- **덜 친절한 화면:** 99 Nights HUD가 이미 이 방향의 성공 사례예요.
- **핼러윈 사탕 → 칭호, 11/09 뒤에도 열림**(A23-79 #4): 99 Nights는 사탕으로 '한정 상점'을 열지만, 우리는 한정 압박 없이 가요.
- **편의 패스, 힘 없음**(Slayers 2): A23-72와 같은 결이에요.

## 5. 따라 하지 않을 것 (규칙 때문에)
- 운·확률 패스(Luck, Huge Hunter, Super Shiny…): 뽑기 규칙.
- 검·드롭 2배 같은 **힘 패스**(Dark Blade 1,200, 2x Boss Drops): 스탯 판매. (경험치·골드 2배는 A23-75가 이미 허용.)
- 돈 쓴 사람에게 주는 배지(Loyal Spender): 번 모양 ≠ 산 모양.
- 열매 알림 같은 **정보 판매 2,700**: 덜친절 규칙과도 반대.
- 못 이기는 무서운 적(사슴): 아이 대상.
- 클릭 반복 중심(Loot Forge): 우리는 '덜 지루하게'이지 '반복 없음'이 아니에요(메모리: grind less, not none).
- 즐겨찾기를 보상으로 묶는 유도(추정): 정책이 불분명하고 아이에게 부담이에요.

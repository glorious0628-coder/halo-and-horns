### 1-3. 이 퀘스트 줄의 특징
- **보상이 바로 다음 단계 재료예요.** 고블린 피 → 팔기 / 돌 → 돌검 / 철 → 철검. 헤매지 않고 이어져요. [자막에서 읽은 흐름]
- **퀘스트마다 마을 서비스 하나를 가르쳐요.** (전당포, 제작소, 강화소, 연금술사, 분해) [자막]
- **골드가 빨리 커져요:** 1,000 → 2,500 → 5,000 → … → 100,000 → 150,000. 첫 보상이 2번째 퀘스트(약 2분)에 와요. [화면·자막]
- **약한 점:** 길 안내 화살표가 없어서 영상 속 플레이어도 "사냥터가 어디지?" 하며 돌아다녀요 [화면 + 자막]. 돌검 대기 60초가 길다는 반응도 있어요. 영어는 구글 번역이라 글이 틀린 곳이 많아요. [자막]
- 2026-09 업데이트 전에는 **일일·주간 퀘스트가 없었어요.** 유튜버가 계속 달라고 했고 그제서야 생겼어요. [자막]

## 2. 전투

- 조작: WASD 이동, **Q 대시(마나 5)**, 왼클릭 공격, 스킬 E·R·T, 물약 1·2·3 [자막]
- **수동 전투만** 보여요. 자동 전투 기능은 못 봤고, 매크로는 밴이라고 해요. [자막] 유튜버가 오토 마우스를 써서 "밴됐어?" 농담하는 장면도 있어요.
- 스탯 점수 4가지: HP, 데미지, MP, 방어. 레벨마다 점수를 줘요. 한 스탯에 50점 쌓일 때마다 점당 효과 +10%. [자막]
- 스킬은 **스킬북(드랍)**을 써서 배워요. 최대 3개 장착, 패시브는 자동. 스킬 이름 아래 마나 값이 보여요. [자막·화면]
- 스킬은 **각성**해요(예: 낙화참 → 낙화참·만개, 약 2,500번 써야 변해요). [자막]
- 몬스터 공격은 **바닥 빨간 범위 표시**로 알려줘요. 때리고 → 대시로 피하기가 기본 요령이에요. [자막]
- 피해 숫자: 흰 글씨 + 검은 테두리로 떠요. **콤보 숫자**("콤보 10")도 떠요. [화면]
- 큰 스킬 이펙트가 화면을 꽉 채워요(가는 흰 선이 퍼지는 모양 포함). [화면] → 우리는 빛살 무늬 금지라 이 모양은 따라 하지 않아요.
- 보스 피해가 **7% 미만이면 보상이 없어요**(9월 업데이트로 4%로 내려간 것으로 들림). [자막]
- 모바일 조작: 영상에서 못 봤어요. 9월에 "모바일 상점 구매 버그"가 있었다는 말만 있어요. [자막]

## 3. 성장 루프

- 레벨: 1세계 끝 부근 55, 현재 랭킹 1위 약 149레벨(2026-09). [자막]
- **마나 코어**(2세계부터): 코어 레벨 1마다 모든 스탯이 오르고 스탯 점수도 줘요. 코어 레벨은 마력 정수·마나석 같은 재료로 올려요. 코어 랭킹도 있어요. [자막]
- 장비: **무기**(1개 장착) + **액세서리**(3개 장착) + 칭호 + 특성(레벨 50부터). 방어구는 못 봤어요. [자막]
- **무기 품질 %**: 만들 때마다 굴려져요(예: 62~124 사이). 높을수록 데미지가 커요. 같은 무기 2개를 합쳐 품질을 올리는 "품질 재조합"이 있어요(최대 100%). [화면·자막]
- **강화**: +1씩 올라요. +7부터는 실패하면 한 단계 내려가요. 보호권을 쓰면 안 내려가요. [자막]
  - 높은 단계(+49→+50)는 성공률이 약 0.05%라서 **약 4,500번**이 나와야 천장(확정)이에요. 한 유튜버는 약 11억 골드 + 보호권 171장을 썼어요. +50 무기 한 방 약 15,000 데미지. [자막]
- 제작: 전리품 + 골드 + 대기 시간으로 만들어요. 대기를 건너뛰는 게임 패스가 있어요. [자막]
- 노가다 정도: 한 유튜버가 보스 하나를 약 21,000마리 잡았다고 해요(한 달 이상). [자막]
- 대시 업그레이드는 숨은 NPC에게 25,000골드를 내고 대시 500번을 해야 해요. [자막]

## 4. 월드

- 1세계(루나 타운 → 고블린 마을 → 동굴(골렘) → 용암 호수 → 사막(슬라임·미라·피라미드) → 지옥 같은 나락 → 단풍 숲(무사) → 눈 지역 → **겨울 성 1·2·3관**(레벨 50·52·55)). [자막]
- **2세계(2차원)**: 레벨 60 + 겨울 성 보스 재료 + "알 수 없는 스킬/종이"로 사막 피라미드에서 포털을 열어요. 아틀란티스는 2세계 마지막 지역이에요(2026-02쯤). 3세계 준비 중이고 마나 코어를 대신할 새 시스템이 온다고 해요. [자막]
- 보스: 구역 보스 + **월드 보스**(플레이어 수에 따라 체력, 절반에서 무적 단계). 4시간마다 나오게 계획, 일부 서버에만 나와요(희귀하게). [자막]
- 레이드: 사막 레이드, 용암 동굴 레이드 입장권. [자막·화면]
- 텐트로 **부활 지점**을 정해요. [자막]
- 구역이 열리는 조건 = **레벨 + 아이템 + 보스 재료**예요(예: 40레벨에 눈 지역). [자막]

## 5. 소셜

- **거래**: 게임 안 거래창(9월에 새로 만들어 위쪽에 뜸) + 디스코드 거래 서버. [자막]
- 유튜버가 매주 **"가치표"**(아이템 값 목록) 영상을 올려요. 시세가 매일 변해요. [자막]
- **파티·길드·PvP는 아직 없어요.** 길드는 1주년 업데이트에 예고, 1:1 결투도 계획 중이에요. [자막]

## 가져오면 안 되는 것

- **강화 보호권·소환권을 로벅스로 팔기.** 돈 낸 사람이 강해져요(스탯을 안 판다는 A23-75와 충돌). 소환권(120 R$)은 "보상 상자를 돈으로 여는 것"이라 더 위험해요.
- **극단 확률(0.05%) + 수천 번 천장.** 아이에게 도박 느낌이에요. 우리는 10/30/70%, 파괴 없음.
- **보스 2만 마리 같은 벽.** 우리 원칙은 "노가다는 덜, 없애진 않기"예요.
- **플레이어끼리 쓰는 아이템 돈(보호권 시장).** 디스코드 거래·"가치표" 문화는 사기·현금 거래로 번져요. 우리는 서버가 확인하는 거래소만 써요(A23-127·133).
- **한정 이벤트 상점에 능력 아이템 넣기.** 놓치면 영영 못 얻는 힘은 불공정해요.
- **구글 번역 글.** 틀린 글이 많아서 욕먹어요. 우리는 글을 중앙 표로 관리하고 번역 검수(L10n).
- **빛살 무늬 스킬 이펙트.** 화면 꽉 찬 가는 선이 퍼지는 모양은 우리 규칙상 금지.
- **디스코드에만 공지·관리.** 사고가 나면 소통이 끊겨요. 게임 안 공지를 같이 쓰기.
- **너무 작은 UI.** 유튜버가 "클릭하기 힘들다"고 했어요. 우리는 글자 최소 크기 규칙(텍스트 constraint)을 지켜요.
- **돈을 쓰면 더 빨리 강해지는 2배 보호권류.** (2배 XP·골드 패스는 이미 결정(A23-75). 보호권처럼 능력에 가까운 것은 안 함.)

### UI 아이디어 상위 5 (우리 규칙 지킴: 승인된 그림만, 글 짧게, 빛살 금지)

1. **퀘스트 줄에 보상 칩 + 진행 막대**
   - 방법: 기존 코인 아이콘·바 부품(`Config.UIArt.Parts`, `UIKit` 대체)만 사용. 글은 "+150" 같은 숫자뿐.
   - 비용: 작음. 베타 전.
   - 규칙: 보상은 A23-99가 남기라고 한 것. 새 그림 없음.
2. **보스 기여 % 칩**(둥근 작은 칩, 기준 미만 = 빨강, 이상 = 흰색)
   - 방법: 이름표 아래 숫자만. 새 문장 없음.
   - 비용: 작음~중간(서버가 피해를 이미 세는지 확인 필요). 베타 전(A23-137 보스 경쟁).
   - 규칙: 둥근 칩만, 빛살 없음.
3. **퀘스트 창 탭 + 초기화 시간**(Main · Daily · Weekly 또는 지금 종류 이름 그대로)
   - 방법: 기존 퀘스트 창 탭 부품 재사용, 시간은 숫자(예 10h 21m).
   - 비용: 작음. 베타 전.
   - 규칙: 안내 글 늘리지 않기. 타이머는 정보라서 허용(검수 확인).
4. **가방 검색칸 + 무기 품질 바**
   - 방법: 검색칸은 기존 입력 부품. 품질 바(빨강 → 초록)는 새 그림이라 **먼저 승인 필요**(Firefly 부품 1개). 품질 시스템이 없으면 검색칸만.
   - 비용: 검색칸 작음(베타 후), 품질 바 중간(시스템 + 그림).
   - 규칙: 승인된 그림만. 품질 시스템은 새 규칙이라 사용자 확인.
5. **이벤트 상점 2×2 카드**
   - 방법: 기존 상점 카드를 4칸으로 재사용, 가격 = 이벤트 재화 아이콘 + 숫자, 구매 한도 "0/1".
   - 비용: 중간. 베타 후(겨울 행사).
   - 규칙: 꾸미기·편의만 판매. 새 그림은 재화 아이콘 1개(Firefly 승인 필요).

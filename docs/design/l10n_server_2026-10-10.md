# 한국어 모드 — 서버 글 설계 (게임성 개발 3, 2026-10-10, SPEC A23-111)

순서: **빛 마을 끝난 뒤 구현**(사용자 같은 날). 지금은 설계 + 글 목록 뽑는 도구(`tools/l10n_export.py`)만. 클라 쪽 장치는 개발 1의 `docs/design/l10n_client_2026-10-10.md` — 이 문서는 그 계약에 서버가 맞추는 방법이다.

## 1. 지금 서버 글이 어디서 나오나 (실측)
- `py tools/l10n_export.py` → `docs/l10n/strings_server_en.json`: 플레이어가 보는 영어 글 **1,792줄 / 서로 다른 글 1,610개 / 약 5만 자**. 큰 곳: StoryQuests 약 740, Text 135, Barks 127, TownReact 66, Tutorial 60, Settings 57, Help 55, Loot 49, Ranking 46, Skills 44, Announce 43, TitleDefs 42, Board 41.
- 서버 코드에 **직접 박힌** 영어 알림은 9곳뿐(CombatService·QuestService·VitalsService의 `Net.Notify(player, "…")`, 총 알림 호출 52). 나머지는 모두 `Config.*.Text` 표(`TXT.X`)에서 `string.format`으로 만들어 보낸다.
- 보내는 길목: `Net.Notify`(알림·보상·퀘스트 완료), `Net.Announce`(공지), 퀘스트 줄 `QuestService.publish`(행 `Text`), `OpenPanel` 이야기 카드 `Lines`, 칭호·랭킹 이름 속성.

## 2. 플레이어 언어
> **대체됨 — `docs/design/l10n_contract_2026-10-11.md` v2(검수 승인 조건 반영, 2026-10-11).** 아래는 기록용.
- 플레이어 속성 **`Lang`** = `"en"`/`"ko"` (개발 1 문서와 같은 이름). 서버가 정한다:
  1. 저장된 `Settings.Lang`이 `en`/`ko`면 그것.
  2. `Auto`(기본)면 `player.LocaleId`(서버에서 읽히는 속성)가 `ko`로 시작하면 `ko`, 아니면 `en`. — 클라가 LocaleId를 알려 줄 필요 없음.
  3. 설정에서 바꾸면(SetSettings 경로 그대로) 같은 자리에서 `Lang`을 다시 정해 속성을 바꿈 → 클라 `UIKit.LangChanged`.
- 읽는 곳은 한 함수: `L10n.Lang(player)`(속성이 없으면 `"en"`). `Shared/L10n.luau` 한 파일을 서버와 클라가 같이 씀(Shared에 두는 이유: 같은 글 표를 둘이 읽는다).

## 3. 글 표와 키
> **대체됨 — `docs/design/l10n_contract_2026-10-11.md` v2(검수 승인 조건 반영, 2026-10-11).** 아래는 기록용.
- **키 = Config 안의 경로**: `Config.Text.PotionBought`, `Config.StoryQuests.Defs.KO1.Steps.3.Text`, `Config.Barks.Lines.BigSlime.Hit.1`. `tools/l10n_export.py`가 정확히 이 키로 영어 글을 뽑는다(리스트 칸은 1부터 번호).
- 한국어는 코드 옆 표가 아니라 **한 파일** `Shared/TextKo.luau` = `{ ["<경로>"] = "한국어", ... }` (개발 1 문서와 같음). 없으면 영어로 — 빈 글·깨진 글이 나갈 일 없음.
- 자리표시자(`%s %d %.1f {Auto}`)는 **순서·개수가 영어와 같아야** 한다(순서가 바뀌어야 하는 문장은 `{1}`·`{2}` 이름 자리로 바꿔 쓰고, `L10n.Fmt`가 둘 다 받음). 시험이 `args`가 같은지 본다.
- 길이 어림 `max`(영어 글자 수 × 1.3, 8 이상)를 export가 줘서 번역이 칸을 넘지 않게 한다. 폰 한 줄 이름(`ShortName`)은 14자 이하 규칙 그대로.

## 4. 서버가 글을 만드는 방법 — 두 길 (같이 씀)
> **대체됨 — `docs/design/l10n_contract_2026-10-11.md` v2(검수 승인 조건 반영, 2026-10-11).** 아래는 기록용.
**A. 새 글·옮기는 글 = 키로** (권장): `L10n.T(player, "Config.Text.PotionBought")`가 그 사람의 언어 틀을 돌려주고 바로 `string.format`/`L10n.Fmt(player, key, ...)`. 이미 `TXT.X`를 쓰는 서비스는 `TXT` 대신 `L10n.Of(player, TXT_ROOT)`(경로 앞부분을 붙여 주는 도우미)로 바꾸면 줄 하나씩 옮길 수 있다. 서버가 `{ Key, Args }`만 보내고 클라가 `UIKit.Tx`로 만드는 길은 개발 1 문서 6절 — 새 알림은 이쪽이 더 낫다(말 중에 언어를 바꿔도 알림 기록이 맞음).

**B. 안전망 = 보내는 길목에서 영어 글 → 사람 언어** (호출 자리 안 바꿈): 서버가 시작할 때 `Config`를 한 번 걸어서 `영어 틀 → 경로` 색인을 만든다(`%s`/`%d` 자리는 자리표시자로 바꾼 정규식, 맨 앞 글자 몇 개로 묶어 찾는 속도 확보). `Net.Notify`·`Net.Announce`·퀘스트 행·이야기 카드 `Lines`가 나가기 직전에 `L10n.Translate(player, englishText)`를 한 번 거친다:
  1. 받는 사람이 `en`이면 그대로.
  2. 영어 글이 색인에 있는 틀과 **딱 한 개** 맞으면 `TextKo[경로]`에 맞아 들어간 값들을 끼워 한국어로. 값이 그 자체로 이름 글(몬스터·지역·직업 이름 등 `Name`/`Short`/`Title`)이면 그것도 한국어로.
  3. 한 개도 안 맞거나 둘 이상 맞으면(애매) 영어 그대로 + 개발용 경고 한 번.
 장점: 서비스 열 몇 개를 건드리지 않고도 첫날부터 대부분 한국어가 됨(모르는 건 영어로 남을 뿐 틀리지 않음). 단점: 글을 `..`로 이어 붙인 문장(예: "Bright: " + 줄)은 안 맞음 → 그런 곳만 A로 옮김. 시험이 "export된 모든 영어 글(예시 값을 끼워)이 자기 경로에 유일하게 맞는다"를 본다.

## 5. 서비스별 일 (개발 2에게)
> **대체됨 — `docs/design/l10n_contract_2026-10-11.md` v2(검수 승인 조건 반영, 2026-10-11).** 아래는 기록용.
- 규칙은 지금과 같다: **글은 중앙 표(Config … Text)에 두고** 서비스는 `TXT.X`로 꺼낸다 — 표에 있기만 하면 B가 번역해 준다. 새 글을 코드에 직접 박지 말 것(직접 박힌 9곳은 내가 표로 옮김: CombatService·QuestService·VitalsService).
- 문장을 이어 붙이지 말고 한 틀로(`"%s: %s"`처럼) 두 칸에 나눠 쓰면 B가 못 맞춘다.
- 이름(몬스터·아이템·지역)은 `Name`/`Short` 칸에서 가져다 쓰면 번역이 따라간다.
- 개발 2의 새 서비스(퀵슬롯·King 등)는 `Config` 표에 글을 두고, 줄 키를 `docs/l10n/strings_server_en.json`에서 확인.

## 6. 번역 흐름 (검수 API)
> **대체됨 — `docs/design/l10n_contract_2026-10-11.md` v2(검수 승인 조건 반영, 2026-10-11).** 아래는 기록용.
1. `py tools/l10n_export.py` → `docs/l10n/strings_server_en.json` (키·영어·자리표시자 `args`·길이 `max`·`where`). 같은 영어 글은 한 번만 번역해도 된다(`en`이 같은 키가 1,792 중 182개).
2. 검수가 번역 초안을 `docs/l10n/strings_server_ko.json`(같은 `key` + `ko`)로 만든다 — 용어집 `docs/design/glossary_ko_*.md` 기준, 아이도 읽는 쉬운 말.
3. `tools/l10n_apply.py`(개발 1)가 `TextKo.luau`를 쓰고 시험이 검사: 모든 키가 영어에 있음 · `args` 같음 · 글자 수 `max` 안 · 금지어 없음.
4. 영어 글을 고치면 다시 export → 바뀐 키만 `ko`를 다시 받음(export가 `en` 해시로 바뀐 줄을 알려 주는 `--diff`는 구현 때).

## 현재 진행 순서 — 사용자 확정 (2026-10-05 최신)

**게임성 먼저, 그림은 나중에.** 아래 베타 필수 목록은 *범위*이고, 작업 *순서*는 이 절을 따른다(베타 목록의 번호 순서가 아니다).

1. **첫 10분이 끊기지 않게:** **15~25초 3D 오프닝(건너뛰기 가능, A23-9)** → 진영·직업 선택 → 안내자 대화·첫 임무 수락 → 말랑 초원 슬라임5마리 → **150골드** → 대장간에서 무기 고르기(구매는 선택) → 대장간 뒤에도 보이는 다음 목표. 스킬 사용 퀘스트는 몬스터를 맞힌 스킬만 센다.
2. **전투:** 수동 전투 확인 + **자동 전투 켜기/끄기**(선택 퀘스트 "내 싸움을 배우는 왕관 조각"으로 해금, 자동은 공격·스킬 모두, 몬스터만). 계약은 `SPEC_ADDENDUM.md` A23.
3. **치비 3D 코스튬 제거:** 플레이어는 본인 Roblox 아바타 + 무기 + 헤일로/뿔. R15·R6에서 걷기·점프·공격·스킬·사망/부활 확인.
4. **전리품·성장:** 주문서 강화 등 "사냥 → 전리품 → 준비·선택" 흐름(세부 수치는 사용자 확인 후).
5. **마을 서비스:** 상점 NPC는 우선 기본 Roblox 스타일 NPC로 세워 물약·장비 상점을 작동.
6. **바로 이어서 Firefly 그림 전면 교체 + 화면 구조(HUD 배치) 전면 재설계** (사용자 2026-10-05: "화면 구조도 다 바꿔야 하는 거 알지?"). 배치 시안 1장을 먼저 승인받고 그림과 함께 바꾼다. 확인된 문제: 3D 지역 간판이 상단 전쟁 바와 겹침, 왼쪽 카드·물약·퀘스트가 세로로 길게 차지, 오른쪽 칸들이 흩어짐, 폰 작은 화면에서 가운데가 가려짐. 그 전까지는 명백한 겹침만 작게 고친다.
   **그림:** 옛 그림은 전부 폐기(안 쓰는 건 즉시 삭제, 게임 속 그림은 새 그림으로 바꿀 때 삭제). 진영 화면 → HUD·공통 화면 → 아이콘 → 캐릭터·NPC(로블록스 스타일) → 바닥 지형 텍스처15개.
   **2026-10-06 사용자 결정(A23-25): 그림 묶음 0~21 전부 베타(지형 15장 포함). '여유 있을 때만'·'최저선' 규칙은 없앤다. 세션은 5개(이미지 생성·이미지 개발·게임성 개발·게임성 개발 2·검수), 진행판 `docs/design/beta_board_2026-10-06.md`.**

- **코드를 고치면 바로 실행 중인 Studio에 반영해 사용자가 같이 해 볼 수 있게 한다**(사용자 요청 2026-10-05).

## 언어 (2026-10-09 최신: A23-48 영어 전용 + A23-89)
- **글로벌(영어) 버전을 먼저 낸다**(베타 10/31, 정식 12/19). **한국어 버전은 그 뒤에 따로** 낸다(형태·날짜는 글로벌 정식 뒤 사용자가 정함). 한국어 글자는 이미지로(Firefly GPT 모델, 한 글자씩 확대 검사). 아래 옛 '한국어 + 영어 한 게임' 계획은 기록용.
- (옛 계획) 게임을 둘로 나누지 않는다. 같은 서버에서 플레이어 언어 설정에 따라 글자가 바뀐다.
- `LocalizationTable`: 한국어 원문 → 영어 번역을 직접 넣는다. 게임 용어(헤일로, 혼즈, 깡패, 장인 길드…)는 용어집을 정해서 일관되게 쓴다. 새 한국어 문구는 중앙 텍스트 표에 넣어 번역할 수 있게 한다.
- 로블록스 자동 번역은 다른 언어의 보조로만 쓴다.
- 그림 글자는 현재 꺼져 있다(`UseTextImages=false`). 영어 전환의 실제 걸림돌은 **한국어 글씨가 그림에 박힌 이미지**(진영 카드3·제목·설명판·하단 안내 등)다. 영어판이 필요하면 같은 스타일을 **Firefly로 만들어** 사용자 승인 후 `Player.LocaleId`에 따라 바꿔 끼운다.

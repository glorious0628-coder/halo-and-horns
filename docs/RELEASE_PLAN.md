## 언어 (2026-10-09 최신: A23-48 영어 전용 + A23-89)
- **글로벌(영어) 버전을 먼저 낸다**(베타 10/31, 정식 12/19). **한국어 버전은 그 뒤에 따로** 낸다(형태·날짜는 글로벌 정식 뒤 사용자가 정함). 한국어 글자는 이미지로(Firefly GPT 모델, 한 글자씩 확대 검사). 아래 옛 '한국어 + 영어 한 게임' 계획은 기록용.
- (옛 계획) 게임을 둘로 나누지 않는다. 같은 서버에서 플레이어 언어 설정에 따라 글자가 바뀐다.
- `LocalizationTable`: 한국어 원문 → 영어 번역을 직접 넣는다. 게임 용어(헤일로, 혼즈, 깡패, 장인 길드…)는 용어집을 정해서 일관되게 쓴다. 새 한국어 문구는 중앙 텍스트 표에 넣어 번역할 수 있게 한다.

## 현재 진행 순서 — 사용자 추가 확정 (2026-10-04)

게임에 쓰는 기본 디자인을 먼저 정립한 뒤 스토리와 플레이 전반을 다시 점검한다. 진영 선택의 카드·설명판·제목·하단 안내를 각각 새 투명 PNG로 완성하고, 실제 사용 이미지 목록에 따라 HUD와 공통 화면으로 이어간다. 확대 글씨·밝고 어두운 배경·실제 클라이언트 검사를 거친다. 기본형 이후에도 디자인은 계속 업데이트한다. 아래 출시 날짜는 유지하며, 아래 베타 기능 목록을 완료로 처리하거나 없애지 않는다. 전체 이미지 수는 구버전·미사용·3D와 UI를 구분한 목록으로 집계한다.

사용자가 재제작 범위를 **3D 아바타를 제외한 모든 그림, 직업별 이미지 전부 포함**으로 명확히 했다. 기존 그림체를 유지하고 캐릭터의 어깨·몸통·배·다리는 의상으로 완전히 가린다. 독립 UI/캐릭터 그림은 투명 배경으로 한 장씩 만들며, 지형 타일처럼 표면 전체를 채워야 하는 이미지와 구분한다. 이 디자인 작업에서 3D 아바타를 다시 생성하지 않는다.

## 언어: 게임 하나에 한국어 + 영어
- 게임을 둘로 나누지 않는다. 같은 서버에서 플레이어 언어 설정에 따라 글자가 바뀐다.
- `LocalizationTable`: 한국어 원문 → 영어 번역을 직접 넣는다. 게임 용어(헤일로, 혼즈, 깡패, 장인 길드…)는 용어집을 정해서 일관되게 쓴다.
- 로블록스 자동 번역은 다른 언어의 보조로만 쓴다.
- 그림 글자(`art/out/TXT_*.png`, C 스타일 42개)는 같은 스타일의 **영어판을 GPT로 만들어** 사용자에게 보여 주고 승인을 받는다. 플레이어 언어(`Player.LocaleId`)에 따라 바꿔 끼운다.
- 닉네임 금칙어에 영어 목록을 추가한다.
- Studio 로케일 에뮬레이션으로 ko와 en을 둘 다 검사하고 스크린샷을 남긴다.
- **컷라인:** 10/24까지 아래 베타 필수 1–6이 안 끝나면 영어는 정식(12/19)으로 미룬다.

   - 게임 아이콘과 썸네일: GPT 시안을 보여 주고 사용자가 고른다.
   - 설명문: 한국어와 영어.
   - 성숙도 설문 답안.
   - 여러 명 테스트: Studio 클라이언트 3명 이상, PvP, 거위, 괴수.

# Claude 검토용: 사용자 지정 영상과 현재 HUD 글자 문제

작성일: 2026-10-04 KST. 대상 게임: **선악 키우기: 헤일로 & 혼즈**.

**참고자료 정리 완료, 전편 시청 완료 아님.** 제공 자막 7개 중 6개는 전체 내용이 있고, 코드아티스트 1개는 인터뷰 구간이 빠져 있다. 실제 재생·화면 관찰·자막 분석과 미확인 범위를 아래에 구분했다.

우리 게임 실행 제안은 다음 다섯 가지이며 **아직 승인된 구현이 아니다.**

1. **가독성:** 한글·숫자·영어의 실효 글자 크기, 고정 폭, 여백, 굵기·테두리를 실제 게임 해상도에서 측정한다.
2. **3D 프로필:** 실제 아바타와 같은 얼굴·코스튬을 보여 주고, 작은 원 안의 눈·입이 충분히 크고 선명한지 비교한다.
3. **입력 피드백:** 공격·발사·명중·버튼·보상 결과를 알아볼 수 있는지 확인하고, 과한 효과가 얼굴·목표·HUD를 가리지 않게 검토한다.
4. **단계별 안내:** 첫 진영/직업 선택부터 사냥·보상·업그레이드까지 현재 해야 할 행동을 하나씩 이해할 수 있는지 확인한다.
5. **핵심 선악 선택:** 쉬운 조작 안에서 누구를 돕거나 털었는지, 그 선택의 결과가 헤일로·뿔·표식·보상에 연결되는지 검토한다.

이 문서는 영상에서 확인한 내용, 자동 자막으로 읽은 내용, 우리 게임 적용 제안을 구분한다. 제안은 사용자 승인이나 구현 완료가 아니다. 영상의 코드·에셋·플러그인을 설치하거나 게임 소스를 변경하지 않았다.

**R2 아바타 제작과 별도 자료다.** 무료 B0/B0H 기준선은 제작·측정 후 사용자에게 표시했다. 최신 출시 계획 지시에 따라 유료 R2는 보류하며 유료 실행 0이다. 이 문서의 영상 조사나 HUD 제안을 R2 제작 승인·최종 합격으로 집계하지 않는다.

**최신 작업 순서:** 사용자가 지정한 유튜브 연구를 먼저 마친 뒤, `docs/RELEASE_PLAN.md`·`docs/GDD.md` §0·`AGENTS.md` 상단의 확정 우선순위를 따른다. R2는 무료 기준선까지만 보여 주고 이후 베타 필수 작업 순서로 진행한다. 영상에서 얻은 제안이 출시 범위를 늘리거나 유료 제작을 승인하지 않는다. 핵심 조건은 **“모든 행동이 천사 아니면 악마 쪽으로 기운다”**, 조작은 쉽게 두고 선택과 결과가 드러나게 하는 것이다.

## 9. 현재 HUD 글자가 작고 약하게 보이는 코드 근거

아래는 `HUD.luau`·`UIKit.luau`와 연관 Config를 **읽기 전용으로 확인한 결과**다. 파일 수정 없이 작성했으며 줄 번호는 이 문서 작성 당시 기준이다. 한글 글꼴 자체의 결함이나 폰트 로딩 실패를 확인한 것은 아니다.

### 9.1 제목과 본문이 낮은 실효 크기 상한으로 다시 제한됨

`artLabel()`은 개별 `TextSize`·`MaxTextSize`를 받은 뒤 제목 13px/본문 12px 상한을 다시 적용한다. 별도 호출도 직업명 12px, XP·퀘스트 보상 11px, 데스크톱 레벨 14px로 제한한다. 큰 화면에서도 주요 글자가 충분히 커지지 않는 직접적인 설정이다.

- `src/StarterPlayer/StarterPlayerScripts/HUD.luau:420` — `L.FitText`.
- `src/StarterPlayer/StarterPlayerScripts/HUD.luau:479` — 제목 13/본문 12 상한 재적용.
- `src/StarterPlayer/StarterPlayerScripts/HUD.luau:648` — 데스크톱 레벨 14.
- `src/StarterPlayer/StarterPlayerScripts/HUD.luau:709` — 상태창 제목 13/직업 12.
- `src/StarterPlayer/StarterPlayerScripts/HUD.luau:726` — XP 11.
- `src/StarterPlayer/StarterPlayerScripts/HUD.luau:2500` — 교체·퀘스트 배지·보상 11, 퀘스트 본문 12.

### 9.2 작은 화면에서 좁아지는 가로폭과 한 줄 축소가 겹침

데스크톱 배율은 `화면 높이 / 720 × 0.8`, 최저 0.6이다. 높이 475px에서는 상태창 폭 `280×0.6=168px`, 제목 칸 폭 `(280−138)×0.6=85.2px`다. `LayoutStats()`는 글자 칸 높이를 보정하지만 폭은 유지한다. HUD는 줄바꿈을 끄고 `UIKit.FitText()`가 칸에 맞춰 글자를 줄인다. 긴 한글 이름·설명은 더 빨리 축소나 말줄임 대상이 된다.

- `src/ReplicatedStorage/Shared/Config.luau:1044` — DesktopScaleMult/Min/Max.
- `src/StarterPlayer/StarterPlayerScripts/UIKit.luau:255` — 실제 데스크톱 배율 식.
- `src/StarterPlayer/StarterPlayerScripts/HUD.luau:57` — 상태창 기본 폭 280.
- `src/StarterPlayer/StarterPlayerScripts/HUD.luau:453` — 줄바꿈 해제.
- `src/StarterPlayer/StarterPlayerScripts/HUD.luau:792` — 제목 가로폭 고정.
- `src/StarterPlayer/StarterPlayerScripts/UIKit.luau:931` — 실제 칸/글자 경계를 비교해 축소.

### 9.3 최소 글자 크기 계산과 물리 크기 측정 기준이 다름

HUD의 `min(11, floor(11 / scale))`는 배율 0.6에서도 논리 최소값을 11로 둔다. 반면 측정 함수는 최소 물리 크기 11로 계산한다. 적용 최소값과 측정 기준이 서로 다르므로 코드만으로 실효 11px 보장을 주장할 수 없다. **실제 화면이 6.6px였다고 단정한 결과는 아니다.** 최소 크기까지 줄어든 라벨의 실제 TextSize·UIScale·TextBounds·화면을 함께 측정해야 한다.

- `src/StarterPlayer/StarterPlayerScripts/HUD.luau:430` — 논리 최소값 계산.
- `src/StarterPlayer/StarterPlayerScripts/UIKit.luau:879` — 측정 시 최소 물리 크기 11 적용.
- `src/StarterPlayer/StarterPlayerScripts/UIKit.luau:956` — fit 최소값을 다시 11 이하로 제한.

### 9.4 숫자 전용 글꼴과 글자 계층이 공통 글꼴로 덮임

Config에는 Title=GothamBlack, Body=GothamBold, Number=FredokaOne이 있다. 그러나 `themeFontFace()`는 Enum.Font를 공통 글꼴 ID `12187370747`의 굵기로 변환한다. FredokaOne도 공통 글꼴의 Bold로 바뀌고, HUD는 제목 이외를 다시 Regular로 지정한다. 따라서 `Number=true`라고 해서 둥근 Fredoka 숫자가 실제로 유지되는 구조가 아니다. 기존 기록상 공통 글꼴은 사용자가 선택한 Noto Sans이며, 이 자료는 그 선택을 임의로 취소하자는 제안이 아니다.

- `src/ReplicatedStorage/Shared/Config.luau:1323` — 제목·본문·숫자 글꼴 설정.
- `src/StarterPlayer/StarterPlayerScripts/UIKit.luau:23` — 공통 글꼴 ID.
- `src/StarterPlayer/StarterPlayerScripts/UIKit.luau:140` — FredokaOne을 Bold로 변환.
- `src/StarterPlayer/StarterPlayerScripts/UIKit.luau:305` — 생성한 텍스트에 공통 FontFace 적용.
- `src/StarterPlayer/StarterPlayerScripts/HUD.luau:452` — Bold 또는 Regular로 재지정.
- `src/StarterPlayer/StarterPlayerScripts/HUD.luau:476` — artLabel의 제목/일반 굵기 재지정.

### 9.5 HUD의 글자 테두리가 매우 약하게 재설정됨

기본 `LightText()`는 두께 1.5의 불투명 테두리를 사용하지만 HUD는 두께 0.4·투명도 0.65로 바꾸고 기본 TextStroke도 끈다. 작은 Regular 글자와 함께 쓰여 장식이 많은 프레임·밝은 게이지 위에서 획이 약하게 보일 가능성이 있다. 미관의 좋고 나쁨은 코드만으로 확정하지 않고 실제 화면과 승인 시안을 비교해야 한다.

- `src/StarterPlayer/StarterPlayerScripts/UIKit.luau:750` — LightText 기본 테두리.
- `src/StarterPlayer/StarterPlayerScripts/HUD.luau:454` — 기본 TextStroke 끄기.
- `src/StarterPlayer/StarterPlayerScripts/HUD.luau:457` — 두께 0.4/투명도 0.65.
- `src/StarterPlayer/StarterPlayerScripts/HUD.luau:478` — artLabel에서도 같은 테두리 재설정.

Claude 후속 검토는 **영상의 정보 전달 원칙과 위 코드의 실측 가능한 원인**을 연결하는 데 집중하면 된다. 글꼴·크기·배치·새 장식은 아직 확정안이 아니며, 사용자에게 보여 줄 GPT 시안과 실제 해상도 비교를 거쳐야 한다.

# 첫 시작과 짧은 애니메이션 참고 — 2026-10-04

사용자 요청: 인기 Roblox 게임뿐 아니라 다른 RPG의 튜토리얼·오프닝을 조사하고, 우리 게임 첫 10분에 가져올 점을 남긴다. 최종 목표는 이후에도 계속 플레이할 수 있는 게임이다.

## 확인 범위

웹의 공식 소개·공식 초보 안내·퀘스트 공략을 읽은 비교다. 이번 조사에서 타 게임을 직접 실행하거나 영상을 연속 재생하지 않았다. 현재 인기 순위, 초보 이탈률, 정확한 첫 10분 소요시간을 측정한 자료가 아니다. 아래 흐름과 제작 제안은 구분한다.

## 우리 게임에서 확인한 문제와 이번 수정

- 실제 Studio에서 안전한 빛의 성채 바로 앞에 개인 황금 슬라임이 나타났다. 사용자 “너무 뜬금없어”라는 지적을 받았다. 초기 화면에 전쟁·발사·거위 정보가 동시에 나타나는 점도 별도 미해결이다.
- 개인 슬라임을 마을에 생성하는 QuestService 경로를 제거했다. 진영·직업 선택 → ‘왕관 조각을 삼킨 슬라임이 초원에 있다’는 짧은 안내 → 초원 이동 → 기존 5킬 임무로 연결했다. 신규 대화 NPC·컷신을 구현했다는 의미는 아니다.
- 기존 고정 퀘스트 위젯으로 현재 목표를 계속 표시한다. 5킬 진행은 저장 데이터 필드에 두며, 실제 영속 DataStore 검증은 별도다. 보상 뒤에는 대장간·Lv5·Lv10 목표가 이어진다.

## 짧은 오프닝 제안 — 아직 제작·적용 안 함

**약 10–15초, 건너뛰기 가능:** 지금 있는 왕관·마을을 잠깐 보여 줌 → 내 아바타로 카메라 이동 → 진영의 첫 조사 목적 한 문장 → 초원 방향을 보여 주고 조작권 복귀. 기존 리그의 고개 돌리기·손짓 정도만 우선한다. 시간은 제작 범위 제안이며 실제 재생 검증값이 아니다.

첫 목적 후보는 같은 조사라도 빛은 동료를 지킬 힘, 뿔은 왕관을 차지할 힘, 장인은 전쟁 밖에서 자기 길을 만들기라는 기존 세계관에 연결한다. 아직 없는 조각 인벤토리·주문서·NPC 보상을 이미 얻었다고 말하지 않는다. 내 Roblox 아바타와 친구가 있는 월드로 자연스럽게 돌아오는 것이 기준이다.

장면 제작을 시작하면 GPT 스토리보드를 먼저 보여 주고 선택된 구도로 만든다. 이번 연구는 승인된 아트 변경·새 NPC/모션 업로드·유료 생성 승인이 아니다. 현재 디자인은 유지한다.

## 애니메이션 제작 가능성과 검사

Roblox는 리그의 관절/뼈에 포즈를 만들고 포즈 사이를 보간하는 애니메이션을 지원한다. 현재 게임의 리그를 이용한 짧은 동작과 카메라 연출은 구현 가능한 범위다. 관절 없는 정적 그림과 3D 리그를 구분한다. [공식 Animation Editor](https://create.roblox.com/docs/animation/editor), [공식 캐릭터 애니메이션 튜토리얼](https://create.roblox.com/docs/tutorials/use-case-tutorials/animation/create-an-animation)

카메라 연출 중에는 Scriptable 제어와 종료 후 기존 CameraSubject/CameraType 복원이 필요하다. 이미 고친 추적 카메라가 컷신 뒤 다시 끊기지 않도록, 건너뛰기·사망·리스폰·화면 크기 변경을 검사해야 한다. [공식 Camera API](https://create.roblox.com/docs/reference/engine/classes/Camera)

우리 프로젝트 기준 제작 난도 판단: 짧은 손짓·고개 돌림·카메라 이동은 작은 범위, 여러 인물의 정교한 전투·입 모양·장편 연출은 큰 범위다. 기존 3D 사용 자체에 Tripo 재생성은 필요하지 않다. 이번 연구/코드 수정의 유료 호출·Tripo 사용은 0이다.

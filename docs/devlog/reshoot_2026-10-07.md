## 5. 촬영 스크립트 (10/08 고쳐 둠, Play 전)
`FILM_OK=1 STUDIO_NAME=FilmSet py tools/devlog_shots_s40.py [A] [C] [B]`(글자 없으면 전부, 늘 A → C → B 순서), 빼고 싶은 장면은 `SKIP=s40_crossroads,s40_halo_town`.
- A는 시작 전에 Edit에서 `StudioFreshSave`를 켜고, 끝나면 끈다(새 데이터, 저장 안 됨). 리모트·모루는 `play_weapon_first.py`와 같다.
- 좌표: 장소·몬스터 위치는 Play 때 `Config.Zones`의 Center·Spawn에서 읽는다(성 입구 길은 s30과 같은 모양).
- 슬라임 사냥: 가장 가까운 내 슬라임으로 걸어가 `Keybinds.Dispatch` F(공격)를 0.45초마다 누른다. 5마리 뒤 4.5초 쉬고 [Claim]을 누른다(싸운 직후 카드는 저절로 안 열림, Panels CalmSeconds).
- 말풍선: 서버에서 슬라임에 `Bark`·`BarkAt`을 넣는다(BarkService 계약, 내 캐릭터 60스터드 안).
- 오프라인 검사: `py -m py_compile`과 Lua 조각 16개 `luau-compile` 통과.
- **첫 Play에서 볼 것:**
  1. 공격 키 F로 슬라임이 실제로 맞는지
  2. [Claim] 뒤 도시락 카드가 바로 뜨는지(안 뜨면 `StoryAction Open`)
  3. HUD를 꺼도 말풍선이 보이는지
  4. 새 카메라 길(초원·숲 위)이 땅이나 나무에 막히지 않는지
  - 장면마다 확인 시트 `build/devlog/check/<이름>_sheet.png`를 보고 고친다.

## 6. 순서 (단계마다 검수 "전달함, 시작" 뒤, 끝나면 "끝")
검수 결정(10/08): 교차로·두 성(C-1~C-3)은 교차로 3D 바꾸기·성이 메인에 들어간 뒤 따로 찍는다 → 그 전 촬영은 `SKIP=s40_crossroads,s40_halo_town,s40_horns_town`. 새 쇼츠 'first 60 seconds'는 대본 안 씀(아이디어 목록에만).
1. FilmSet 맞추기 + 테스트 Play + 내 캐릭터 정면 1장(약 4분) → 사진을 검수로.
2. A 흐름(새 플레이어, 약 4분) → 확인 시트를 검수로.
3. B·C(약 12분) → 확인 시트.
4. 쇼츠 4편(+ 새 쇼츠는 OK 뒤) + 1편 다시 만들기 → 안전 영역 시트 → 다운로드 새 폴더 `HaloHorns_<무엇>_<날짜>` → 검수.

# 화면(UI) 검수 기준 (검수 세션, 2026-10-06)

> 2026-10-09 검수: 그 뒤 바뀐 것 — 게임 글은 영어만(SPEC A23-48: ②의 한국어 줄 길이·⑨의 KO/EN 대신 쉬운 영어), 글꼴 Denk One + Montserrat(A23-63), HUD 틀은 ①의 v2 대신 A23-74·A23-94, UI는 PC 먼저·폰 라운드는 따로(A23-98, ⑧).

사용자가 보여 준 `Superfuture/design-review`(MIT, 10가지 디자인 기준 + 막힘/중요/다듬기 3단계 + 숫자로 재는 검사)에서 쓸 만한 것만 가져와 **우리 게임(Roblox, 어린이, 폰, 장난감 UI)** 에 맞게 바꿨다. 설치해서 쓰지 않고, 화면 시트·캡처를 검수할 때 이 표로 본다. 각 세션은 시트를 보내기 전에 스스로 한 번 훑는다.

## 등급
- **상(막힘):** 고장, 글자를 못 읽음, 누를 수 없음, 안전·옷차림 문제, 겹쳐서 가림.
- **중(중요):** 눈에 띄게 헷갈리거나 불편함(무엇을 눌러야 할지 모름, 폰에서 너무 작음, 같은 것이 다르게 생김).
- **하(다듬기):** 더 예쁘게 할 여지.
- 찾은 것마다 **무엇이 문제인지 / 왜 / 정확한 고칠 값**(px·색·간격)을 적는다. "좀 더 크게" 같은 말은 쓰지 않는다. 끝에 잘된 점과 가장 효과 큰 고칠 것 1~3개를 쓴다.

## 10가지 기준 (우리 게임 숫자)
1. **눈길 순서·배치:** 한 화면에 가장 중요한 것 하나(예: 진영 카드의 [이 편으로!], HUD의 공격 버튼)가 먼저 보인다. 관련된 것끼리 묶고, HUD v2 사각형(`docs/design/hud_layout_v2_2026-10-06.json`)에 맞춘다. 화면 가운데는 비워 캐릭터·몬스터가 보이게 한다.
2. **글자:** 글꼴 가족은 2개 이하. 크기 단계는 5개 이하(예: 제목·부제·본문·작은 글·숫자). 폰(749×361)에서 본문 실제 14px 이상, 버튼 글자 16px 이상, 이름표 12px 이상. 한 줄에 너무 길지 않게(한국어 본문은 한 줄 약 20~28자). 밝은 판 위 글자는 진한 색, 어두운 판·3D 위 글자는 외곽선(UIStroke)을 넣는다. 글꼴·꾸밈은 글꼴 조사 결과(검수 정리 예정)를 따른다.
3. **간격:** 4의 배수 간격(4·8·12·16·24). 같은 종류 칸 사이 간격은 화면 전체에서 같다. 누르는 것끼리 최소 2du 떨어진다(맞닿지 않음).
4. **색·대비:** 판 위 본문 글자 대비 4.5:1 이상, 큰 글자·아이콘·버튼 테 3:1 이상(PIL로 잰다). **색으로만 뜻을 전하지 않는다:** 등급은 색 + 별/글자, 진영은 색 + 후광/뿔 모양, HP·MP는 색 + 글자. 꺼진 버튼도 읽힐 만큼(3:1) 보인다.
5. **움직임:** 버튼·창 전환 0.15~0.25초, 큰 등장 0.3~0.5초. 화면 흔들림·번쩍임은 설정의 '흔들림 끄기'(BB3, ReducedMotion)를 따른다. 움직임 때문에 다른 칸이 밀리지 않는다.
6. **버튼 상태:** 누르는 것마다 보통·눌림·꺼짐(+ PC 마우스 올림, 쿨다운·MP 부족 같은 게임 상태)이 정해져 있다. **누르는 칸 60du 이상**(폰). 창마다 빈 상태(가방이 비었을 때), 불러오는 중(랭킹), 실패(서버 거절) 문구가 있다.
7. **누구나 쓰기:** PC 키 안내는 Keybinds.ShowsKeys()로만, 폰은 버튼 이름으로. 게임패드로 닫기(B)·고르기. 아이콘만 있는 버튼은 처음 한 번 이름이 보이거나 길게 누르면 이름이 뜬다.
8. **화면 크기:** 1280×720, 1024×768(태블릿), 749×361(폰, 안전 영역 655×340), 844×390에서 겹침 0, 잘린 글자 0, 조이스틱 자리(왼쪽 아래) 비움. 확인은 사진 + AbsolutePosition·AbsoluteSize 측정.
9. **문구:** 짧고 아이가 바로 아는 말. 버튼은 동작으로("이 편으로!", "받기"). 없는 기능·보상을 약속하지 않는다("곧 추가" 금지). 문구는 Config 표에 KO/EN.
10. **한결같음:** 같은 종류는 같은 그림 키(UIKit·Config.UIArt), 같은 테 두께·모서리·그림자·아이콘 스타일(장난감 광택, 굵은 남색 테). 새 모양은 승인된 그림이 먼저(AGENTS Art workflow).

## 이미 정해진 우리 규칙(덧붙임)
- 그림엔 글자를 굽지 않는다(글자는 TextLabel). 사람 그림은 단정한 옷. 누끼는 밝은·어두운 바탕 4배로 본다.
- 어린이용: 무섭거나 피 나는 표현 없음, 핼러윈도 귀엽게.

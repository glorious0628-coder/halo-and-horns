- PC 왼쪽 드래그 카메라 고치고(시프트락에서 2배 회전, 움직이며 클릭하면 공격 누락) 직접 확인. 스킬 버튼에 MP 비용 보이기.

### 단계 6. 물약 상점 열기 (베타 3번)
- 임시 기본 NPC + Panels에 없는 PotionShop 화면 + 남은 수량.
  - 화면은 대장간 화면 패턴: 가격·보유 골드·재고·1병/5병·서버 확인 결과·실패 이유.

- 첫 임무에서 HP 물약 1~2병 줄지도 물어보기.

### 단계 7. 전리품: 주문서 강화 (규칙부터)

  - 무기 바꿀 때 처리(추천: 강화 수치 이어받기 또는 판매·교체 때 주문서 반환)

  - 처음 한 번은 대장간에서 "주문서로 한 번 강화해 봐요 · 항상 성공" 안내 + 결과 "+1 · 공격 N→M (슬라임 3방→2방)" 표시

### 단계 8. Firefly로 그림 전부 새로 (게임성 단계 끝나면 바로)
- **도구:** Firefly 웹(firefly.adobe.com)을 Claude와 연동된 브라우저(내 Chrome 로그인)로 써. 결과는 art/out/<id>.png로 저장. 다운로드 확인이 필요하면 묶어서 한 번에 물어보기.
- **맨 처음:** 스타일 기준 1장을 만들어 나한테 승인받기(로블록스풍 블록 장난감 느낌, 밝은 색, 아이 친화). 그다음부터는 승인된 새 Firefly 그림만 스타일 참고로 써(옛 그림 참고 금지).
- **프롬프트 규칙:**
  - "Roblox" 같은 상표 이름 대신 모양을 설명("blocky toy-avatar style, square head, simple flat face, chunky limbs").
  - 사람 캐릭터는 어깨·몸통·배·다리를 가리는 단정한 옷.
  - 판 그림에는 글자를 넣지 말고 빈 판으로(글자는 게임 TextLabel로, 한영 전환용).
  - 누끼 쉽게 단색 배경.
- **한 장씩 순서:** 프롬프트를 art/prompts/<id>.txt에 저장 → Firefly로 2~4개 생성 → 나한테 한 장씩 보여 주기 → 내가 고름 → art/approved.json 기록 → 누끼(image_remove_background 또는 로컬, 원본 보관) → 밝은/어두운 배경 확대 검사 → 10장 이하로 업로드 → Config.UIArt / MaterialService ID 교체 → **바로 Studio 반영** → 화면 확인 → 옛 파일 삭제·기록.
- **지형 텍스처15개:** 누끼 없이 이음새 없는 정사각 타일. 3×3으로 이어 붙여 검사한 뒤 MaterialService에 적용.
- **순서:**
  1. 진영 선택 화면(카드3·제목·설명판·하단 안내)
  2. HUD·공통 화면(버튼·바·패널·퀘스트 줄·물약 칸·자동 전투 버튼)
  3. 아이콘(무기27 등)
  4. 캐릭터·NPC·안내자(로블록스 스타일, 직업 선택 그림 포함)
  5. 지형 텍스처15
- 진행을 "그림 N/총M 교체"로 게임성 개수와 따로 보고.

# 폰 실기 확인 목록 (게임성 개발 1, 2026-10-17) — 큐 #2

진짜 폰(사용자 폰 또는 게임 플레이 세션의 폰 흉내)에서 볼 것. 각 줄 = 무엇을 하고 → 무엇이 되면 통과.
Studio 폰 흉내로 값 재기(엄지 두 개 동시 입력은 흉내로 못 함 → 진짜 폰만): `HH_MAIN_STUDIO=1 py tools/play_phone_round_photos.py first10`
(메인 반영 1) 또는 시험 Studio(STUDIO_ID)로 같은 도구.

## A. 엄지 두 개 (진짜 폰만)
1. 왼손 이동 스틱을 누른 채 오른손 공격 버튼 연타 → 걸으면서 공격이 나감(이동이 멈추지 않음).
2. 왼손 이동 중 오른손으로 화면 끌기 → 카메라가 돌고 이동은 그대로.
3. 왼손 이동 중 스킬 Z 버튼 → 스킬 나감(MP·재사용이 막으면 버튼 테두리로 보임, 글 띠 없음).
4. 싸우는 중 물약 퀵슬롯 1 누르기 → 마심(HP 숫자 오름), 이동 안 끊김.

## B. 공격 '통역사' (Config.AutoFace, HUD L.FaceTarget)
5. 몬스터가 옆(90° 안)에 있을 때 공격 버튼 → 몸이 그쪽으로 살짝 돌고 맞음. 등 뒤(겨눔 각 밖)는 안 돎.
6. 몬스터 없이 공격 → 그냥 휘두름(돌지 않음, 막힘 표시 없음).

## C. 누르기 범위 (UIKit.TapPad, 최소 44px)
7. 공격·스킬·물약·메뉴 버튼을 가장자리 가까이 눌러도 됨(손가락 반쯤 걸쳐도).
8. 퀘스트 줄(왼쪽 목표) 누르기 → 길 안내 표시가 뜸.
9. 줍기(가방·도시락 등 Pickup)는 스쳐 지나가도 주워짐(StoryNpcs.BrushPickup, 5칸 안).

## D. 첫 10분 읽힘 (폰 흉내로 값: play_phone_round_photos first10 → summary.txt의 cut / small / off / overlap / tiny)
10. cut 0, off 0, overlap 0. small·tiny는 사진으로 판단.
11. 이번 주 새로 들어간 것: 허수아비 줄('Hit the dummy'), 가방 강화 창(모루 G), KO 화면 몬스터 그림, 물약 칸 반짝, 2배 칩 반짝 — 폰에서 잘리지·겹치지 않는지.

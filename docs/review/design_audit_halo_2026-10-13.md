## 한 줄 결론
**시안은 다시 쓰지 않는다. 모델도 좋다. 모자란 건 '땅·길·절벽·물·빽빽함'이고 전부 0원(파트·MaterialVariant·Terrain·조명·이미 통과한 모델 놓기)으로 된다.** 10/20 주 6단계 교체 때 이 표대로 하면 시안의 70%까지 간다.

## 잘된 것 (그대로)
- 구역 시안: 흰 대리석 + 금 돔 + 하늘색 띠, 크림색 포장에 금 무늬, 절벽 섬과 폭포, 구름 덤불·흰/파랑 꽃. 통일돼 있고 Roblox 풍. 사용자가 고른 것이라 그대로.
- 구역 지도 v2: 첫 10분 동선(성문 → 다리 → 교차로 대장간 → 초원)과 11개 동네, 집 29채, 물길 3, 다리 3이 다 정해져 있음. 바꿀 것 없음.
- PBR 모델: 분수(Town_Halo_Fountain3)·동상(Halo_Statue)은 2D와 거의 같음(4면 IoU 0.5~0.9, 색 맞음). 95종 통과 판정 유지.
- 집 골격 7채 + 가게 4: 흰 벽·금 테·하늘색 창·차양 = 시안 팔레트 안.

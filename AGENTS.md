## Code conventions (Luau)
- `src/` Rojo-style (no Rojo): `*.server.luau` Script, `*.client.luau` LocalScript, `*.luau` Module. Modules use `Init(S)`/`Start()`; entries `src/ServerScriptService/Main.server.luau`, `src/StarterPlayer/StarterPlayerScripts/ClientMain.client.luau` load by `WaitForChild` from fixed lists: remove a module from the lists **and every `require`** before deleting its file, or it hangs.
